## 3. UI 적용 사양

### 배치 위치
- 각 분석 화면 **상단** 또는 **하단**에 접이식(collapsible) 배너로 배치
- 최초 1회는 펼쳐진 상태로 표시, 이후 접힌 상태 유지
- 자동매매 화면에서는 항상 펼쳐진 상태 유지

### 디자인 가이드
- 배경색: `var(--color-warning-bg)` 또는 연한 노란색 (#FFF3CD)
- 텍스트: `var(--color-text-secondary)` 또는 어두운 회색
- 아이콘: 경고 아이콘 (TriangleAlert) 사용
- 폰트 크기: 본문보다 1단계 작게 (12px ~ 13px)

### 컴포넌트 이름
- `<DisclaimerBanner type="signal" />`
- `<DisclaimerBanner type="ai-analysis" />`
- `<DisclaimerBanner type="coaching" />`
- `<DisclaimerBanner type="backtest" />`
- `<DisclaimerBanner type="auto-trade" />`
