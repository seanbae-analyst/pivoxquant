# PivoxQuant 개인정보처리방침

> 시행일: 2026년 4월 __일
> 최종 수정일: 2026-04-09
> 법적 검토 상태: 초안 (변호사 검토 전)

---

PivoxQuant(이하 "회사")은 「개인정보보호법」 제30조에 따라 이용자의 개인정보를 보호하고, 이와 관련한 고충을 신속하고 원활하게 처리하기 위하여 다음과 같이 개인정보처리방침을 수립하여 공개합니다.

---

## 제1조 (개인정보의 수집 항목 및 수집 방법)

### 1. 수집 항목

#### 필수 수집 항목

| 수집 시점 | 수집 항목 | 수집 근거 |
|-----------|-----------|----------|
| 회원가입 시 | 이메일 주소, 비밀번호(해시 처리) | 동의 (개인정보보호법 제15조 제1항 제1호) |
| 서비스 이용 시 | 서비스 이용 기록, 접속 로그, 접속 IP, 브라우저 종류 | 동의 (개인정보보호법 제15조 제1항 제1호) |

#### 선택 수집 항목

| 수집 시점 | 수집 항목 | 수집 근거 |
|-----------|-----------|----------|
| 투자 프로필 설정 시 | 투자 경험, 투자 목표, 위험 성향, 투자 기간, 관심 섹터, 투자 금액 범위, 선호 분석 방법, 투자 빈도 (8문항 응답) | 동의 (개인정보보호법 제15조 제1항 제1호) |
| 포트폴리오 등록 시 | 보유 종목 코드, 보유 수량, 매입 단가, 매입일 | 동의 |
| 브로커 연동 시 | 브로커 API 인증 토큰 (Alpaca, KIS) | 동의 |
| 유료 구독 결제 시 | 결제 수단 정보 (PG사 통해 처리, 회사 직접 보관하지 않음) | 동의 |

### 2. 수집 방법

- 웹 애플리케이션 회원가입 및 서비스 이용 과정에서 이용자가 직접 입력
- 서비스 이용 과정에서 자동 수집 (접속 로그, 이용 기록 등)

### 3. 수집하지 않는 항목

회사는 다음 항목을 수집하지 않습니다.
- 주민등록번호, 여권번호 등 고유식별정보
- 건강 정보, 범죄 경력 등 민감정보
- 신용카드 번호, 은행 계좌번호 (PG사에서 직접 처리)

회사는 수집한 개인정보를 다음 목적으로 이용합니다.

| 이용 목적 | 상세 내용 | 관련 수집 항목 |
|-----------|----------|---------------|
| 회원 관리 | 회원 식별, 가입/탈퇴 처리, 본인 확인 | 이메일, 비밀번호 |
| 퀀트 분석 서비스 제공 | 개인화된 퀀트 시그널 생성, 포트폴리오 분석 | 투자 프로필, 포트폴리오 데이터 |
| AI 코칭 서비스 제공 | AI 기반 투자 교육 콘텐츠 생성, SWOT 분석 | 투자 프로필, 포트폴리오 데이터 |
| 자동매매 서비스 제공 | 브로커 연동 주문 실행 | 브로커 API 토큰, 매매 주문 정보 |
| 서비스 개선 | 서비스 이용 통계 분석, 신규 기능 개발 | 서비스 이용 기록, 접속 로그 |
| 고객 지원 | 문의 사항 처리, 공지사항 전달 | 이메일 |
| 유료 서비스 제공 | 구독 관리, 결제/환불 처리 | 결제 관련 기록 |

## 제3조 (개인정보의 제3자 제공)

회사는 원칙적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만, 다음의 경우 이용자의 동의를 받아 제공합니다.

| 제공받는 자 | 제공 목적 | 제공 항목 | 보유 기간 | 소재국 |
|------------|----------|----------|----------|--------|
| Anthropic (Claude API) | AI 분석/코칭 텍스트 생성 | 투자 프로필 요약, 포트폴리오 요약 정보, 이용자 질의 내용 | API 처리 완료 시 즉시 삭제 (Anthropic 정책에 따름) | 미국 |
| Financial Modeling Prep | 시세/재무 데이터 조회 | 종목 코드 (개인정보 미포함) | 해당 없음 | 미국 |
| Alpaca Markets | 미국 주식 주문 실행 | 매매 주문 정보, API 인증 토큰 | 브로커 정책에 따름 | 미국 |
| 한국투자증권 (KIS) | 한국 주식 주문 실행 | 매매 주문 정보, API 인증 토큰 | 브로커 정책에 따름 | 한국 |

또한 다음의 경우 이용자의 동의 없이 제3자에게 제공할 수 있습니다.
- 법령에 특별한 규정이 있는 경우
- 수사 목적으로 법원, 검찰, 수사기관의 적법한 절차에 의한 요청이 있는 경우

## 제4조 (개인정보 처리 위탁)

회사는 서비스 제공을 위해 다음과 같이 개인정보 처리 업무를 위탁하고 있습니다.

| 수탁업체 | 위탁 업무 | 소재국 |

## 제5조 (개인정보의 국외 이전)

회사는 서비스 제공을 위해 다음과 같이 개인정보를 국외로 이전합니다.

| 이전받는 자 | 이전 국가 | 이전 항목 | 이전 목적 | 이전 방법 | 보유 기간 |
|------------|----------|----------|----------|----------|----------|
| Anthropic | 미국 | 투자 프로필 요약, 포트폴리오 요약 | AI 분석/코칭 | HTTPS 암호화 전송 | 처리 완료 시 즉시 |
| Alpaca Markets | 미국 | 매매 주문 정보 | 주식 주문 실행 | HTTPS 암호화 전송 | 브로커 정책 |
| Vercel Inc. | 미국 | 접속 로그 | 웹 호스팅 | HTTPS 암호화 전송 | 서비스 이용 기간 |
| Railway Corp. | 미국 | 서비스 이용 데이터 | 서버 호스팅 | HTTPS 암호화 전송 | 서비스 이용 기간 |
| Supabase Inc. | 미국/싱가포르 | 전체 이용자 데이터 | 데이터베이스 | HTTPS 암호화 전송 | 서비스 이용 기간 |

이용자는 회원가입 시 개인정보의 국외 이전에 동의하며, 동의를 거부할 권리가 있습니다. 다만, 동의를 거부하는 경우 서비스 이용이 제한될 수 있습니다.

## 제6조 (개인정보의 보유 및 이용 기간)

### 1. 원칙

회사는 개인정보의 수집 및 이용 목적이 달성된 후에는 해당 정보를 지체 없이 파기합니다.

### 2. 회원 탈퇴 시

회원 탈퇴 요청 시 개인정보는 즉시 삭제합니다. 다만, 다음의 정보는 관련 법령에 따라 일정 기간 보관 후 파기합니다.

| 보관 항목 | 보관 기간 | 근거 법령 |
|-----------|----------|----------|
| 계약 또는 청약 철회 등에 관한 기록 | 5년 | 전자상거래법 제6조 |
| 대금 결제 및 재화 등의 공급에 관한 기록 | 5년 | 전자상거래법 제6조 |
| 소비자의 불만 또는 분쟁 처리에 관한 기록 | 3년 | 전자상거래법 제6조 |
| 표시/광고에 관한 기록 | 6개월 | 전자상거래법 제6조 |
| 접속에 관한 기록 | 3개월 | 통신비밀보호법 제15조의2 |
| 전자금융거래에 관한 기록 | 5년 | 전자금융거래법 제22조 |

### 3. 장기 미이용 회원

1년 이상 서비스를 이용하지 않은 회원의 개인정보는 별도의 데이터베이스로 분리하여 보관하거나 파기합니다. 분리 보관 시 해당 회원에게 사전에 이메일로 통지합니다.

## 제7조 (개인정보의 파기 절차 및 방법)

### 1. 파기 절차

수집 목적이 달성되거나 보유 기간이 경과한 개인정보는 별도의 데이터베이스로 옮겨져 내부 방침 및 관련 법령에 따라 일정 기간 저장된 후 파기됩니다.

### 2. 파기 방법

- 전자적 파일: 복구 불가능한 방법으로 영구 삭제
- 종이 문서: 분쇄기를 이용하여 파쇄 (해당 시)

---

## 제8조 (정보주체의 권리와 행사 방법)

이용자(정보주체)는 다음의 권리를 행사할 수 있습니다.

### 1. 권리 목록

| 권리 | 내용 | 근거 |
|------|------|------|
| 열람 요구권 | 회사가 보유한 본인의 개인정보 열람 요구 | 개인정보보호법 제35조 |
| 정정 요구권 | 개인정보의 오류에 대한 정정 요구 | 개인정보보호법 제36조 |
| 삭제 요구권 | 개인정보의 삭제 요구 | 개인정보보호법 제36조 |
| 처리정지 요구권 | 개인정보의 처리 정지 요구 | 개인정보보호법 제37조 |
| 동의 철회권 | 개인정보 수집/이용에 대한 동의 철회 | 개인정보보호법 제15조 |

### 2. 행사 방법

- 서비스 내 설정 화면에서 직접 열람, 정정, 삭제 가능
- 이메일([고객센터 이메일])을 통한 서면 요청
- 요청 접수 후 지체 없이 (최대 10일 이내) 조치 결과를 통지합니다.

### 3. 유의 사항

- 법령에 따라 보존이 의무화된 개인정보는 삭제 요구에도 불구하고 해당 기간 동안 보관됩니다.
- 정정/삭제 요청 시 해당 정보를 이용 또는 제공하지 않으며, 잘못된 개인정보가 제3자에게 이미 제공된 경우 제3자에게 지체 없이 통지하여 정정/삭제 조치합니다.

## 제9조 (개인정보의 안전성 확보 조치)

회사는 개인정보보호법 제29조에 따라 다음과 같은 안전성 확보 조치를 취하고 있습니다.

### 1. 관리적 조치

- 개인정보 처리 담당자 최소화
- 정기적인 개인정보 보호 교육 실시

### 2. 기술적 조치

| 조치 항목 | 적용 현황 | 상세 |
|-----------|----------|------|
| 전송 구간 암호화 | 적용 | HTTPS (TLS 1.2 이상) 적용 |
| 비밀번호 암호화 | 적용 | pbkdf2:sha256 해시 알고리즘 적용 |
| 브로커 API 토큰 보호 | 적용 | 환경변수 관리, 서버사이드 저장 |
| 접근 권한 관리 | 적용 | 데이터베이스 접근 권한 제한 |
| SQL 인젝션 방지 | 적용 | ORM(SQLAlchemy) 사용 |
| XSS 방지 | 적용 | React 자동 이스케이프 |

### 3. 물리적 조치

- 클라우드 서비스 이용 (Vercel, Railway, Supabase) -- 각 서비스의 물리적 보안 정책 적용

---

## 제10조 (쿠키의 사용)

### 1. 쿠키 사용 목적

회사는 이용자에게 개인화된 서비스를 제공하기 위해 쿠키(Cookie)를 사용할 수 있습니다.
- 세션 관리 및 로그인 상태 유지
- 서비스 이용 편의 제공

### 2. 쿠키 거부 방법

이용자는 웹 브라우저 설정을 통해 쿠키 저장을 거부할 수 있습니다. 다만, 쿠키 저장을 거부하는 경우 로그인이 필요한 서비스 이용이 제한될 수 있습니다.

---

## 제11조 (만 14세 미만 아동의 개인정보)

회사는 만 14세 미만 아동의 회원가입을 제한하며, 만 14세 미만 아동의 개인정보를 수집하지 않습니다.

## 제12조 (개인정보 보호 책임자)

## 제14조 (개인정보처리방침의 변경)

1. 본 개인정보처리방침은 시행일로부터 적용됩니다.
2. 개인정보처리방침이 변경되는 경우 변경 내용과 시행일을 서비스 내 공지사항을 통해 공지하며, 변경된 방침은 공지한 시행일부터 효력이 발생합니다.
3. 이용자에게 불리한 변경의 경우 최소 7일 전에 공지하며, 이메일 등 개별 통지합니다.

---

## 부칙

1. 본 개인정보처리방침은 2026년 __월 __일부터 시행합니다.
