# Pivox 인스타그램 고정 게시물 3개

세 제품을 **같은 구성**으로 만든 6장짜리 캐러셀(1080×1350, 4:5)이에요. 표지는 세 랜딩 첫 화면과 같아요:
검은 바탕, 은은한 스폿 조명, Playfair 500 대문자 워드마크(자간 0.22em), `PIVOX` 는 아이보리, 제품명은 브론즈.

| 장 | 내용 |
|---|---|
| 01 | 표지: 랜딩 첫 화면과 같은 워드마크 + 한 줄 설명 + `PIVOX 0n · 태그` |
| 02 | 무엇인가: 한 문장 정의 |
| 03 | 왜 필요한가: 출처 줄 포함 |
| 04 | 어떻게 쓰나: 3단계 |
| 05 | 원칙: 하지 않는 것, 데이터를 다루는 방식, 믿을 수 있는 이유 |
| 06 | 주소, 상태, 그리고 세 제품을 잇는 줄 |

스토리라인: **나의 거래(Quant) → 회사의 데이터(Map) → 산업의 변화(Data). 흘려보내지 않고 숫자로 봅니다.**
6장마다 하단에 세 제품 워드마크를 같이 넣어, 어느 게시물을 봐도 다른 두 제품으로 넘어갈 수 있게 했어요.

다시 만들기: `node docs/marketing/instagram/pinned/build.cjs [quant|map|data]` (문구는 파일 위쪽 `PRODUCTS` 한 곳)

## 고정 순서

인스타그램은 **나중에 고정한 게시물이 맨 왼쪽**에 와요. 그리드에 `QUANT | MAP | DATA` 순으로 놓으려면:

1. 03 Data 게시 → 고정
2. 02 Map 게시 → 고정
3. 01 Quant 게시 → 고정

## 프로필 소개 (예시)

```
Pivox — 흘려보내지 않고 숫자로 봅니다
나의 거래 · PivoxQuant
회사의 데이터 · PivoxMap
산업의 변화 · PivoxData
```
링크는 하나만 걸 수 있으니 링크 모음(인스타 '링크 추가'에서 최대 5개)에 세 주소를 넣어 주세요.

## 캡션

### 01 PivoxQuant

```
사기 전에 한 번 멈추고, 이유를 적고, 나중에 돌아봅니다.

PivoxQuant는 개인 투자 기록 도구예요.
① 멈춤: 사기 전, 일곱 가지 질문에 답하며 이유를 적어요
② 기록: 산 이유와 사려다 만 이유가 한자리에 남아요
③ 거울: 처음에 적은 '내 방식'과 최근 30일 실제 거래의 간극을 보여 줘요

점수도, 종목 고르기도, 사라·팔라는 신호도 없습니다.
미국·한국 주식 · 클로즈드 베타 · 무료
🔗 pivoxquant.com

관측 자료이며 투자 권유가 아닙니다.

#투자기록 #투자일지 #매매일지 #주식기록 #개인투자자 #PivoxQuant
```

### 02 PivoxMap

```
같은 '등록일자'가 파일마다 다른 이름으로. REG_DT, 등록일, CRT_DATE…

PivoxMap은 표준 사전과 파일을 올리면 컬럼마다 표준용어를 제안해요.
① 자동 확정: 확신 있는 건 바로 붙이고, 애매한 것만 사람이 승인
② 쌓이는 사전: 승인·수정이 동의어로 쌓여 다음 파일부터 자동으로
③ 증빙까지: 리포트·CSV, 평가 증빙 xlsx 내보내기

파일은 브라우저 안에서 읽어요. 서버로 가는 건 컬럼명과 값의 형식뿐, 원본 값은 0.
🔗 map.pivoxquant.com

#데이터표준화 #데이터품질 #공공데이터 #표준용어 #메타데이터 #PivoxMap
```

### 03 PivoxData

```
기사보다 먼저 움직이는 숫자가 있어요.

PivoxData는 기업의 AI 전환(AX)을 매일 같은 방식으로 숫자로 보는 레이더예요.
① 평소보다 얼마나: 크기보다 커지는 속도로 줄 세우기
② 누가 앞서나: 분야마다 1위가 바뀌는 순간
③ AX 사건: 회사·정부가 직접 낸 발표만, 원문 링크와 함께

npm · PyPI · arXiv · Hugging Face · SEC 공개 데이터, 검산이 어긋나면 갱신하지 않아요.
매일 갱신 · 무료
🔗 data.pivoxquant.com

#AX #AI전환 #AI트렌드 #데이터 #오픈소스 #PivoxData
```
