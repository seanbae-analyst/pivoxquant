# 5. Go-To-Market 전략

## 타겟 유저 페르소나

### A: "주식 입문 직장인" — 김민수 (29세)
- 투자 경력 1~2년, 삼성전자/카카오 물려있음
- 유튜브/리딩방에 휘둘려 손실
- **니즈**: "내가 산 게 맞는지" 확인
- **지불 의향**: 월 1만원 이하
- **채널**: 블라인드, 네이버 주식 카페

### B: "데이터 지향 투자자" — 이지현 (34세)
- 투자 3~5년, 미국주식 60%
- 퀀트 관심 있지만 환경 구축 귀찮음
- **니즈**: 팩터별 점수 직접 보고 판단
- **지불 의향**: 월 2만원
- **채널**: 퀀트 오픈카톡, GitHub, X(트위터)

### C: "미국주식 입문 MZ" — 박서연 (25세)
- 투자 6개월 미만, 테슬라 1~2주
- 영어 리포트 읽기 어려움
- **니즈**: AI가 쉬운 말로 설명
- **지불 의향**: 무료 → 9,900원
- **채널**: 틱톡, 에브리타임, 인스타
