# 7. 법적 요건 + 규제 대응

## 핵심 법적 쟁점

### 투자자문업 등록 여부

**자본시장법 제7조**: 투자자문업 = 금융투자상품의 투자판단에 관한 자문

**StockPilot 리스크**: 퀀트 시그널 + AI 코칭이 "투자자문"으로 해석될 여지 있음

**대응 전략**: "정보 제공 서비스"로 포지셔닝

### FINT와의 규제 차이

| 항목 | FINT | StockPilot |
|------|------|------------|
| 유형 | 투자일임업 (돈 직접 운용) | 정보 제공 (분석 도구) |
| 등록 | 투자일임업 + 투자자문업 등록 | 등록 불필요 (정보 제공) |
| 규제 수준 | 금융위/금감원 직접 감독 | 통신판매업 수준 |
| 자기자본 요건 | 수억원 | 없음 |
| 자동매매 | AI 완전 자동 | 유저 승인 기반 반자동 (핵심!) |

> **"유저 승인 기반 반자동" 유지 필수**: 완전 자동매매로 전환하면 투자일임으로 분류될 위험 급증.

## 즉시 실행 (런칭 W3)

| 액션 | 상세 |
|------|------|
| 면책 문구 | 모든 분석 화면: "본 서비스는 투자자문이 아니며, 투자 판단의 책임은 이용자에게 있습니다" |
| UI 워딩 점검 | "추천" → "시그널", "해야" → "시사점", "반드시" → "참고" |
| 이용약관 | 서비스 성격, 면책, 구독/결제/환불 정책 |
| 개인정보처리방침 | PIPA 준수, 수집 데이터 명시 |

## 1~3개월 내

| 액션 | 상세 |
|------|------|
| 사업자등록 | 통신판매업 + 소프트웨어 개발업 |
| 금감원 문의 | 핀테크 혁신지원, 규제 샌드박스 가능 여부 |
| 변호사 자문 | 초기 상담 1회 (30~50만원) |

## 3~6개월 (MAU 1,000명+)

| 액션 | 상세 |
|------|------|
| 투자자문업 등록 검토 | 요건: 자기자본 1억, 전문인력 1명 |
| 혁신금융서비스 | 금융위 규제 샌드박스 신청 (2년 유예) |
| 개인정보보호 책임자 | 1,000명 이상 보유 시 필수 |
