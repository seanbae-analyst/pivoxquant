# 1. Executive Summary

## 한 줄 정의

> StockPilot은 유저의 투자 성향에 맞춰 자동 조정되는 AI 퀀트 분석 플랫폼이다.

## 핵심 메시지

**"같은 주식, 다른 분석"** — 증권사 앱은 모든 사람에게 같은 차트를 보여주지만, StockPilot은 당신의 투자 성향을 이해하고 같은 종목도 당신에게 맞게 분석한다.

## 문제

1. 개인투자자의 70%가 시장 수익률을 밑돈다 (DALBAR 연구)
2. 기존 증권사 앱: 모든 유저에게 동일한 차트/지표, 개인화 없음
3. 로보어드바이저(FINT 등): 블랙박스 운용, 높은 수수료(연 9.5%+), 개별 종목 분석 불가
4. 퀀트 도구(Quantconnect 등): 코딩 필수, 초보자 접근 불가

## 솔루션

- **8문항 온보딩** → 유저 리스크 프로필 자동 파악
- **22개 팩터 퀀트 엔진** → 기술/펀더멘탈/센티멘트/퀀트 모델 종합 분석
- **5개 전략 프로필** → 시장 환경에 따라 자동 전환 (Trend Rider → Survival)
- **AI 코칭** → Claude AI가 유저 수준에 맞춰 설명
- **자동매매** → 유저 승인 기반 반자동 실행 (한국/미국 주식)
