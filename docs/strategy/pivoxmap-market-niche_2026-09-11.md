## 0. 한 줄 결론

**PivoxMap 의 시장은 "데이터 카탈로그"가 아니라 "연 1회 마감이 있는 규제 대응"이다.**
행안부가 공공데이터법 §22 로 **679개 기관**(2024년 기준)을 매년 진단·평가하고, 그 진단 항목에
**"공통표준용어 기준으로 비표준 데이터 매핑 정보를 관리하고 있는지"** 가 **전년 대비 추가**됐다.
PivoxMap 의 `평가 증빙 내보내기(xlsx)` 는 **바로 그 항목의 산출물을 만든다.** 이건 우연한 인접이 아니라 정조준이다.

**하지만 진짜 위험은 경쟁자가 아니라 구매 방식이다.** 이 시장은 현재 **솔루션이 아니라 용역(컨설팅)으로 팔린다** —
검색에 걸린 공급자 다수(에이오디컨설팅, 다우콘, KMAC, 엔코아)가 "평가 대응 **컨설팅**"을 판다.
679개 기관이 매년 사람을 사서 해결하고 있다면, PivoxMap 은 기관에 파는 제품이 아니라
**컨설팅사에 파는 도구(B2B2G)** 여야 한다. 이 질문에 답하기 전엔 아무것도 짓지 마라 (§4 죽이는 질문).

**한국 현실 파일에 대한 커버리지가 이 제품의 숨은 자산이다.** 확장자가 아니라 **내용**으로 판단한다 —
확장자만 `.xls` 인 EUC-KR HTML 표, 엑셀 XML 스프레드시트 2003, ODS, XLSB, 보고서형 시트(제목·작성일 줄 건너뛰기),
통계 연보형 시트(단위 줄·영문 번역 줄 건너뛰고 **병합된 윗단 헤더를 열 이름에 이어 붙임**), 암호·DRM·한셀은 이유를 말하고 멈춤.
**이건 논문이 아니라 삽질의 결과물이고, 후발주자가 베끼기 가장 비싼 부분이다.**

## 2. 진짜 시장 — 숫자와 근거

| 사실 | 값 | 출처 |
|---|---|---|
| 법적 근거 | **공공데이터법 §22**(공공데이터의 품질관리) | 행정안전부 |
| 평가 대상 | 2016~17 국가중점 63개 DB → 2018 중앙행정기관 → 2019 지자체 → 2020 공공기관 → 2023 시도교육청 → **2024년 679개 기관** | 행안부 / data.go.kr |
| 핵심 진단 항목 | **"공통표준용어 기준으로 비표준 데이터 매핑 정보를 관리하고 있는지 진단하기 위하여 전년 대비 추가"** | data.go.kr 품질 안내 |
| 공통표준용어 규모 | 포털 기준 **누적 9,027개** / 행안부 배포 파일은 **13,176행**(2025-11 8차, 폐기 포함) | data.go.kr / 레포 bench README |
| 매뉴얼 | 2023년 공공데이터 품질관리 수준진단·평가 매뉴얼 (PDF 공개) | cisp.or.kr |

**이 시장의 성질이 중요하다:**
- **반복 수요** — 매년 평가. 한 번 팔고 끝이 아니다.
- **마감이 있는 고통** — 평가 일정이 정해져 있다. 마감은 지불 의사를 만든다.
- **산출물이 명확** — 매뉴얼이 양식을 정해 놨다. "좋은 제품"이 아니라 "이 표를 내놓는 것"이 요구사항이다.
- **679개라는 유한하고 열거 가능한 고객 목록** — 1인 창업자가 다룰 수 있는 크기다. 리스트가 공개돼 있다.

> 이건 PivoxQuant(개인 유저·무료 베타·지불 의사 미확인)와 **정반대 성질**의 시장이다. 좋은 쪽으로.

## 3. 경쟁 — 세 겹

**① 국내 표준화 솔루션 (정면)**
- **엔코아 `DA#` / `DQ#` / `DATAWARE`** — 국내 데이터 표준화의 사실상 표준. `DA# Workgroup Contents Builder Edition` 은
  **"패키지 표준사전 + 자동표준분석기"** 를 내세우고, **"기존 표준사전 없이 DB 카탈로그 스키마 테이블/컬럼 정보로 표준사전 구축"** 이라고 광고한다.
  → **PivoxMap 의 `from-columns`(첫 파일이 사전이 된다)와 기능 주장이 겹친다.** 다만 **DA# 는 DB 스키마·모델링 대상**이고
  **PivoxMap 은 파일 대상**이다. 이 차이가 §4 의 틈이다.
- **위세아이텍 WiseDQ · 비아이엔(b2en) · KMAC K-DQMS(DQ 인증)** — 품질·인증 쪽.

**② AI 신규 진입 (가장 가까움)**
- **데이터클리닉 (페블러스, `dataclinic.ai`)** — *"기관 내부의 규칙과 패턴을 학습하며, 아직 표준화되지 않은 데이터를 찾아내고
  데이터 구조를 일정하게 맞추며 정제"*. **표준용어 자동 매핑을 명시적으로 판다.** 블로그로 이 키워드 SEO 를 이미 하고 있다
  (`/blog/public-data-quality-management-stage`, `/blog/public-data-quality-tool`).
  → **가장 직접적인 경쟁자.** 제품을 직접 써 보지 않았다 — **미검증**.
- **우리데이터** — 공공데이터 'AI-Ready' 자동 전환 솔루션 (보도 1건만 확인, 미검증).

**③ 컨설팅 (실제로 예산을 먹는 쪽)**
- **에이오디컨설팅(아이큐) · 다우콘(dacon.kr) · 엔코아 데이터 컨설팅 · KMAC** — 전부 "평가 대응 컨설팅"을 판다.
- **나라장터 실제 발주 건수·금액은 확인 못 했다** (§4 죽이는 질문이 여기 걸려 있다).

**④ 글로벌 (지금은 무관, 나중에 위협)**
Informatica **CLAIRE**(사용자 수정으로 학습하는 스키마 매칭) · Fivetran(스키마 드리프트 자동 대응) ·
DataFlowMapper · Energent.ai · integrate.io. *"과거 매핑 수백만 건으로 학습해 85~95% 정확도"* 로 광고한다(벤더 주장).
→ **한국 공통표준용어·평가 양식·한글 조사 처리라는 규제 특화가 사라지면 차별화가 0 이 된다.** 이게 §5 의 전략적 제약이다.

|---|---|---|---|

### 죽이는 질문 (이거 하나만 먼저 답해라)

> **"679개 기관은 솔루션을 사는가, 용역을 사는가?"**

- **용역을 산다면** → PivoxMap 은 기관에 파는 SaaS 가 아니라 **컨설팅사·SI 에 파는 도구**다 (B2B2G).
  고객이 679개가 아니라 **10~20개 컨설팅사**로 바뀌고, 가격·영업·제품 우선순위가 전부 달라진다.
  (컨설턴트에게 필요한 건 예쁜 UI 가 아니라 **증빙 xlsx 대량 생성과 이력**이다 — 둘 다 이미 있다.)
- **솔루션을 산다면** → 조달 등록(나라장터)·보안성 심사·공공 레퍼런스 1호가 진짜 관문이다.

**재는 법 (코드 짜기 전, 하루면 된다):** 나라장터에서 최근 2년 `공공데이터 품질관리`·`데이터 표준화` 용역 공고를
검색해 **건수 · 평균 금액 · 낙찰 업체**를 세라. 용역 공고가 수십 건인데 솔루션 구매 공고가 0 이면 답이 나온 것이다.

## 5. 위험 — 먼저 말해 둘 것

1. **1인 vs 조달.** 공공 조달은 제품 품질이 아니라 **자격**(업체 등록·실적·보안성 심사)으로 거른다. 1인 기업의 최대 장벽이고, §4 죽이는 질문이 "용역"으로 답하면 **오히려 우회로가 된다**(컨설팅사가 자격을 갖고 있다).
2. **LLM 층이 켜지면 원가와 심사가 같이 온다.** `PIVOXMAP_LLM_PROVIDER=anthropic` 은 **기관 데이터의 컬럼명·설명을 외부 API 로 보낸다.** 값은 안 가지만 **컬럼명 자체가 민감할 수 있다**(사업명·부서명·사업자 식별). 공공기관 계약서에 걸리는 항목이다. → 지금 `file` 공급자로 코드 경로를 분리해 둔 설계는 옳다. **"LLM 끄고도 자동확정 오답 0, 69%" 라는 측정이 영업 자산**이니 이 조건을 기본값으로 유지하고 명시적으로 팔아라.
3. **PivoxQuant 의 Anthropic 국외 이전 이슈가 여기서 반복된다.** `SHIP_BLOCKERS.md` R0 과 같은 종류의 문제다 — 개인정보처리방침·계약서에 국외 이전을 **먼저** 적어라. PivoxQuant 에서 이미 한 번 겪었다.
4. **자기채점 숫자를 영업에 쓰지 마라.** 99% 는 정답표와 답을 같은 주체가 쓴 상한선이다. **밖에 말할 수 있는 숫자는 눈가리개 85.5%(69쌍)와 자동확정 오답 0 뿐이다.** 레포가 스스로 그렇게 경고하고 있다 — 그 규율을 마케팅까지 끌고 가라.
5. **두 제품 동시 운영.** PivoxQuant(개인·무료·바이럴)와 PivoxMap(기관·유료·영업)은 판매 방식이 반대다. 1인이 둘 다 하면 컨텍스트 스위칭에서 진다. **어느 쪽이 본진인지는 시장이 아니라 CEO 가 정할 문제다.**

## 8. 실측 보강 (2026-09-12) — 죽이는 질문에 1차 자료로 답이 나왔다

> 이 절은 §2·§3·§4·부록 B 를 **덮어쓴다**. 앞 절의 틀린 부분은 아래에 명시한다.

### 8-1. 죽이는 질문: **용역을 산다** (1차 자료 1건 + 정황 3건)

**1차 자료 — 부산광역시 미래기술전략국 『2026년 주요업무계획』(2026-01-29 기획재경위원회 보고, 46p, 국회도서관 CLIK 소장 PDF) p.28:**

```
○ 공공데이터 제공·운영실태/품질관리 평가 추진 ▹ ‘26.6.~10.
  - (근거) 공공데이터법 제9조, (주관) 행정안전부, (평가) 3개 영역, 10개 지표
○ 공공데이터 품질 진단실시 및 품질개선 용역 추진 ▹ ‘26.6.~10., 0.5억원
  - 정보시스템원천데이터개방에 대비한 정보시스템DB품질 진단실시
```

**광역시 한 곳이 평가 대응을 `용역` 으로 5,000만원, 5개월(6~10월)에 발주한다.** 평가 일정과 용역 일정이 **같은 달에 시작해 같은 달에 끝난다** — 용역이 평가 대응 그 자체라는 뜻이다.

정황 3건(2차, 공고 제목·기간만 확인, 금액 미확인):

| 발주기관 | 사업명 | 기간 |
|---|---|---|
| 군산시 | 공공데이터 품질관리 컨설팅사업 | 2026-05-01 ~ 2026-08-31 |
| 국립중앙의료원 | 공공데이터 수준평가 대응 컨설팅사업 | 2026-07-01 ~ 2026-09-30 |
| 한국농어촌공사 | 2025년 공공데이터 및 데이터기반행정 활성화 컨설팅 용역 (공고 `R25BK00737754-000`) | 입찰 2025-05-07 |

**→ §4 의 판정을 바꾼다. 1순위 고객은 679개 기관이 아니라 컨설팅사다 (B2B2G).**
확인된 공급자 **7곳**: 에이오디컨설팅(아이큐) · 다우콘 · 한국리버스컨설팅 · 그루텍 · Next I&I · 토브업 · KMAC(교육).

**결정적 근거 — 경쟁사가 이미 PivoxMap 의 산출물을 판다.** 에이오디컨설팅 서비스 페이지(직접 읽음):
3단계 중 1단계 *"기관별 진단 지표 20개 항목 체크리스트 작성"*, 2단계 *"AI 기반 데이터 오류 진단 솔루션 적용"*,
3단계 ***"평가기관이 요구하는 표준화된 보고서 및 증빙자료 패키지 제공"***.
→ **증빙자료 패키지는 이미 상품이다.** PivoxMap 의 차별점은 "증빙을 만든다"가 아니라 **"사람 손 대신 만든다 + 원본 값을 안 보낸다 + 결정 이력이 남는다"** 여야 한다.
단 같은 페이지에서 **표준용어 매핑은 품질평가 컨설팅에 포함되지 않고 별도 "메타데이터" 항목**으로 분리돼 있다 — **§4-2 의 틈(파일 대상 표준용어 매핑)은 아직 살아 있다.**

### 8-2. 시장이 커지는 속도 — 이게 이 제품의 존재 이유다

행안부 공통표준용어 개수 (전자신문 2025-12-23 기사 직접 읽음):

| 시점 | 공통표준용어 |
|---|---|
| 2020 | **535개** |
| 2025-01 (행안부 카드뉴스) | "9,000개 이상" |
| 2025 확정 (4,132개 추가) | **13,159개** |

**5년에 24.6배.** 그리고 행안부는 이걸 문서가 아니라 **오픈포맷(CSV·JSON·XML)과 API 로 개방**하며,
목표를 *"기계가 읽기 쉬운 형태로 제공해 **AI 가 데이터 표준을 자동 학습하고 점검**할 수 있는 환경을 마련"* 이라고 못 박았다
(이세영 인공지능정부정책국장: *"공통표준용어 확대와 기계 판독할 수 있는 형식의 개방으로 공공과 민간이 데이터를 쉽게 연계할 수 있을 것"*).

**두 가지 함의:**
1. **13,159개 × 수천 컬럼을 사람이 눈으로 맞추는 건 이미 불가능하다.** 이게 PivoxMap 의 시장이다 — 정책이 만들어 준다.
2. **사전을 파일로 올릴 필요가 없어진다.** 지금 PivoxMap 은 사전 업로드가 1단계인데, 행안부가 API 를 열었으므로
   **`공통표준용어 최신판 자동 동기화`** 가 가능하다. 경쟁사의 "패키지 제공"이 못 하는 일이고, 온보딩 1단계를 통째로 없앤다. **다음 기능 후보 1순위.**

또한 §1 의 개수 불일치가 해소됐다: bench 의 `13,176행`(2025-11 8차, 폐기 포함) ≈ **13,159개 확정 + 폐기 행**. 모순이 아니다.
