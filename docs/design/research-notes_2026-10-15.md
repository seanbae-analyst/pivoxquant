> 화면: `/journal/research` (기록의 하위 화면) · 기록 화면 진입 줄 · 포트폴리오 관찰 노트 창의 링크 · `/pre-trade` 읽기 전용 블록

## 0. 왜

- CEO 2026-10-15: "리서치한 내용을 적게 하고 평가하는 식" → "리서치 양식을 만들어 주고 기입하게".
- 일반 개인투자자는 분석보다 **남의 결론을 모아서** 산다. 서울신문·리멤버 리서치 조사(2026-08, 30·40대 1,005명): 투자정보 출처 증권사 보고서 41.9% · 영상 29.7%; "주식정보 취득처"로 물으면 SNS·지인 16.2% · AI 15.6% · 보고서 14.6%. 빈 리서치 페이지는 비거나 "유튜브에서 봄" 한 줄이 된다.
- 그래서 **모든 종목에 같은 짧은 양식**이 "이것만은 직접 보라"는 가이드가 된다. 새 가치는 적기가 아니라 **정한 날 채점**이다 — 멈춤 7문항 Q1(이유)·Q2(틀린 선)과 적는 일은 겹치지만, 7문항은 사는 순간의 행동(감정·크기·계획)을 묻고 이 양식은 회사를 묻는다.
- 베타 질문("기록을 하긴 하는가 / 다시 보러 오는가")에 서버 데이터로 답한다 (월급날 배분과 반대).

## 1. 양식 (모든 종목 동일)

| # | 칸 | 필수 | 캡 |
|---|---|---|---|
| 1 | 이 회사는 뭘로 돈을 버나 | ✅ | 300 |
| 2 | 내가 보는 이유 (1~3개) | ✅ | 각 300 |
| 3 | 이게 보이면 틀린 것 | | 500 |
| 4 | 가장 큰 위험 하나 | | 500 |
| 5 | 직접 확인한 숫자 (비우면 "안 봄") | | 1000 |
| + | 어디서 알게 됐나: 리포트 / 유튜브 / 지인·SNS / AI / 직접 분석 | | — |
| + | 다시 볼 날: 1·3·6개월 (기본 3) → KST 날짜, 말일 보정 | | — |

- **우리가 채우는 것 없음**: 종목 정보·뉴스·재무 숫자·종목별 안내 없음 (자본시장법 §6 투자자문 경계, FMP §2.2.2 Display Agreement 미체결). 시세를 부르지 않는다. 플레이스홀더는 어느 회사도 가리키지 않는 일반 예시.
- **저장 후 수정 없음, 삭제만** (관찰 노트와 같은 정책 — 고칠 수 있는 기록은 거울이 아니다).

## 2. 채점

- 다시 볼 날이 되면 `/journal/research` 맨 위 "다시 볼 리서치"에 채점이 열린 채로 뜬다. 기록 화면 진입 줄에 "다시 볼 것 N개". 날 전에도 "지금 채점하기"로 가능.
- **채점은 한 번만** (서버가 두 번째를 400 으로 거절). 저장하면 카드에 본인 체결 손익이 보이므로, 다시 채점하게 두면 그 손익을 본 뒤의 판단이 된다 — legal-kr-fintech 에이전트 검토 2026-10-15(변호사 확인 전).
- 이유마다 **맞음 / 틀림 / 모름** + 한 줄(선택).
- **채점하는 동안 실제 손익을 보여 주지 않는다** — "판 뒤 이익"을 먼저 보면 돈으로 이유를 판단하게 된다(결과 편향). 저장한 뒤에 카드에 나온다.

## 3. 결과 = 본인 체결만

- 그 종목을 **리서치를 쓴 날(날짜 단위) 이후 판 기록**이 있으면 그 매도들의 실현 손익 합의 부호 → 판 뒤 이익 / 손실 / 본전. 없으면 "아직 안 팖". 등록용 행(holding_seed/adjust) 제외.
- 보유 중 평가손익은 쓰지 않는다 (시세 → 3축 규칙). 읽기 시점에 계산하고 행에 박지 않는다.
- 요약은 **개수만**: 판단(맞음/틀림) × 결과 표, 모름은 따로 개수, 출처별 맞음/틀림/모름 숫자. 적중률·점수·등급·비율 막대 없음(맞음/전체 막대는 비율 그림이고 출처 순위를 부추긴다 — legal-kr-fintech 에이전트 검토).
- 캡션: 결과는 손익 합계의 **부호**이고, 리서치와 무관하게 산 수량의 매도도 포함하며, 이유가 맞았다는 증거가 아니라고 화면에 적는다.

## 4. 연결

- `/pre-trade`: 종목을 고르면 그 종목 최신 리서치의 이유·틀렸다고 볼 신호를 질문 위에 **읽기 전용**으로 (링크·버튼·폼 없음 — 멈춤이 7문항을 우회하는 통로가 되지 않게, 관찰 노트와 같은 원칙).
  - 2026-10-18 추가(CEO "리서치 가이드가 안 보인다"): 질문이 **시작되기 전**(setup 단계)에만 "회사부터 정리하고 싶다면 · 리서치 양식" 링크 한 줄(`?ticker=` 전달). 질문 단계는 위 원칙 그대로 읽기 전용.
  - 기록 화면 진입 줄은 overview 로딩·실패 중에도 보인다(숨기면 Render 콜드 스타트 내내 양식에 못 들어갔다). 기다리는 건 "다시 볼 것 N개" 숫자뿐.
- 포트폴리오 보유 종목 → 관찰 노트 창에 "리서치 양식으로 쓰기 →" (`?ticker=&name=&from=portfolio`).
- 기록 화면 관찰 노트 작성 아래 진입 줄. 하단 탭은 늘리지 않음(`/journal` subRoutes).
