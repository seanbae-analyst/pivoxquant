## 1. 시작하기

PivoxQuant는 AI + 퀀트(Quantitative Analysis, 통계·수학적 분석) 기반 개인 투자 정보 플랫폼입니다. 미국·한국 주식을 하나의 대시보드에서 분석하고 포트폴리오를 관리할 수 있습니다.

> **법적 고지:** PivoxQuant는 투자 정보를 제공하는 서비스입니다. 모든 분석 결과는 참고용이며, 투자 권유나 조언이 아닙니다. 투자 결정과 그 결과는 전적으로 본인의 책임입니다.

### 베타 접속 방법

1. **pivoxquant.vercel.app** 접속
2. 베타 비밀번호 입력: `***REDACTED***`
3. 로그인 화면으로 이동

### 로그인

현재 **Google** 또는 **카카오** OAuth(소셜 로그인)만 지원합니다. 이메일/비밀번호 방식은 지원하지 않습니다.

- [Google로 로그인] 버튼 클릭 → Google 계정 선택
- [카카오로 로그인] 버튼 클릭 → 카카오 계정 인증

[SCREENSHOT: 로그인 화면 — Google/카카오 버튼]

### 온보딩 설문 (투자 성향 진단)

최초 로그인 후 **20문항 투자 성향 설문**이 진행됩니다. 설문 결과에 따라 8가지 투자자 유형 중 하나가 배정됩니다.

| 투자자 유형 | 설명 |
|-------------|------|
| 패시브 인덱스 추종형 | ETF·인덱스 중심 장기 보유 |
| 꾸준한 축적형 | 정기적 적립식 투자 |
| 가치 투자형 | 저평가 종목 장기 발굴 |
| 리스크 관리 성장형 | 안전 마진 확보 후 성장 추구 |
| 스윙 트레이더 | 수일~수주 단위 중단기 매매 |
| 모멘텀 추종형 | 상승 추세 종목 집중 |
| 매크로 로테이션형 | 경제 사이클에 따른 섹터 이동 |
| 공격적 스캘퍼 | 단기 고빈도 매매 |

투자 성향은 나중에 Settings에서 재설정할 수 있습니다.

## 2. 홈 대시보드

**경로:** `/home`

[SCREENSHOT: 홈 대시보드 전체 화면]

홈은 PivoxQuant의 메인 화면입니다. 로그인 후 가장 먼저 만나는 페이지로, 포트폴리오 현황과 시장 요약을 한눈에 볼 수 있습니다.

### 표시 정보

**인사말 헤더**
- 시간대에 따라 "좋은 아침", "좋은 오후", "좋은 저녁" + 사용자 이름
- 오늘 날짜 (한국어/영어 언어 설정 반영)

**지표 카드 (Metric Cards)**
포트폴리오 핵심 수치 4가지를 카드 형태로 요약합니다. 포지션을 추가하면 자동으로 채워집니다.

**Morning Brief 카드**
오늘의 시장 브리핑 요약 카드. 장이 열리기 전 주요 뉴스와 지표를 간략히 보여줍니다.

**자산 추이 차트 (Equity Chart)**
내 포트폴리오 자산 변화를 시간별로 보여주는 차트입니다. 우측 상단에서 기간을 선택할 수 있습니다.

- 기간 옵션: 1개월(기본값), 기타 기간 선택 가능

[SCREENSHOT: 자산 추이 차트]

**시그널 위젯 + 리스크 위젯**
- 시그널 위젯: 보유 포지션 중 Positive/Negative/Neutral 신호를 받은 종목을 요약 표시
- 리스크 위젯: 포트폴리오 리스크 점수 요약 (샤프 비율, 최대 낙폭, 방어 상태)

**보유 포지션 목록 (Positions List)**
보유 중인 종목 카드 목록. 실시간 가격 업데이트(SSE, Server-Sent Events)가 적용되어 가격이 변경된 종목은 강조 표시됩니다.

### 사용 방법

1. 포트폴리오가 비어 있으면 카드들이 비어 있거나 플레이스홀더 상태로 표시됩니다.
2. `/portfolio`에서 포지션을 추가하면 홈 화면 데이터가 자동으로 채워집니다.
3. 차트 기간을 변경하려면 차트 우측 상단 기간 버튼을 클릭합니다.
4. 포지션 카드를 클릭하면 해당 종목 상세 페이지(`/detail/[ticker]`)로 이동합니다.

## 3. 포트폴리오

**경로:** `/portfolio`

[SCREENSHOT: 포트폴리오 페이지 — 포지션 목록]

내가 보유한 주식 포지션을 직접 입력하고 관리하는 페이지입니다. 수동 입력 방식과 Alpaca 브로커 연동(Settings에서 설정 후) 두 가지가 있습니다.

### 요약 카드

포지션이 1개 이상 있으면 상단에 4개의 요약 카드가 표시됩니다.

| 카드 | 설명 |
|------|------|
| 총 평가금액 | 전체 포지션의 현재 시가 합계. KRW/USD 혼합 보유 시 주통화 기준으로 표시, 보조 통화는 소글씨로 병기 |
| 총 손익 | 매입가 대비 현재 평가금액 차이. 금액과 % 동시 표시 |
| 가용 현금 | Settings에서 설정한 시드머니에서 투자 금액을 뺀 나머지 |
| 시그널 | 보유 종목 중 Positive 신호 / Negative 신호 개수 |

[SCREENSHOT: 포트폴리오 요약 카드 4개]

### 포지션 추가

우측 상단 **[+ 추가]** 버튼을 누르면 포지션 추가 모달이 열립니다.

1. **종목 검색:** 검색창에 티커(예: `AAPL`), 회사명(예: `nvidia`), 한글명(예: `삼성전자`) 입력
2. 드롭다운에서 원하는 종목 선택 → 현재가 자동 조회
3. **수량** 입력 (소수점 허용, 미국 주식의 소수점 매수 지원)
4. **평균 단가** 입력 (현재가가 자동 입력되지만 직접 수정 가능)
   - 한국 종목은 KRW(원화), 미국 종목은 USD(달러)
5. **[포지션 추가]** 클릭

> 종목 선택 전 단가를 직접 입력했으면 선택 후에도 입력한 단가가 유지됩니다. (의도한 단가 보호)

[SCREENSHOT: 포지션 추가 모달]

### 포지션 관리 (수정/매수/매도/삭제)

각 포지션 카드 우측의 **[...]** (점 세 개) 버튼을 누르면 4가지 작업이 가능합니다.

| 작업 | 설명 |
|------|------|
| 추가 매수 | 기존 포지션에 주식을 더 사는 경우. 매수 수량과 단가를 입력하면 가중평균 단가로 자동 계산됨 |
| 매도 | 보유 주식 일부 또는 전체 매도. MAX 버튼으로 전량 매도 가능. 예상 손익 미리 확인 |
| 포지션 수정 | 수량과 평균 단가 직접 수정 (기록 오류 정정 시 사용) |
| 제거 | 포지션 전체 삭제. 삭제 후 복구 불가, 거래 이력은 보존 |

[SCREENSHOT: 포지션 액션 메뉴]

### 포지션 카드 읽는 법

각 포지션 카드에는 다음 정보가 표시됩니다.

- **현재가** / **평균 단가** / **수량** / **평가금액**
- **P&L 바:** 손익률(%) + 손익금액 (수익은 초록, 손실은 빨강)
- **PivoxScore 바:** 퀀트 엔진이 계산한 종목 점수 (0–100)
- **시그널 뱃지:** POSITIVE / NEUTRAL / NEGATIVE
- **TP/SL:** Take Profit(목표가) 및 Stop Loss(손절가)가 설정된 경우 표시

카드 클릭 시 해당 종목 상세 페이지로 이동합니다.

### 정렬 및 필터

포지션 목록 상단에서 필터와 정렬을 설정할 수 있습니다.

- **필터:** 전체 / Positive / Negative / Neutral
- **정렬:** 티커 / 손익 / 평가금액 / 점수 (클릭 시 오름차순/내림차순 전환)

### 통화 처리

- 한국 종목(KRX)은 KRW로 표시
- 미국 종목은 USD로 표시
- 혼합 보유 시 FX 환율을 적용하여 KRW 환산값도 함께 표시
- 하단에 적용된 USD/KRW 환율 표시

## 4. 종목 검색 + 상세

**경로:** `/detail/[ticker]`

[SCREENSHOT: 종목 상세 페이지 — NVDA 예시]

포트폴리오, 관심종목, Discover 등 어디서든 종목 카드를 클릭하면 상세 페이지로 이동합니다. URL에 티커를 직접 입력해도 됩니다 (예: `/detail/AAPL`, `/detail/005930`).

### 검색 방법

- **미국 주식:** 티커 그대로 입력 (예: `NVDA`, `TSLA`, `AAPL`)
- **한국 주식:** 6자리 종목 코드 입력 (예: `005930`은 삼성전자, `035420`은 NAVER)
- 포트폴리오/관심종목/Discover에서 카드 클릭으로도 이동 가능

### 주가 헤더 (Stock Header)

- 종목명 + 티커
- 현재가 (미국: USD, 한국: KRW)
- 당일 변동률 (%) — 상승 초록, 하락 빨강
- 섹터

[SCREENSHOT: 주가 헤더 영역]

### PivoxScore 바

퀀트 엔진이 계산한 **0–100 사이의 종합 점수**와 시그널(POSITIVE / NEUTRAL / NEGATIVE)이 시각적 바로 표시됩니다.

- 70 이상: 초록 (강세)
- 45–69: 노랑 (중립)
- 44 이하: 빨강 (약세)

> 이 점수는 통계 모델 기반 정보 제공 지표이며, 투자 권유가 아닙니다.

### 가격 차트

기간 선택 버튼(1W / 1M / 3M / 6M / 1Y)으로 차트 기간을 변경할 수 있습니다. 데이터가 없는 경우 "재시도" 버튼이 표시됩니다.

[SCREENSHOT: 가격 차트 — 기간 선택 버튼 포함]

### Key Metrics (주요 지표)

| 지표 | 설명 |
|------|------|
| Take Profit | 퀀트 모델이 계산한 목표 가격 (현재가 기준 %) |
| Stop Loss | 퀀트 모델이 계산한 손절 기준 가격 |
| P/E Ratio | 주가수익비율 (주가 ÷ 주당순이익) |
| Market Cap | 시가총액 |
| 52W High | 52주(1년) 최고가 |
| 52W Low | 52주(1년) 최저가 |

### Quant Breakdown (4 기둥 분석)

퀀트 엔진은 4개 영역으로 나뉩니다. 각 영역은 0–100 점수로 표시됩니다.

| 기둥 | 설명 |
|------|------|
| Technical (기술적) | 이동평균, 모멘텀, 볼린저밴드 등 가격·거래량 기반 지표 |
| Fundamental (기본적) | PER, EPS, 매출 성장률 등 재무 데이터 기반 |
| Sentiment (심리) | 뉴스 감성 분석, 시장 심리 지표 |
| Quant | StatArb(통계적 차익거래), MeanReversion(평균 회귀) 등 퀀트 모델 종합 |

[SCREENSHOT: Quant Breakdown 4개 기둥 카드]

### 뉴스

해당 종목 관련 최근 뉴스 최대 8건. 뉴스 제목, 출처, 날짜가 표시되며, 클릭 시 원문 기사로 이동합니다.

## 6. Signals

**경로:** `/signals`

[SCREENSHOT: Signals 페이지]

내 포트폴리오에 보유 중인 **종목들에 대한 퀀트 시그널**을 보는 페이지입니다. 포지션이 없으면 시그널도 없습니다.

> **중요:** 여기 표시되는 POSITIVE/NEGATIVE/NEUTRAL 시그널은 통계 모델에서 산출된 정보입니다. 매수·매도 권유가 아니며, 투자 결정은 본인이 직접 내려야 합니다.

### 시그널 뱃지 의미

| 뱃지 | 의미 |
|------|------|
| POSITIVE | 퀀트 모델이 현 시점에서 상대적으로 강한 신호를 감지 |
| NEUTRAL | 특별한 방향성 없음, 관망 상태 |
| NEGATIVE | 퀀트 모델이 현 시점에서 약세 신호를 감지 |

### 팩터 점수 해석

## 10. Risk

**경로:** `/risk`

[SCREENSHOT: Risk 대시보드 전체]

포트폴리오의 리스크 지표를 정량적으로 분석하는 페이지입니다. 포지션이 없으면 모든 지표가 비어 있으므로, 먼저 포트폴리오에 종목을 추가해야 합니다.

> **법적 고지:** 이 페이지의 모든 수치는 통계 모델 기반 정보 제공 지표입니다. 투자 권유가 아닙니다. 실제 손실은 추정값과 다를 수 있습니다.

### 상단 요약 카드

| 카드 | 의미 |
|------|------|
| 샤프 비율 (Sharpe Ratio) | 위험 대비 수익률. 1 이상: 양호, 0.5–1: 보통, 0.5 미만: 위험 |
| 최대 낙폭 (Max Drawdown) | 고점 대비 최대 하락폭. 10% 이하: 양호, 20% 초과: 주의 |
| 연환산 변동성 | 연간 기준 수익률 변동성. 15% 이하: 안정, 25% 초과: 고위험 |
| 방어 레이어 | 7단계 방어 레이어 중 정상 통과 개수 (예: 7/7) |

### Value at Risk (VaR)

VaR(Value at Risk)은 "95% 확률로 하루 최대 얼마를 잃을 수 있는가"를 금액으로 나타냅니다.

- **VaR (95%):** 하루 예상 최대 손실 — 5일 중 4일은 이 금액 이하로 손실
- **VaR (99%):** 하루 극단 손실 — 100일 중 99일은 이 금액 이하로 손실

> VaR이 감당 범위를 초과하면 변동성이 낮은 종목으로 리밸런싱을 검토하세요.

[SCREENSHOT: VaR 섹션]

### 최대 낙폭 분석 (Drawdown Analysis)

| 지표 | 의미 |
|------|------|
| Max Drawdown | 포트폴리오 역사상 고점 대비 최대 하락폭 |
| Current Drawdown | 현재 고점 대비 현재 낙폭 (현재 얼마나 빠진 상태인지) |
| Recovery Days | 과거 낙폭에서 회복까지 평균 소요 일수 |

### 스트레스 테스트 시나리오 (Stress Test)

과거 주요 위기 시나리오가 다시 재현될 경우 내 포트폴리오에 예상 영향(%)을 막대 그래프로 보여줍니다. 시나리오 예시: 2008 금융위기, 2020 코로나 폭락, 금리 +1% 충격 등.

막대가 빨간색일수록 해당 시나리오에서 큰 손실이 예상된다는 의미입니다.

[SCREENSHOT: 스트레스 테스트 섹션]

### 종목별 예상 손실 기여도 (Component Expected Shortfall)

**포지션 2개 이상 필요.** 극단적 시장 상황(꼬리 위험)에서 어떤 종목이 포트폴리오 손실에 가장 많이 기여하는지 분해합니다.

- 막대가 긴 종목 = 꼬리 위험 기여도 높음
- 비중이 크다고 기여도가 높은 것은 아님 → 상관관계 고려
- 한 종목이 전체 위험의 30% 이상이면 분산 부족 신호

### 7단계 리스크 방어 상태 (Defense Status)

PivoxQuant는 7개 방어 레이어를 실시간으로 감시합니다.

| 레이어 | 감시 내용 | 트리거 시 권장 행동 |
|--------|-----------|---------------------|
| 01 VaR Layer | 95% 일별 손실 한도 초과 여부 | 신규 매수 보류, 큰 종목 일부 익절 고려 |
| 02 Correlation Layer | 종목 간 상관관계 과도 (분산 효과 소실) | 다른 섹터·자산군 추가 |
| 03 VIX Layer | 시장 공포지수(VIX) 급등 | 신규 매수 보류, 현금 비중 확대 |
| 04 Tail Layer | 블랙스완 위험 노출 | 헤지 수단 검토, 위험자산 비중 축소 |
| 05 Daily Layer | 당일 누적 손실 한도 초과 | 당일 추가 매매 중단 |
| 06 Sector Layer | 한 섹터 비중 과도 집중 | 초과 섹터 비중 축소 |
| 07 Cash Layer | 현금 버퍼 부족 | 일부 포지션 정리하여 현금 회복 |

- **모두 통과(초록):** 7단계 정상
- **경고(노랑):** 일부 레이어 경계 구간
- **트리거(빨강):** 기준 초과 — 카드 하단에 권장 행동 안내가 표시됨

> PivoxQuant는 read-only 서비스입니다. 자동으로 매매를 실행하지 않으며, 모든 투자 결정은 본인이 직접 내려야 합니다.

## 11. What-if Simulator

**경로:** `/simulator/what-if`

[SCREENSHOT: What-if Simulator 페이지]

"만약 과거에 이 종목을 샀다면 지금 얼마일까?" 를 시뮬레이션하는 타임머신 도구입니다. 로그인 없이도 접근 가능한 공개 페이지입니다.

### 사용 방법

1. **종목(티커)** 입력 (예: `NVDA`, `AAPL`, `005930`)
2. **투자 시작일** 선택 (예: 코로나 바닥 2020-03-23)
3. **투자 금액** 입력 + **통화** 선택 (KRW / USD)
4. (선택) **정기 적립** 방식 선택: 없음 / 월 1회 / 주 1회
5. **[계산하기]** 버튼 클릭

결과 화면에는 최초 투자 금액, 현재 평가금액, 총 수익률(%), 연환산 수익률이 표시됩니다.

### 기본값 예시

페이지 첫 진입 시 다음 예시가 미리 입력되어 있습니다.
- 종목: NVDA (엔비디아)
- 시작일: 2020-03-23 (코로나 저점)
- 금액: 5,000,000원

이 설정으로 [계산하기]를 누르면 코로나 저점 NVDA 투자 결과를 바로 확인할 수 있습니다.

### URL 공유

결과 계산 후 URL에 파라미터가 자동으로 추가됩니다. 이 URL을 그대로 복사해서 친구에게 공유하면 같은 시뮬레이션 결과를 볼 수 있습니다.

A. 페이지를 새로고침하거나 잠시 기다려 주세요. 데이터는 SWR 캐시 기반으로 자동 갱신됩니다. 그래도 안 되면 문제 해결 가이드를 참조하세요.

**Q4. 한국 주식도 분석할 수 있나요?**
A. 네, 가능합니다. 삼성전자(005930), NAVER(035420), 카카오(035720) 등 주요 KRX 종목을 지원합니다. 검색창에 6자리 종목코드 또는 한글명(예: 삼성전자)으로 검색하세요.

**Q5. PivoxScore는 어떻게 계산되나요?**
A. 기술적 분석, 펀더멘털 분석, 심리 분석, 퀀트 모델 4개 영역의 점수를 가중 합산하여 0–100으로 정규화합니다. 투자 권유 지표가 아닌 정보 제공 목적의 참고 점수입니다.

**Q6. POSITIVE 시그널이 뜨면 사도 되나요?**
A. 아닙니다. 시그널은 퀀트 모델의 통계적 분석 결과를 나타내는 정보입니다. 투자 결정과 책임은 전적으로 본인에게 있습니다.

**Q7. VaR(Value at Risk)이 너무 높게 나와요. 어떻게 해야 하나요?**
A. 변동성이 높은 종목의 비중이 크거나 포지션이 집중되어 있을 가능성이 있습니다. 종목 수를 늘리거나 변동성이 낮은 ETF 비중을 늘리는 방향을 검토하세요. 단, 이는 일반적인 정보이며 투자 조언이 아닙니다.

**Q8. AI Chat이 잠겨 있어요.**
A. AI Chat은 Pro 플랜 이상에서 사용 가능합니다. `/settings` → 구독 탭 또는 `/pricing` 페이지에서 업그레이드할 수 있습니다.

**Q9. 자동매매(AutoTrade)를 바로 실전에 사용할 수 있나요?**
A. AutoTrade는 Premium 플랜 전용입니다. 반드시 모의투자(Paper Trading) 모드로 충분히 테스트한 후 실전을 검토하세요. 알고리즘 매매는 수익을 보장하지 않습니다.

**Q10. Alpaca를 연결하면 자동으로 주문이 실행되나요?**
A. 현재 Alpaca 연결은 포지션 동기화(가져오기) 목적으로만 사용됩니다. AutoTrade 기능을 켜야만 자동 매매 신호가 생성되며, Premium 플랜 필요합니다.

**Q11. 관심종목(Watchlist)에 추가한 종목과 포트폴리오 종목은 다른가요?**
A. 네. 관심종목은 모니터링용으로 실제 보유 포지션이 아닙니다. 포트폴리오는 `/portfolio`에서 별도로 관리합니다.

**Q12. 차트 데이터가 없다고 나와요.**
A. 데이터 소스(FMP) 문제일 수 있습니다. [재시도] 버튼을 눌러보거나, 잠시 후 다시 접속해 보세요.

**Q13. 언어를 영어로 바꾸려면 어떻게 하나요?**
A. `/settings` → Language 탭 → English 선택. 즉시 적용됩니다.

**Q14. 투자 성향이 잘못 진단된 것 같아요. 다시 할 수 있나요?**
A. `/settings` → 계정 탭 → [투자 성향 재설정] 버튼을 클릭하면 온보딩 설문을 다시 진행할 수 있습니다.

**Q15. 계정을 삭제하려면 어떻게 하나요?**
A. `/settings` 페이지 하단 위험 구역에서 [계정 삭제] 버튼을 누르면 지원팀 이메일(seanbae1521@gmail.com) 문의 화면이 나타납니다. 이메일로 계정 삭제를 요청하면 처리됩니다. 개인정보보호법(PIPA)에 따라 요청 후 처리됩니다.

## 문제 해결 가이드

### 로그인이 안 됩니다

**증상:** Google/카카오 버튼 클릭 후 오류 발생 또는 로그인 후 다시 로그인 화면으로 돌아옴

**해결 방법:**
1. 브라우저 쿠키 및 캐시 삭제 후 재시도
2. 시크릿(인코그니토) 창에서 시도
3. VPN 사용 중이면 꺼보기
4. Safari 사용 시 크롬 또는 Edge로 변경
5. 그래도 안 되면 seanbae1521@gmail.com 으로 문의

### 포지션이 추가되지 않습니다

**증상:** 포지션 추가 모달에서 [포지션 추가] 클릭 후 아무 반응이 없거나 오류 메시지

**해결 방법:**
1. 드롭다운에서 종목을 반드시 선택했는지 확인 (직접 티커 입력만으로는 안 됨)
2. 수량과 단가가 0보다 큰 숫자인지 확인
3. 백엔드 서버가 실행 중인지 확인 (로컬 환경 사용 시)
4. 페이지 새로고침 후 재시도

### 포지션을 추가했는데 데이터가 안 뜹니다

**증상:** 포트폴리오 요약 카드가 비어 있거나 0으로 표시

**해결 방법:**
1. 데이터 로딩에 수초 걸릴 수 있음 — 잠시 대기
2. 시그널 엔진이 분석 중일 수 있음 — `/signals` 페이지에서 [새로고침] 버튼 클릭
3. 브라우저 새로고침 (F5)

### Market 페이지 데이터가 안 보입니다

**증상:** 지수 카드가 모두 "—" 로 표시

**해결 방법:**
1. 네트워크 연결 확인
2. 데이터 API(FMP)의 일시적 오류일 수 있음 — 잠시 후 재시도
3. 브라우저 새로고침

### Discover 스캔이 되지 않습니다

**증상:** [스캔] 버튼 클릭 후 오랫동안 로딩 중이거나 빈 결과

**해결 방법:**
1. 스캔은 최대 30초 소요될 수 있음 — 기다려 보기
2. 이전 스캔 캐시가 있으면 캐시 결과가 우선 표시됨 (하단 "캐시됨: [시각]" 확인)
3. FMP API 한도 초과 시 빈 결과가 나올 수 있음 — 1시간 후 재시도

### AI Chat 응답이 중간에 멈춥니다

**증상:** 스트리밍 중 텍스트가 더 이상 출력되지 않음

**해결 방법:**
1. 빨간 [중지] 버튼을 누르고 다시 질문
2. 너무 긴 답변을 요구하는 경우 질문을 더 구체적으로 단순화
3. 백엔드 응답 시간 초과일 수 있음 — 재시도

### VaR / Risk 데이터가 없습니다

**증상:** Risk 페이지에서 "VaR 데이터 없음" 또는 "Drawdown data is not available"

**해결 방법:**
1. 포트폴리오에 포지션이 1개 이상 필요
2. 포지션 추가 후 수분 이내 자동 계산됨
3. Component ES는 포지션 2개 이상 필요

### 브라우저 푸시 알림이 오지 않습니다

**증상:** Settings에서 Morning Brief 알림을 켰는데 알림이 안 옴

**해결 방법:**
1. 브라우저 알림 권한 확인: 브라우저 주소창 왼쪽 자물쇠 아이콘 → 알림 → 허용
2. 기기(OS) 수준 알림 설정 확인 (맥 시스템 환경설정 → 알림)
3. 모바일에서는 PWA로 설치한 경우에만 푸시 지원
