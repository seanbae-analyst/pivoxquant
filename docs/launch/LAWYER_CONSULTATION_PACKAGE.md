> **작성일**: 2026-04-17
> **작성**: 법무부 (General Counsel, Kim & Chang Standard)

> **면책**: 본 문서는 내부 준비용 자료이며, 법률 자문이 아님. 최종 판단은 반드시 변호사 확인.

## 1. 상담 목적 + Agenda

### 목적
PivoxQuant(AI + 15팩터 퀀트 분석 SaaS) **출시 2개월 전**, 한국 금융규제 리스크를 **변호사 관점에서 최종 확정**한다. 내부 법무부(Kim & Chang 기준) 검토 결과 CRITICAL 5건 + HIGH 8건이 식별된 상태이며, 외부 변호사의 독립 확답 없이는 유료 출시 불가로 판단함.

### 상담 대상
1차: 핀테크 특화 부티크 로펌(디라이트, 미션 등) — 2~3시간 자문(약 ₩80만~₩120만)
2차(필요 시): 김앤장/세종 금융규제팀 — 시간당 ₩60만~₩100만

### 60분 Agenda
- **0~10분** 서비스 데모(3분) + 현 사업모델 브리핑
- **10~30분** 유사투자자문업(§101) + 자본시장법 §6/§71 확답
- **30~45분** 마이데이터(KIS/키움/SnapTrade 연동) + 개인정보/GDPR
- **45~55분** CRITICAL 5건 수정안 리뷰
- **55~60분** 약관/개인정보처리방침 작성 위임 논의 + 후속 일정

### 예상 결과 3가지 시나리오
| 시나리오 | 조건 | 출시 영향 |
|---|---|---|
| **A. Green** | 정보 제공 + 고지 배너로 충분 | 1주 내 베타 재오픈 |
| **B. Yellow** | 유사투자자문업 신고 필요(20만원+변호사비) | 4~6주 지연, 신고 후 출시 |
| **C. Red** | 투자자문업 등록(자본 5억) 또는 마이데이터 인가 필요 | 기능 재설계 + 6개월+ 지연 |

**의사결정 기준**: Yellow까지는 수용, Red면 해당 기능 삭제 또는 사업모델 피벗.

## 2. 핵심 질문 리스트 (Top 20, 영역 A~F)

### A. 유사투자자문업 (자본시장법 §101)

**Q1.** PivoxQuant의 "15팩터 종목 점수(1~10점) 표시 + AI 해석 문구" 수준이 **자본시장법 §101 유사투자자문업(불특정 다수 대상 투자 조언)**에 해당하는지?
> 변호사 확답 필요: Y/N + 근거 조항 + 판례

**Q2.** **무료 베타(유료 전환 전)** 운영 시에도 유사투자자문업 신고 의무가 발생하는지? (§101 ①: "대가를 받고" 요건 해석)
> 변호사 확답 필요: 무료 = 신고 면제 여부

**Q3.** 유료 전환 시점부터 신고 필수라면, **사전 신고**(베타 중)와 **전환 직전 신고** 중 어느 쪽이 실무상 안전한가?

**Q4.** 신고 접수처(금융감독원 전자민원시스템) + **수수료 20만원 외 실제 총비용**(변호사 대행비, 교육 이수비 등)?
> 목표: 전체 예산 100만원 내 소진 가능 여부 확인

**Q5.** 신고 후 의무사항(분기 영업보고서, 교육 이수 12시간/년, 광고 심의 등) 중 **1인 창업자가 실질적으로 감당 가능한 범위**?

### B. 자본시장법 §6(투자자문업) / §71(부당권유)

**Q6.** "이 종목 점수 8점" 숫자 표시만으로 §6 투자자문업(등록 요건: 자본금 5억) 해당 가능성이 있는지? **숫자 vs 문장("매수 추천")의 법적 차이**?

**Q7.** "15팩터 기반 분석 결과"라는 문구가 **§71 부당권유 금지** 조항(단정적 판단 제공 금지)에 저촉되는지? 허용 수위 예시?

**Q8.** 유저 보유 포지션을 읽어 "이 종목 비중이 30%로 높음" 알림 = **개별 맞춤 자문(§6)**으로 해석될 위험?
> 쟁점: "정보 제공" vs "자문"의 법적 경계

**Q9.** 투자자문업 등록(자본 5억) **회피하면서 동등 가치를 전달할 설계 원칙** 3가지? (예: ① 불특정 다수 대상만, ② 특정 종목 추천 대신 팩터 점수만, ③ 면책 배너)

### C. 마이데이터 (신용정보법 §2 ①9의2, 본인신용정보관리업)

**Q10.** KIS/키움 OAuth로 **포지션 조회만**(거래 실행 無) = **마이데이터 인가(자본 5억+허가제) 필요 여부**?
> 핵심 쟁점: "신용정보 통합조회 서비스" 해당성

**Q11.** **SnapTrade(미국 API) 경유 글로벌 증권사 연동**의 한국 법상 지위? 해외 SaaS 위탁 = 국외 이전 동의 필요?

**Q12.** 유저 동의 방식: **명시적 동의 체크박스 + 보관 기간 + 철회 절차** 최소 요건?

**Q13.** 유저가 동의 철회 시 **수집 데이터 즉시 파기** 의무 범위(로그/백업 포함 여부)?

### D. 개인정보보호법 + GDPR

**Q14.** 한국 사업자 + 글로벌 유저(EU 포함) 수집 시 **GDPR §3(역외 적용)** 적용? 대표자(representative) 지정 의무?

**Q15.** AI 호출(Anthropic/OpenAI) 시 유저 포트폴리오 데이터 전송 = **개인정보보호법 §28조의8(국외 이전) 별도 동의** 필요? 표준계약조항(SCC) 수준?

### E. 결제 / 환불

**Q16.** 전자상거래법 §17(청약철회) — **구독 서비스 7일 철회권** 적용 범위? 디지털 콘텐츠 예외(§17 ②5호 "용역 제공 개시") 주장 가능?

**Q17.** 연간 결제 중도 해지 시 **일할 환불 / 잔여월 환불 / 환불 불가** 중 약관에 명시 가능한 최대 사업자 우위 조건?

**Q18.** Stripe 해외 결제 + 한국 사업자 **부가세(10%) 처리 방식**? 간이과세자 해외 매출(수출 영세율) 가능성? 글로벌 유저가 50% 넘어갈 경우 법인 전환 시점?

### F. 책임/면책 (추가 보완)

**Q19.** "정보 제공 목적이며 투자 판단은 이용자 책임"이라는 **면책 조항의 실효성 한계**? 대법원 판례상 사업자 책임 면제 가능 범위?

**Q20.** AI 오류(잘못된 점수/해설)로 유저 손실 발생 시 **예상 손해배상 리스크**? AI 책임 보험 가입 필요성?

## 3. CRITICAL 5건 기능 재설계 현황

| # | 기능 | 이전 법무 판정 | 현재 상태 | 제안 수정안 | 변호사에게 물어볼 것 |
|---|---|---|---|---|---|
| **1** | **Portfolio Impact Radar** (유저 보유종목 대비 리스크 경고) | CRITICAL(§6 맞춤자문 우려) | 수정 진행 중 | 종목명 비노출 → "섹터 집중도" "변동성 점수"만 표기 + 면책 배너 | 이 수준이면 §6 회피 가능한가? |
| **2** | **Options Translator** (옵션 전략 해설) | CRITICAL(파생상품 권유 우려) | 삭제 vs 유지 고민 | **삭제 권장** — 옵션은 §9조 고난도 금융투자상품, 권유 규제 엄격 | 순수 교육(용어 해설)만도 위험한가? |
| **3** | **Thesis Tracker 경고** (유저 매매논리 위반 시 알림) | CRITICAL(자문성 짙음) | "상태 업데이트"로 리네이밍 | 경고 문구 제거, 단순 "지표 변화" 객관 표기만 | 문구 변경만으로 충분? 알고리즘 자체가 문제? |
| **4** | **데일리 AI 브리핑** (매일 종목 시황 발송) | CRITICAL(불특정다수+정기 = §101 전형) | **일시 중단** | 유사투자자문업 신고 완료 후 재개 | 신고 후엔 전면 허용? 추가 제약? |
| **5** | **전략 마켓플레이스** (유저간 전략 공유/판매) | CRITICAL(무인가 자문업 중개) | **1년 연기** | 신고+자문업 등록 완료 후 착수 | 플랫폼 책임 vs 게시자 책임 분리 가능? |

**총평**: 1~3은 **문구/UX 조정**으로 해결 가능 여부가 핵심, 4는 **신고 비용/기간** 확정, 5는 **중장기 로드맵**으로 분리.

### CRITICAL 5건 상세 수정안

**① Portfolio Impact Radar**
- 현재 UX: 유저 보유 종목별 "삼성전자 리스크 7점 / 비중 30% 경고" 표시
- 수정 UX: **종목명 비노출**, "반도체 섹터 비중 30%", "포트폴리오 변동성 상위 20%" 등 **집합 통계만 표시**
- 법적 논거: 개별 종목 맞춤 조언 → 집합 통계 정보 제공으로 전환 시 §6 회피 가능성

**② Options Translator**
- 현재: 콜/풋 전략 설명 + "이 상황에 적합한 전략" 제안
- 수정: **완전 삭제 권장**. 옵션은 §9조 고난도 금융투자상품, 광고/권유 규제 엄격(자본시장법 시행령 §68)
- 대안: 위키피디아 링크 정도의 외부 참조만

**③ Thesis Tracker**
- 현재: "매매논리 위반 감지 → 매도 고려 경고"
- 수정: "지표 변화 감지 → 본인이 설정한 임계치 도달" (단순 알림, 행동 유도 문구 전면 제거)
- 법적 논거: 유저 자가 설정 임계치 = 단순 툴, 사업자 조언 아님

**④ 데일리 AI 브리핑**
- 정기 + 불특정 다수 + 투자 정보 = §101 유사투자자문업 전형 해당
- 신고 전 일시 중단, 신고 후 "시장 동향 브리핑"(개별 종목 조언 無)으로 재개

**⑤ 전략 마켓플레이스**
- 유저간 전략 판매 = 무인가 투자자문업 중개 소지
- 1년 연기 → 투자자문업 등록(자본 5억) 검토 병행
