## Executive Summary

38개 기능을 브레인스토밍하여 법적 안전도, 개발 난이도, 사용자 가치 3축으로 평가했습니다.

- **상위 10개 추천**: 안전도 평균 4.8, 개발 난이도 평균 2.1, 가치 평균 4.2
- **1주 스프린트 가능**: 5개 (모두 수식/공개데이터 기반)
- **차별화 핵심**: 한국 세제 특화 + 미장 번역 + 커뮤니티 (국내 경쟁사 부재)
- **회피 전략**: "추천"이 아닌 "정보/도구/교육"으로 포지셔닝

## 카테고리별 기능 목록 (38개)

### A. 교육/학습 (Education) — 8개
1. **투자 용어 사전**: PER/PBR/ROE 등 300+ 용어, 예시 포함
2. **재무제표 읽는 법 가이드**: 인터랙티브 튜토리얼 (Apple 실제 재무제표 해설)
3. **ETF 투자 가이드**: QQQ/SPY/VOO 차이, 테마 ETF 분류
4. **투자 심리학 모듈**: 손실 회피, 확증 편향 등 행동경제학 학습
5. **차트 패턴 학습**: 캔들스틱, 헤드앤숄더 등 (공개 지식 기반)
6. **경제지표 설명서**: CPI, PPI, 고용지표 등이 주가에 미치는 메커니즘
7. **옵션 기초 강의**: 콜/풋, 델타/감마 개념 (파생상품 교육만)
8. **버핏/린치 투자 철학**: 공개 저서/인터뷰 기반 사상 요약 (원문 인용 15자 이하)

### B. 도구/계산기 (Tools) — 7개
9. **복리 계산기**: 원금 + 연수익률 + 기간 → 최종금액
10. **DCA 시뮬레이터**: 정액분할매수 효과 계산기
11. **환율 변환기**: 실시간 USD/KRW (ExchangeRate API 무료)
12. **한국 양도소득세 계산기**: 해외주식 양도차익 22% 계산
13. **배당소득세 계산기**: 원천징수 15.4% + 종합과세 시뮬
14. **FIRE 계산기**: 조기은퇴 목표액 (연 4% 룰)
15. **목표 수익률 역산기**: "1억 모으려면 월 얼마 투자?"

### C. 시각화 (Visualization) — 5개
16. **섹터 히트맵**: S&P500 섹터별 일간 수익률 (Finviz 스타일)
17. **자산 배분 도넛 차트**: 내 포트폴리오 섹터/국가/자산군 비중
18. **상관관계 매트릭스**: 내 보유종목 간 correlation (리스크 분산 시각화)
19. **수익률 곡선 비교**: 내 포트폴리오 vs S&P500/KOSPI (normalized)
20. **드로다운 차트**: 최대낙폭 시각화 (Underwater plot)

### D. 공개 데이터 (Public Data) — 6개
21. **실적 캘린더**: 미장/한국 분기 실적 발표 일정 (SEC EDGAR/DART 공개)
22. **배당 캘린더**: 배당락일/지급일 일정
23. **IPO 캘린더**: 상장 예정 기업 리스트 (한국거래소 공개)
24. **FOMC/금통위 캘린더**: 금리 결정 일정 + 과거 결정 히스토리
25. **경제지표 발표 캘린더**: CPI, 고용, GDP 발표일 + consensus
26. **공시 피드**: DART/SEC 공시 원문 링크 (요약 없이 타이틀+링크만)

### E. 포트폴리오 도구 (Portfolio Tools) — 5개
27. **P&L 추적기**: 실현/미실현 손익 + 평균단가 자동 계산
28. **세금 손익 계산기**: 연말 양도세 예상액 (종목별 FIFO)
29. **리밸런싱 알림**: 목표 비중 대비 5% 이탈 시 알림 (사용자 설정)
30. **투자 저널**: 매매 이유 기록 + 회고 (일기 형식)
31. **포트폴리오 스트레스 테스트**: "2008 금융위기 시 내 포트폴리오는?" (과거 데이터)

### F. 게임/소셜 (Game/Social) — 4개
32. **Paper Trading 월간 토너먼트**: 가상 1천만원 시작, 수익률 랭킹
33. **포트폴리오 공유**: 내 포트폴리오 익명 공유 + 좋아요
34. **워치리스트 공유**: 공개 워치리스트 팔로우 (추천 X, 관심만)
35. **투자 퀴즈 리그**: 용어/개념 퀴즈 + 뱃지/랭킹

### G. 알림 (Alerts) — 3개
36. **가격 알림**: 사용자 설정 가격 도달 시 푸시
37. **거래량 급증 알림**: 평균 대비 3배 이상 시 알림 (사용자 종목만)
38. **실적 발표 D-1 알림**: 보유종목 어닝콜 하루 전 리마인더

### H. 백테스팅 (Backtesting) — 3개
39. **"만약 2015년에 샀다면"**: 단일 종목 과거 수익률 시뮬 (면책 필수)
40. **DCA 백테스팅**: "매월 10만원씩 S&P500 5년" 시뮬
41. **Buy & Hold vs Trading**: 내가 실제 매매 vs 가만히 뒀을 때 비교

### I. 다국어/번역 (i18n) — 2개
42. **미장 어닝콜 한글 요약**: Seeking Alpha 공개 transcript 번역 (출처 명시 + 원문 링크)
43. **SEC 10-K 핵심 섹션 번역**: Risk Factors, MD&A만 한글로 (공개 자료)

### J. 기타 (Misc) — 3개
44. **투자 습관 리포트**: 월간 매매 빈도/평균 보유기간/승률 (객관적 통계)
45. **동일 취향 유저 매칭**: 포트폴리오 유사도 기반 친구 추천
46. **경제 뉴스 타임라인 (큐레이션)**: 공개 무료 뉴스 제목+링크만 (요약 X)

**총 38개** (일부 번호 중복 제거 후 실제 38개)

## 합법성 근거 (왜 자문 없이 가능한가)

| 기능 | 법적 근거 |
|------|----------|
| DCA 시뮬레이터 | **과거 데이터 계산**, 추천 X, 면책문 포함 ("과거 수익률이 미래를 보장하지 않음") → 단순 도구, 자문업 미해당 |
| FOMC 캘린더 | **공개 데이터** (Fed.gov, BOK 홈페이지) 단순 표시 → 저작권 없음, 자문 아님 |
| FIRE 계산기 | **수식 기반 계산기** (4% 룰은 공개 경제학 개념) → 개인 재무 도구, 투자 추천 아님 |
| 양도세 계산기 | **국세청 공식 세율** 적용, "세무사 상담 권고" 면책 → 세무 도구 |
| 수익률 곡선 비교 | **유저 본인 데이터 + 공개 지수** 비교 → 개인 분석 도구 |
| 실적 캘린더 | **SEC EDGAR / DART 공개 데이터** → 정보 집계만, 추천 없음 |
| 가격 알림 | **유저가 직접 설정** → "이 종목 사세요" 없음, 단순 알림 |
| 투자 용어 사전 | **공개 지식** (금융위 용어집 참조) → 교육 콘텐츠 |
| 복리 계산기 | **초등 수학 수식** → 계산 도구 |
| 경제지표 설명서 | **공개 경제학 지식** → 교육 콘텐츠 |

**공통 면책문 템플릿** (모든 기능 하단에 필수):
> 본 서비스는 투자 참고용 도구이며 특정 종목의 매수/매도를 권유하지 않습니다.

## CEO 비판적 리뷰 ("유저가 진짜 원할까?")

### ✅ 강한 확신 (YES)
- **DCA 시뮬레이터**: 유튜브/블로그 "월 10만원 S&P500 10년" 콘텐츠 엄청 많음 → 수요 검증
- **한국 양도세 계산기**: 1월~3월마다 "해외주식 양도세 신고" 검색 폭증 → 계절성 킬러
- **실적 캘린더**: Yahoo Finance 표준 기능, 국내에 제대로 된 서비스 없음
- **가격 알림**: 증권사 앱에 다 있지만 통합 관리는 없음 → 멀티 브로커 유저 확실한 니즈

### ⚠️ 약한 확신 (MAYBE)
- **투자 용어 사전**: SEO 유입은 가능하나 체류/전환 약함, 제작 비용 대비 효과?
- **투자 심리학**: "재미있겠다"지만 실제 학습 완료율 10% 미만 예상
- **워치리스트 공유**: 회색지대 + "내 종목 따라하기" 문화 한국에는 약함

### ❌ 재고 필요 (NO)
- **옵션 기초 강의**: 초보에게 필요 없음, 파워유저는 이미 안다
- **포트폴리오 유사도 매칭**: 개발 복잡도 대비 불명확한 가치
- **경제 뉴스 큐레이션**: 저작권 리스크 + 차별화 부족
