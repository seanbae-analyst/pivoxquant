# 2. 제품 상세 — PivoxQuant 퀀트 엔진

## 아키텍처 개요

```
유저 온보딩 (8문항)
    ↓
투자 프로필 생성 (Conservative / Balanced / Growth / Aggressive)
    ↓
퀀트 엔진 파라미터 자동 조정
    ↓
┌──────────────────────────────────────────────┐
│           22개 팩터 종합 분석                    │
│  ┌─────────┐ ┌─────────┐ ┌──────┐ ┌───────┐ │
│  │기술 12개 │ │펀더 8개  │ │뉴스   │ │퀀트 5개│ │
│  └─────────┘ └─────────┘ └──────┘ └───────┘ │
└──────────────────────────────────────────────┘
    ↓
적응형 가중치 (주식 유형별 × 유저 프로필별)
    ↓
종합 점수 (0-100) → BUY / HOLD / SELL
    ↓
AdaptiveParams 3-Layer → 동적 TP/SL/Trail
    ↓
자동매매 실행 (Alpaca US / KIS KR)
```

## C. 적응형 가중치 시스템

### 주식 유형별 자동 가중치

```
ETF:        기술 50% | 펀더 5%  | 뉴스 3% | 퀀트 42%
한국주식:    기술 28% | 펀더 32% | 뉴스 3% | 퀀트 37%
대형주:      기술 22% | 펀더 25% | 뉴스 3% | 퀀트 50%
소형주:      기술 25% | 펀더 22% | 뉴스 3% | 퀀트 50%
기본:        기술 22% | 펀더 25% | 뉴스 3% | 퀀트 50%
```

### 유저 프로필 블렌딩 (50/50)

```
최종 가중치 = (주식유형 가중치 + 유저프로필 가중치) / 2
→ 같은 NVDA도 보수적 유저와 공격적 유저가 다른 점수를 받음
```

## D. AdaptiveParams 3-Layer 모델

### Layer 1: ATR 기반 변동성 스케일링

```
ATR% = (20일 평균 True Range / 현재가) × 100
TP = ATR% × 프로필 TP 배수
SL = ATR% × 프로필 SL 배수
```

### Layer 2: 시장 체제 → 전략 프로필 자동 매핑

| 체제 | 변동성 | 프로필 | TP | SL | Trail |
|------|--------|--------|----|----|-------|
| BULL | LOW | Trend Rider | 30% | 3% | 5% |
| BULL | HIGH | Momentum | 14% | 3% | 4% |
| TRANSITION | * | Scalper | 3.5% | 2% | 3% |
| MILD_BEAR | HIGH | Defensive | 3% | 3% | 2.5% |
| BEAR | * | Survival | 2% | 3.5% | 2% |

### Layer 3: ML 신뢰도 미세조정

```
ML 신뢰도 > 70% → TP ×1.25 (승자 오래 보유)
ML 신뢰도 < 30% → TP ×0.8, SL ×1.2 (빠른 탈출)
```

## F. 시그널 생성 + 기업 건전성 필터

```
종합점수 = tech×w_tech + fund×w_fund + news×w_news + quant×w_quant

점수 ≥ 매수기준 → BUY
점수 < 매도기준 → SELL
그 사이        → HOLD
```

### 기업 불건전성 필터 (BUY 차단)
- 적자 + 매출성장 <10%
- 레버리지 ETF (2X, 3X, INVERSE)
- 가격 < 200일 이동평균 × 0.9
- 52주 고점 대비 50% 이상 하락

### 포지션 사이징 (Kelly 기반)
- 점수 ≥ 85 → 자본의 45%
- 점수 ≥ 80 → 35%
- 점수 ≥ 75 → 25%
- 그 외 → 15% (파일럿)

## G. 백테스트 성과

### 미국 주식 (검증됨)

| 종목 | 기간 | PivoxQuant | Buy&Hold | Alpha |
|------|------|-----------|----------|-------|
| NVDA | 1년 | +34.7% | +15.7% | **+19.0%p** |
| AAPL | 1년 | +29.9% | +23.5% | **+6.4%p** |

### 한계 및 주의사항

| 종목 | 기간 | PivoxQuant | Buy&Hold | Alpha | 분석 |
|------|------|-----------|----------|-------|------|
| Samsung | 1년 | +106.2% | +194.6% | -88.4%p | 아래 참조 |

**삼성전자 백테스트 분석**:
- B&H가 +194.6%인 극단적 강세장(불장 특수)에서의 결과
- 적응형 엔진이 리스크 관리를 위해 조기 익절 → 이후 추가 상승분을 놓침
- 승률 자체는 100% (모든 거래 수익)이며, 한 번의 거래에서 +80.4% 실현
- **결론**: 강한 일방향 상승장에서는 B&H 대비 수익률이 낮을 수 있음. 이는 리스크 관리 엔진의 본질적 트레이드오프이며, 하락장에서의 손실 제한이 장기적으로 더 중요
- **교훈**: 상승장 전용 모드 추가 검토 (Trend Rider 프로필의 TP 상한 완화)

### 백테스트 일반 주의사항

1. 과거 성과가 미래 수익을 보장하지 않음
2. 슬리피지, 수수료, 시장 충격 비용이 반영되지 않음
3. 생존자 편향 — 상장 폐지된 종목은 테스트에서 제외됨
4. 데이터 스누핑 편향 — 과거 데이터에 과적합 가능성 존재
