## 상세 대응

### 1. ~~데이터 소스 안정성~~ (해결됨)

**해결**: FMP + Alpaca 공식 API로 전환 완료.
- US 주식: Alpaca (primary) + FMP (fallback)
- KR 주식: KIS (primary) + FMP (fallback)
- Fundamentals: FMP (24h cache)

### 2. 리텐션 실패 (확률 50%)

**진단 기준**:
- D1 리텐션 < 30% → 온보딩 전면 개편
- D7 리텐션 < 15% → 핵심 가치 재정의
- D30 리텐션 < 10% → PMF 부재, 피벗 검토

**대응**:
1. AHA 모먼트 정의 → 퍼널 단축
2. 온보딩 8문항 → 4문항 축소 A/B 테스트
3. 이탈 유저 카톡/이메일 리타겟팅

### 3. 1인 번아웃 (확률 60%)

**구체적 자동화 레벨**:

| 영역 | 자동화 방안 | 구현 시점 |
|------|-----------|----------|
| CS | 인앱 FAQ + 카카오 챗봇 | Phase 1 |
| 모니터링 | Sentry 에러 알림 → Slack/카톡 | Phase 1 |
| 배포 | GitHub Actions (push → 자동 배포) | Phase 1 |
| 알림 | 모닝브리프 자동 발송 (cron job) | Phase 1 |
| 리포팅 | PostHog 자동 대시보드 | Phase 2 |
| 결제 | 토스페이먼츠 자동 갱신 | Phase 1 |

> "주 1회 운영 안 하는 날"은 자동화 구축 전엔 현실적으로 못 지킴. 위 자동화 6개 완료 후에야 가능.

### 4. 획득 실패 (확률 40%)

**진단**: 런칭 2주 후 가입 < 30명

**피벗 플레이북**:
- 메시지 교체: "적응형 퀀트" → "AI가 분석해주는 주식앱"
- 채널 교체: 카페 → 숏폼 영상 (릴스/틱톡)
- 콘텐츠 교체: 기술 설명 → 수익률 스크린샷

### 5. 전환 실패 (확률 35%)

**대응**: Free 기능 과감히 제한
- 종목 2개 (3개에서 축소)
- AI 1회/일 (토큰 캡 2K)
- 페이월 시점: 유저가 가치를 느낀 직후

### 6. API 비용 폭발 (확률 30%)

**대응**:
- 유저당 일일 토큰 캡 (Free 2K, Pro 20K, Premium 100K)
- 분석 결과 6시간 캐시
- 같은 종목 분석 → 캐시 히트
- 비용 > 매출 40% 시 가격 인상

### 7. 법적 이슈 (확률 20%, 영향 치명적)

**예방**:
- 면책 문구 모든 화면 (런칭 전)
- "추천" 워딩 완전 제거
- 변호사 자문 (3개월 내)

**발생 시**:
- 자동매매 즉시 비활성화
- "분석 리포트" 형태로 전환
- 규제 샌드박스 신청

### 8. 대형 플레이어 진입 (확률 25%)

**핵심 방어**: "유저별 적응형 분석"은 대규모 플랫폼이 구조적으로 따라하기 어려움. 토스/카카오는 모든 유저에게 같은 분석을 줄 수밖에 없음.

### 9. 시장 하락장 (확률 30%)

**오히려 기회**: 하락장에서 분석 도구 수요 증가. "잃지 않는 투자" 메시지 강화.
