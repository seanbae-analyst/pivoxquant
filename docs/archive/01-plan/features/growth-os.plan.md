## 1. User Intent Discovery

### Core Problem (3-in-1)
1. 1인 창업자의 역할 과부하 → 하루가 혼란스럽고 빠지는 것 많음
2. AI가 정리는 해주지만 실제 실행까지는 안 함 (v2에서 해결)
3. 자기 성장을 추적/회고할 시스템 부재 → **v1 핵심**

### Target User
- **Primary:** 나 자신 (dogfood first)
- **Secondary:** 1인 창업자 / indie hacker
- **Tertiary:** 자기계발 중심 취준생, N잡러

### Success Criteria
1. 매일 아침 AI 브리핑으로 하루 시작 (DAU = 1 → retention)
2. AI agent가 실제로 일을 대신 처리 (v2)
3. 주간/월간 성장 그래프 시각화 (공유 → 바이럴)
4. 다른 사람도 유료 사용 (MRR $1K+)

### Data Flow
```
[Morning 08:00]
  Worker cron
    → Claude API (프롬프트: "어제 회고 + 캘린더 + 진행 중 task 분석")
    → INSERT growth_daily_logs (type='briefing', content=JSON)
    → Slack webhook → 유저 폰

[Evening 21:00]
  Worker cron
    → Claude API (프롬프트: "오늘 briefing 기반으로 회고 질문 3개 생성")
    → Slack 질문 전송
    → 유저가 Slack에서 응답 OR /growth 페이지에서 입력
    → POST /api/reflect → INSERT growth_reflections
    → growth_scores 자동 계산 (활동량 + 회고 깊이 + 연속성)

[Weekly Sat 09:00]
  Worker cron
    → 이번 주 daily_logs + reflections 집계
    → Claude API (프롬프트: "주간 회고 생성. 패턴 발견, 성장 포인트, 다음 주 제안")
    → INSERT growth_weekly_reports
    → Slack 발송

[Growth Graph]
  GET /api/growth/data?range=365d
    → growth_scores 테이블에서 일별 점수 조회
    → JSON 응답 → React SVG 히트맵 렌더
```

### DB Schema (추가 테이블)
```sql
-- 일별 활동 기록 (아침 브리핑 + 시스템 수집)
CREATE TABLE growth_daily_logs (
  id SERIAL PRIMARY KEY,
  date DATE NOT NULL UNIQUE,
  type VARCHAR(20) NOT NULL,        -- 'briefing', 'system', 'manual'
  priorities JSONB,                  -- 오늘 우선순위 3개
  motivation TEXT,                   -- 동기부여 한 줄
  actual_done JSONB,                 -- 실제 완료 항목 (저녁에 업데이트)
  created_at TIMESTAMP DEFAULT NOW()
);

-- 회고 질문/응답
CREATE TABLE growth_reflections (
  id SERIAL PRIMARY KEY,
  date DATE NOT NULL,
  questions JSONB NOT NULL,          -- AI 생성 질문 3개
  answers JSONB,                     -- 유저 응답
  mood INTEGER CHECK (mood BETWEEN 1 AND 5),  -- 오늘 기분 1-5
  answered_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 일별 성장 점수 (자동 계산)
CREATE TABLE growth_scores (
  date DATE PRIMARY KEY,
  activity_score INTEGER DEFAULT 0,   -- 0-100: 활동량 (커밋, task 완료)
  reflection_score INTEGER DEFAULT 0, -- 0-100: 회고 깊이 (응답 길이, 인사이트)
  streak_days INTEGER DEFAULT 0,      -- 연속 사용 일수
  total_score INTEGER GENERATED ALWAYS AS
    (activity_score * 0.4 + reflection_score * 0.4 + LEAST(streak_days, 30) * 0.67)
    STORED,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 주간 리포트
CREATE TABLE growth_weekly_reports (
  id SERIAL PRIMARY KEY,
  week_start DATE NOT NULL UNIQUE,   -- 월요일 기준
  summary TEXT NOT NULL,
  patterns JSONB,                     -- 발견된 패턴
  growth_areas JSONB,                 -- 성장 포인트
  next_week_suggestions JSONB,        -- 다음 주 제안
  week_score INTEGER,                 -- 주간 종합 점수
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_growth_scores_range ON growth_scores(date);
CREATE INDEX idx_reflections_date ON growth_reflections(date);
```

## 5. Feature Detail

### F1: Morning Briefing
**트리거:** 매일 08:00 KST (agent_worker cron)
**입력:** 어제 회고 데이터 + growth_daily_logs + 캘린더(v1은 수동 입력)
**출력:**
```
Good morning!

오늘 우선순위:
1. Railway 배포 재시도 (어제 P0, 아직 미완)
2. Stripe Product ID 매핑 (런치 블로커)
3. 면접 준비 자료 정리 (내일 4시)

어제 회고에서: "SQLAlchemy n+1 해결한 게 뿌듯했다"
오늘도 그 흐름 이어가기.

연속 12일째 Growth OS 사용 중.
```
**알림:** Slack webhook
**HITL:** 없음 (정보 전달만, 실행 없음)

### F2: Evening Reflection
**트리거:** 매일 21:00 KST
**Flow:**
1. AI가 오늘 briefing 기반으로 질문 3개 생성
2. Slack으로 전송 OR /growth 페이지 리다이렉트
3. 유저가 텍스트로 답변 (각 1-3문장)
4. mood 점수 1-5 선택
5. DB 저장 → growth_score 자동 계산

**예시 질문:**
```
1. 오늘 우선순위 3개 중 몇 개 완료했나요? 못한 건 왜?
2. 오늘 가장 살아있다고 느낀 순간은?
3. 내일의 나에게 한마디?
```

### F3: Growth Graph
**위치:** `/growth` (Next.js page, 인증 필요)
**구성:**
- 365일 히트맵 (GitHub contribution graph 스타일)
  - 색상: 회색(없음) → 연두(낮음) → 초록(높음)
  - 클릭 시 해당 일 상세 (briefing + reflection + score)
- 주간 트렌드 라인 차트 (activity vs reflection 비교)
- 현재 streak 카운터
- "Share" 버튼 → OG image 자동 생성 (/api/growth/og?range=30d)

### F4: Weekly Report
**트리거:** 매주 토요일 09:00 KST
**입력:** 해당 주 daily_logs + reflections + scores
**Claude 프롬프트 핵심:**
```
이번 주 데이터를 분석해서:
1. 요약 (3줄)
2. 패턴 발견 (반복되는 것, 빠진 것)
3. 성장 포인트 (구체적 증거와 함께)
4. 다음 주 제안 (3가지, 실행 가능한 것만)
절대 "추천", "조언" 단어 사용 금지.
"분석", "관찰", "패턴" 프레이밍만 허용.
```
