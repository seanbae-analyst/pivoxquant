# 로톡 (LawTalk) 무료질문 3개 — Cross-validation 용

**채널**: 로톡 (lawtalk.co.kr) 무료질문 게시판
**비용**: 무료
**예상 회신**: 1-7일, 변호사 1-3명 답변
**용도**: 1357 + 핀테크지원센터 답변과 cross-check (다중 의견 받기)

**주의**:
- 로톡 무료질문은 **책임 의견 아님** (방향성만)
- 변호사가 답변하지 않을 수도 있음
- 답변 받으면 캡처 + 답변 변호사 사무실 메모 (유료 자문 시 후보)

**제출 방법**:
1. lawtalk.co.kr 로그인
2. "무료 질문" → 카테고리 선택 → 작성
3. 글자 수 제한 있음 (보통 1000-2000자) — 아래 양식은 제한 내 작성됨

## 질문 1 — 자본시장법 §17 미등록 영업행위 (PFM 도구 면제 적정성)

**카테고리**: 회사법 / 금융 / 자본시장법

```
[질문]
미국·한국 주식 데이터 기반 개인 투자 분석 SaaS를 출시 준비 중인 1인 창업자입니다.
사용자가 자기 자신의 보유 종목·매매 의도를 자기 자신을 위해 분석하는 PFM
(Personal Finance Management) 도구로 포지셔닝하고 있습니다.

특징:
- 자동매매·매수·매도 일절 없음
- 한국투자증권 API는 read-only 영구 비활성
- 모든 분석은 사용자 user_id 인증 후 본인 데이터 한정
- 외부 배포·구독·1:1 자문 없음
- 시그널 라벨은 POSITIVE/NEGATIVE/NEUTRAL (BUY/SELL 영구 금지)
- 모든 페이지·산출물에 면책 배너 자동 첨부

질문:
1. 위 구조가 자본시장법 §17 미등록 영업행위 또는 §6 투자자문업 정의에
   포섭되나요?
2. 시그널 POSITIVE/NEGATIVE 표시가 §49 (투자권유 — 미등록자 금지)
   트리거 가능성 있나요?
3. 본 모델로 출시 가능한지, 추가로 갖춰야 할 안전장치가 있는지
   방향성 부탁드립니다.

미국 Personal Capital(현 Empower Personal Wealth) 모델 참조했는데,
한국법 적용 시 차이가 있을지 우려됩니다.
```

## 질문 2 — 마이데이터 본인신용정보관리업 (신용정보법 §22의9)

**카테고리**: 금융 / IT·정보통신

```
[질문]
핀테크 SaaS에서 사용자가 직접 발급받은 broker API 키(BYOK 모델)로
사용자 본인 계좌를 조회하는 기능을 만들었습니다.

사용 broker:
- Alpaca (미국, 사용자 BYOK + read-only)
- 한국투자증권 (한국, BYOK + read-only, 주문 영구 비활성)

회사는 사용자 자격증명을 암호화 저장 후 사용자 본인 위임으로 read-only
조회만 수행합니다. 회사 자체 신용정보 통합·재배포는 없습니다.

질문:
1. BYOK + read-only 개인용 도구가 신용정보법 §22의9 본인신용정보관리업
   인가(자본금 5억) 대상인가요?
2. Alpaca(해외 broker) 데이터가 한국 거주 사용자 단말로 들어오는 시점에
   한국 신용정보법 적용되나요?
3. Alpaca + 한투 다중 broker 통합이 §22의9 정의의 "여러 기관 신용정보
   통합"에 해당하나요?
4. 1인 창업자 입장에서 인가 회피 가능한 안전 모델은 무엇인가요?

만약 인가 필요로 판정되면 자본금 5억 트리거되어 사실상 셧다운입니다.
규제 샌드박스 신청이 가능한 사안일까요?
```

## 질문 3 — 약관 §11 책임 제한 + 디지털 콘텐츠 청약철회 (전자상거래법)

**카테고리**: 회사법 / 약관 / 전자상거래

```
[질문]
SaaS 월 구독 서비스(9,900-19,900원) 출시 준비 중입니다. 약관과 청약철회
관련 두 가지 질문 부탁드립니다.

질문 1 — 약관 §11 회사 책임 제한
이용약관 §11에 회사 책임 제한 조항을 넣었습니다. 약관규제법 §7에 따르면
"사업자의 고의 또는 중대한 과실로 인한 손해 면제는 무효"로 알고 있습니다.
다음 단서 조항을 추가했는데 충분한가요?

  "③ 본조 ①②항의 책임 제한에도 불구하고, 약관규제법 §7에 따라
  회사의 고의 또는 중대한 과실로 발생한 손해에 대하여는 회사가
  책임을 부담합니다. ④ 회사가 부담하는 손해배상 책임의 한도는,
  손해 발생 시점을 기준으로 직전 6개월 동안 회원이 회사에 지급한
  유료 서비스 이용료의 합계 금액으로 합니다."

손해배상 한도 "직전 6개월 결제액"이 합리적 수준인가요?

질문 2 — 디지털 콘텐츠 청약철회 제한
SaaS 월 구독을 전자상거래법 §17 ② 5호 "디지털 콘텐츠"로 분류해서
14일 청약철회를 일부 제한할 수 있나요? 약관에 어떻게 명시해야 적법한가요?
```

## 답변 활용 가이드

### 답변 받으면 할 일

1. **답변 변호사 정보 메모** — 사무실 / 분야 / 톤. 유료 자문 시 후보로 적합.
2. **답변끼리 비교** — 1357 + 핀테크지원센터 + 로톡 답변이 다 일치하면 신뢰도 ↑. 다르면 → 유료 변호사한테 cross-check 필수 항목.
3. **"추가 검토 필요" 답변** — 이 항목은 무조건 유료 자문에 가져감.

### 답변 안 오면

1주일 안에 답변 0개면:
- 질문 다시 작성 (더 짧게, 핵심만)
- 다른 카테고리로 재게시
- 또는 로톡 외 채널 (지식인, 변호사 블로그 댓글) 시도

### 무리한 답 기대 금물

로톡 무료질문 답변은:
- 길어야 5-10분 분량
- "이건 위험합니다, 자세한 건 유료 상담"으로 끝나는 경우 多
- 그래도 **방향성** 확인용으로는 충분 (그 방향성만으로도 너 결정 도움 됨)
