## 2. 서비스 본질 (가장 중요)

**한 줄 요약**: 사용자가 자기 자신의 매매·자기점검을 위해 사용하는 PFM(Personal Finance Management) 도구.

세부 특징:

- **데이터 소스**: 미국(Alpaca, FMP) + 한국(KIS — read-only 영구 비활성)
- **AI 기능**: Anthropic Claude API 기반 사용자 자가 분석 보조 (1:1 자문 X, 불특정 다수 대상 정보 제공 X)
- **퀀트 기능**: 사용자 본인 보유 종목·매매 의도에 한정한 self-analysis (시그널 라벨: POSITIVE / NEGATIVE / NEUTRAL — BUY/SELL 라벨 영구 금지)
- **거래 기능**: **자동매매·매수·매도 일절 없음** (autotrader 코드 2026-05 물리 삭제 완료, git tag legal-pre-autotrader-removal 만 보존)
- **한국투자증권**: 조회 전용 (read-only). buy_order / sell_order 함수 영구 비활성화됨.
- **Alpaca**: 시스템 키 ALPACA_ENABLED=0 (production 503 응답). 사용자 BYOK 경로만 향후 출시 예정.

회사는 **유사투자자문업 신고를 하지 않는 결정**을 내렸으며, 그 근거는 미국의 Personal Capital(현 Empower Personal Wealth) 모델을 참조한 "자기 데이터 한정 self-analysis tool" 포지셔닝입니다.

## 3. 자문 요청 사항 (3건)

### 요청 1 — 자본시장법 §17 미등록 영업행위 회피 적정성

본 서비스가 **유사투자자문업 또는 투자자문업 신고·등록 의무를 회피할 수 있는 구조인지** 확인을 요청드립니다.

회사 자체 분석:

- 모든 분석·스코어링은 **사용자 본인 user_id 인증 후 본인 데이터에 한정**하여 산출
- 5종 PDF 산출물 (year_end_letter, earnings_prebrief, credit_rating, insider_mirror, pre_trade_checklist) 모두 `generate_for_user(user_id)` 또는 `generate_for_position(user_id, ticker)` 진입점만 가짐 (즉 본인 사용자가 본인 보유 종목·매매 의도 기반에서만 생성)
- 외부 배포 / 구독 / 1:1 자문 / 불특정 다수 대상 리포트 발행 일절 없음
- 모든 산출물·시그널 페이지에 한·영 면책 배너 자동 첨부

구체적 질문:

a) 위 구조가 자본시장법 §17 (미등록 영업행위 금지) 또는 §6 (투자자문업 정의) 적용 대상인지

b) 시그널 라벨 "POSITIVE / NEGATIVE / NEUTRAL" 표시가 §49 (투자권유 — 미등록자 금지)를 트리거하는지

c) Discover 페이지에서 사용자 watchlist 외 종목의 시그널 리스트를 표시하는 것이 self-data 한정 경계를 벗어나는지

d) 면제 트랙 유지를 위해 필수로 추가해야 할 안전장치가 있는지

### 요청 2 — 신용정보법 §22의9 본인신용정보관리업 인가 필요 여부 (마이데이터)

**BYOK(Bring Your Own Key) + read-only "개인용 도구"** 모델이 본인신용정보관리업 인가(자본금 5억) 대상인지 확인을 요청드립니다.

회사 모델:

- Alpaca(미국 broker) — 사용자 BYOK + read-only
- KIS(한국 broker) — 사용자 BYOK + read-only (주문 실행 영구 비활성)
- 회사는 사용자 자격증명을 암호화 저장 후 사용자 본인 위임으로 read-only 조회만 수행
- 회사 자체적인 신용정보 통합·분석·재배포 없음

구체적 질문:

a) BYOK + read-only 개인용 도구가 §22의9 적용대상인지 (인가 필요 여부)

b) Alpaca(해외 broker) 데이터가 한국 거주 사용자 단말로 들어오는 시점에 신용정보법 적용되는지

c) Alpaca + KIS 다중 broker 통합이 §22의9 정의의 "여러 기관 신용정보 통합"에 해당하는지

d) 본 모델 유지를 위한 필수 고지·동의·약관 조치는 무엇인지

e) **규제 샌드박스 신청 권장 여부** — 본 케이스가 규제 샌드박스 적합 사안인지

### 요청 3 — 자본시장법 §57 광고 표시 의무 / advisory leak 회피 (Q9)

**서비스 페이지 + 백테스트 결과 + 페이퍼 트레이딩 기록**의 표시 방식이 §57 (투자권유 광고 표시 의무) 또는 §178 (시세조작 금지) 트리거 가능성이 있는지 확인을 요청드립니다.

구체적 질문:

a) "자문업 미등록"이어도 §57 광고 표시 의무가 적용될 가능성

b) 백테스트 과거 수익률 표시가 §178 (시세조작) 또는 §57 (광고규제) 트리거하는지

c) 페이퍼 트레이딩(가상 매매 시뮬레이션) 결과의 BUY 라벨 표시가 §49 투자권유 트리거하는지 — 회사는 BUY rationale에 자동 안전장치(legal_filter.safe_scrub) 적용 완료

d) "PRO 배지", "Premium 기능" 표시가 광고 표시 의무 위반인지
