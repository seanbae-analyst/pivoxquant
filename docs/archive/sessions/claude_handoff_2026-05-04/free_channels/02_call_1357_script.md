# 1357 중소기업통합콜센터 — 통화 스크립트

**채널**: 1357 (전화) — 법무부 중소기업 법률지원단
**비용**: 무료
**예상 시간**: 1회 30-60분 (질문 7개라 길게 잡아야 함)
**커버 질문**: Q2 (5 PDF 자기 데이터 한정), Q4 (PIPA §28-8), Q6 (회원탈퇴 보존), Q7 (데이터 라이선스), Q8 (audit 2년), Q11 (사업자 명의), Q12 (표시광고법)

**전화 시간**: 평일 09:00-18:00 (점심 시간 12:00-13:00 회피)
**전화 방식**: 국번없이 1357 → 4번 (법률) → 5번 (또는 안내 따라)
**카톡 옵션**: 카카오톡 "중소기업통합콜센터" 플러스친구 추가 → 동일 자문 가능 (텍스트 기반, 신속)

## 질문 7건 — 각 1-3분씩

### Q2 — 5종 PDF 산출물 자기 데이터 한정 면제 적정성

```
"사용자 본인 데이터로 본인을 위한 5종 PDF 산출물을 만듭니다.
예: 'OO님의 1년 매매 회고', 'OO님 보유 종목 결산 직전 정리'.
모두 사용자 user_id 로그인 후 본인 데이터에서만 생성됩니다.
외부 배포·구독 없습니다.
이게 자본시장법 투자자문업 신고 대상에 해당되나요?"
```

추가 질문:
- 만약 "자기 데이터"라도 5요인 점수(0-100)를 부여하면 신용평가업 트리거되는지
- 모든 PDF에 면책 배너 첨부하면 안전한지

### Q4 — 개인정보 국외이전 (PIPA §28-8) 별도 동의

```
"개인정보가 미국 회사로 위탁됩니다 — Anthropic(Claude AI), Stripe(결제),
Vercel(프론트), Railway(백엔드), Google(OAuth).
2024년 9월 시행된 PIPA §28-8 따라 별도 동의가 필요하다고 알고 있습니다.
회원가입 화면에 5번째 필수 체크박스를 추가했고, 처리방침에 위탁처 표를
명시했습니다. 이 정도면 §28-8 별도 동의 요건 충족하나요?"
```

추가:
- AI 채팅 내용을 미국 Anthropic으로 보내는 것이 "민감정보 국외이전"으로 가중 동의 필요한지

### Q6 — 회원탈퇴 시 거래기록 보존 (전자상거래법 vs PIPA)

```
"전자상거래법 시행령 §6은 거래기록 5년 보존,
PIPA §37은 회원탈퇴 시 즉시 파기를 요구합니다.
이 둘이 충돌하는데 어느 쪽이 우선인가요?
권장 정책은 'soft delete + 결제기록만 분리 보존(이름·이메일 익명화)'으로
가는 게 맞나요?"
```

### Q7 — 외부 데이터 라이선스 재배포

```
"FMP라는 미국 데이터 제공자한테 월 29달러 결제하고 가공해서
SaaS 사용자에게 보여줍니다. 이게 '재배포(redistribution)' 위반인가요?
또 한국투자증권 OpenAPI는 본인 계좌 외 사용 금지 조항이 있는데,
사용자가 자기 키로 자기 계좌만 조회하는 BYOK 모델은 위반 아닌가요?"
```

### Q8 — AI 산출물 audit log 2년 보존 의무

```
"Journal Companion이라는 기능에서 AI가 생성한 산출물을
사용자별로 2년 보존합니다 (audit log).
이 보존 의무 법적 근거가 뭔가요? 전자금융거래법 §22 vs 자본시장법 §401?
회원탈퇴 시 user_id를 NULL로 익명화하고 audit row만 남기는 게
PIPA에 적법한가요?"
```

### Q11 — 사업자등록 명의 (부친 vs 본인)

```
"제가 취준생 신분이라 사업자등록을 부친 명의로 할까 본인 명의로 할까
고민입니다. 법률 책임 분배 측면에서:
- 부친 명의 시 PIPA 정보주체 청구가 부친한테 가나요?
- 자본시장법 위반 시 처벌이 부친한테 가나요?
- 운영 실체와 명의가 다를 때 책임 분배는 어떻게 되나요?
세무 영향은 별도 세무사한테 문의할 예정입니다."
```

### Q12 — 표시광고법 §3 (기만표시)

```
"예시 화면에서 'AAPL', 'TSLA' 같은 가짜 ticker로 시뮬레이션 결과를 보여줍니다.
실제 종목 아니지만 사용자가 실제로 보일 수 있어요.
표시광고법 §3 기만표시 위반인가요?
백테스트 '과거 수익률' 표시가 자본시장법 §178 시세조작에도 걸리나요?"
```

## 통화 후 처리

1. **즉시 메모**: 통화 끝나자마자 7개 질문별 답변 한 줄씩 메모 (전화기 메모앱)
2. **녹음 검토**: 녹음했다면 다시 들으면서 누락 답변 식별
3. **남은 질문**: Q1 (§17 면제), Q3 (마이데이터), Q5 (약관), Q9 (advisory leak), Q10 (Mentor Match) 5개는 1357로 못 풀린 거 → 핀테크지원센터(Q1/Q3/Q9) + 유료 변호사(Q5/Q10)
4. **법무부 정식 신청**: 1357 통화에서 "정식 서면 자문 받고 싶다" 요청 시 안내 받은 절차로 추가 진행

## 통화 안 되면 — 카카오톡 채널

카톡 "중소기업 통합콜센터" 플러스친구 추가 → 위 7개 질문을 1개씩 분리해서 텍스트로 송부.

각 질문 ~500자 이내로 압축. 답변 받으면 캡처 보관.

## 참고

- 법무부 중소기업 법률지원단: 사업자등록 전이어도 "예비창업자" 자격으로 자문 가능한 경우 多. 첫 통화에서 막히면 다른 상담사로 재시도해도 됨.
- 1357 답변은 책임 의견이 아닌 "방향성"임. 정식 의견서는 별도 신청 필요.
- 핀테크 전문 변호사가 매번 매칭되지는 않음. 받은 답변을 핀테크지원센터(요청서 별도) + 유료 변호사 미팅(축소 범위)에서 cross-check.
