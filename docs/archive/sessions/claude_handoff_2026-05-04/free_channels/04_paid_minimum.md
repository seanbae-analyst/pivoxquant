| 번호 | 주제 | 왜 무료로 안 되나 |
|---|---|---|
| **Q5** | 이용약관 13개 조항 + 처리방침 12개 조항 검수 | 약관 검수는 통상 변호사 별건 작업. 1357·핀테크지원센터·로톡 무료질문으로는 정밀 검수 불가. 단 자체 수정안을 변호사가 review만 해주는 형태로 **별건 견적 30-50만원** 가능 |

## 무료 → 유료 전환 트리거 (이걸 만나면 유료 가야 함)

다음 중 하나라도 발생하면 유료 변호사 미팅 추가:

- [ ] 핀테크지원센터에서 **"규제 샌드박스 신청 권장"** 답변 시 → 변호사 동행 권장
- [ ] 1357에서 답변 못 받은 항목이 3개 이상
- [ ] 로톡 답변 변호사들끼리 의견이 갈림 (해석 다툼 있음)
- [ ] 무료 답변에서 "조건부 가능 (X 충족 시)" 답변 — X가 코드/약관 수정 필요 항목이면 유료 변호사 동반 필요
- [ ] 출시 직전 "최종 확인" 1회 추가 자문 (마음의 평화용 — 30만원선)

## 유료 변호사 찾는 법

비용 최소화 모드에서는 **로톡 매칭 + 견적 비교**가 가장 효율적:

1. lawtalk.co.kr → "변호사 찾기" → 분야 "회사법" + "IT·정보통신" + "금융"
2. 견적 요청 (사연 + 첨부) → 3-5명 동시 견적
3. 견적 회신 비교 (보통 24-72시간)
4. 가장 합리적인 변호사 1명 선택
5. 약관 검수 별건 발주

**견적 요청 시 핵심 문구**: "이미 핀테크지원센터에서 사전 컨설팅 받았고, 본 자문에서는 약관·처리방침 검수만 부탁드립니다. 별건 견적 부탁드립니다."

→ "이미 다 정리된 상태"라는 신호 → 견적 ↓
