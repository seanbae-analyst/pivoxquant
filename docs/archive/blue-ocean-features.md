## Executive Summary

**현재 상황 (기존 38개 평가)**: 기존 38개는 전부 "도구형(tool)" 또는 "정보형(info)"이다. 이건 **기능적으로 정확하지만 감정적으로 허전하다**. 이유는 단순하다 — 사용자가 "매일 열 이유(daily trigger)"와 "자기 것이라는 소유감(ownership)"이 빠졌기 때문이다.

**사각지대의 본질**:
1. **"데이터가 나에 대해 말해준다"의 결여** — 38개 중 개인화 기능은 6개뿐, 그중 진짜 거울 역할은 0개
2. **"오늘 할 일"의 결여** — 38개 중 일일 루틴 트리거는 2개뿐, 주로 세제/백테스트 등 이벤트성
3. **"사회적 인증(social proof)"의 결여** — Paper 토너먼트 1개, 나머지는 고립된 경험
4. **"미래 자아 시뮬레이션"의 결여** — FIRE 계산기 1개, 진짜 감정 건드리는 건 없음
5. **"국가/공공 데이터 × 개인 포지션"의 결여** — DART/SEC 타이틀 노출만, 연결이 없음

**권고 방향**: 38개는 "도구 상자"이고, 새 30개는 "거울 + 의식(ritual) + 서사(narrative)"이다. 두 축이 만나야 "허전함"이 사라진다.

**핵심 통찰**: 38개의 합계 Score는 높지만 **바이럴 계수(K-factor)**는 낮다. 이 문서의 Top 10은 Score를 일부 희생하더라도 **기억에 남는 장면(memorable moment)**을 만드는 데 집중한다.

## A. 신규 아이디어 30개

### Z1. Mirror (행동 거울) — 5개

#### A1. 투자자 DNA 리포트 (Investor DNA)
- 사용자 거래내역 분석 → 16가지 투자자 유형 중 매칭 (MBTI 스타일)
- 예: "손절 회피형 + 급등주 추종 + 아침 매매 집중 → 'FOMO 초보 (F-type)'"
- 매월 1회 리포트, 유형 변화 추적 ("F → V로 진화 중")
- 기존 `investor_profiles.py`(8유형) 확장 재활용
- 저작권/법적: 본인 데이터 분석, 자본시장법 해당 없음

#### A2. 감정 히트맵 캘린더 (Emotion Heatmap)
- 내 1년 매매 → 달력 히트맵으로 표시
- 색상 = 실현 손익, 글자 = 매매 횟수
- "월요일 11시마다 손절" 같은 **시간대 패턴** 자동 발견
- 깃허브 contribution 스타일, 스크린샷 바이럴

#### A3. 두 번째 뇌 — 결정 저널 (Second Brain)
- 매수/매도 시 "왜?" 입력 강제 (선택형 + 서술)
- 30일 후 자동 알림: "30일 전 당신이 쓴 이유 + 결과" 비교
- 장기적으로 "당신의 매수 이유 중 맞았던 것 Top 5" 자동 추출
- 기존 "투자 저널"(#30)과 차별점: **회고 강제 + 검증 자동화**

#### A4. 거울 차트 (Mirror Chart)
- 내 매매 타이밍을 주가 차트 위에 화살표로 오버레이
- "당신은 고점 3일 전에 팔았다" 같은 구체적 피드백
- 종목 상세 페이지 내 탭으로 통합
- 기존 "Buy&Hold vs Trading"(#41)의 시각화 확장

#### A5. 성격 × 포트폴리오 매칭도 (Self-Alignment Score)
- 온보딩 설문("보수적/공격적") vs 실제 포트폴리오 비중 비교
- 불일치율 0-100% ("당신은 자기가 생각하는 것보다 3배 공격적")
- 매월 업데이트, 차이 줄이기 코칭 (정보성)

### Z2. Ritual (일일 의식) — 3개

#### A6. 아침 브리핑 (3-Minute Morning)
- 평일 오전 6시 푸시: "당신의 보유종목 3줄 요약"
  - 미국장 마감 결과 (내 종목만)
  - 오늘 국장 개장 시 주목할 내 종목 1개
  - 오늘 발표 예정 경제지표 중 내 포폴 영향도 높은 1개
- 1분 안에 읽히도록 30초 × 3블록 구조
- 기존 "실적 D-1 알림"(#38)과 차별점: **매일 + 종합 + 개인화**

#### A7. 저녁 회고 (5-Minute Debrief)
- 국장 마감 후 오후 4시: "오늘 포트폴리오 -1.2%, 원인 3개"
- 기여도 분해 (contribution attribution): 어떤 종목이 얼마나 끌어내렸나
- 사용자가 "감정 기록" 1클릭 입력 (😠 / 😐 / 😊)
- 30일 누적 시 **감정 vs 수익률 상관관계** 그래프 제공

#### A8. 주간 체크포인트 (Sunday Reset)
- 일요일 오후 7시 카드 3장:
  1. 지난주 포폴 성과 vs 벤치마크
  2. 다음주 주요 일정 (실적/FOMC/내 종목)
  3. "이번 주 한 가지 행동" 프롬프트 (선택지 5개)
- 습관 형성 핵심, 리텐션 최강 트리거

### Z3. Public Data Alchemy (공공 데이터 × 내 포지션) — 5개

#### A9. 국민연금 동행 지수 (NPS Tracker)
- 분기별 국민연금 5% 이상 지분 공시 (DART, 공공)
- "국민연금이 내 종목 샀다/팔았다" 알림
- 1년 추이 차트 + "국민연금 Top 20 매수 종목" 테이블
- 자본시장법 회피: "사실 전달" 포지셔닝, 추천 X
- 사각지대 이유: 경쟁사 전무, 공공데이터 무료

#### A10. FRED 시그널 대시보드
- 10개 핵심 지표 (10Y-2Y 스프레드, ISM, 소비자신뢰지수 등)
- 각 지표 현재치 vs 과거 불황 시점 비교
- "2000년/2008년/2020년 수준 대비 현재" 게이지
- 내 포폴 베타와 연결: "리세션 신호 시 내 포폴 예상 낙폭"

#### A11. 한은 통계 × 섹터 매칭
- 한국은행 통계 API (기준금리, 환율, 수출입) + 섹터 지수 상관관계
- "원/달러 +3% 시 화장품 섹터 평균 +4.2%" 같은 역사적 상관성
- 내 포폴 섹터 구성 → 환율 변동 민감도 자동 계산

#### A12. KOSIS 인구/소비 × 종목 연결
- 통계청 데이터 (1인가구 증가, 고령화, 소비 트렌드)
- "1인가구 10년간 +40% → 편의점/간편식 섹터 CAGR 8.7%" 같은 구조적 트렌드
- 내 포폴 중 해당 메가트렌드 노출도 점수화
- 학생 창업자 스토리와 잘 맞음 (사회과학적 투자)

#### A13. 국토부 부동산 × 종목 연결
- 국토부 실거래가 API (공공)
- "서울 아파트 거래량 -30% → 가구/건자재 섹터 6개월 후 -12% 역사 패턴"
- 내 포폴 중 부동산 연관 섹터 노출도
- 사각지대 이유: 부동산 데이터를 주식에 연결한 서비스 전무

### Z4. Future Self (미래 자아) — 3개

#### A14. 20년 후 편지 (Letter to Future Self)
- 사용자가 지금 "20년 후 나에게" 편지 작성 (목표 금액, 이유)
- 매년 같은 날 열람, 진행률 자동 계산
- 예: "집 사기 3억 → 현재 8,400만원 (28%)"
- 감정적 hook 최강, 바이럴 없지만 리텐션 극대화

#### A15. 후회 시뮬레이터 (Regret Simulator)
- "만약 2020년에 월 50만원씩 QQQ 넣었다면" 계산 후
- **현재 "하지 않은 금액" 표시** → "지금 시작하면 20년 후에도 후회할 기회비용: ?"
- 감정 자극 최강, 전환율 드라이버
- 면책: 과거 수익률, 미래 보장 X

#### A16. 인생 이벤트 매칭 (Life Events × Money)
- 결혼/출산/내집마련/은퇴 연도 입력
- 각 이벤트 월에 "필요 금액 vs 예상 잔고" 자동 계산
- "2032년 결혼 자금 5천만 부족 → 매월 +23만원 저축 필요"
- 기존 FIRE 계산기(#14)와 차별점: **다이벤트 + 역산 액션**

### Z5. Kimchi Premium (한국 특화) — 3개

#### A17. ISA/연금저축 통합 시뮬레이터
- 일반 계좌 vs ISA vs 연금저축 동일 투자 시 10년 후 차이
- 세제 혜택 자동 반영 (ISA 200만 비과세, 연금저축 16.5% 세액공제)
- "현재 납입 패턴 유지 시 향후 세금 절감액" 가시화
- 사각지대 이유: 3가지 계좌를 한 화면에 비교하는 서비스 없음

#### A18. 증권사 간 이관 비용 시뮬레이터
- 내 보유 종목 CSV → "A증권사 → B증권사 이관 시 총 수수료"
- 수수료 차익 10년 시뮬 (매매 빈도 반영)
- "키움 → 토스 이관 시 10년 수수료 절감액: 147만원"
- 파워유저용 킬러, Pro 전환 트리거

#### A19. 청년도약/희망적금 × 주식투자 비교
- 청년 대상 정부 상품 vs ETF 적립 10년 비교
- 정부 상품 기여금 + 비과세 vs 주식 평균 수익률
- "청년도약 5년 만기 후 남은 돈으로 VOO 10년 vs 처음부터 VOO 15년"
- 한국 MZ 타겟 정확, SEO 트래픽 기대

### Z6. Counterfactual (반사실) — 3개

#### A20. 안 팔았다면 (Never Sold)
- 과거 매도 내역 → "그대로 들고 있었다면" 현재 가치
- "당신이 판 종목 중 가장 후회할 매도 Top 3"
- 냉정한 진실 기능, 감정 자극
- 기존 "Buy&Hold vs Trading"(#41)보다 더 잔인 = 더 기억에 남음

#### A21. 평행우주 포트폴리오 (Parallel Portfolio)
- 사용자의 최근 매매 N개를 "반대로 했다면" 시뮬
- "당신이 손절한 날 사고, 익절한 날 팔았다면 지금 얼마?"
- 오히려 "내 판단이 맞았다" 확인 시 자신감 부스트
- 한쪽으로 편향된 결과만 보여주지 않음 (객관성)

#### A22. 유사 상황 역사 검색 (Similar Situation)
- 현재 시장 상태 (VIX, 금리, 유가) → 과거 유사 시점 3개 자동 매칭
- "지금과 가장 비슷한 시점: 2011.08 / 2015.08 / 2018.12"
- 해당 시점 이후 3/6/12개월 시장 움직임 요약
- 면책 강력 필수, 패턴 매칭 기반 (예측 X)

### Z7. Social Witness (사회적 증인) — 3개

#### A23. 결정 챌린지 (Decision Challenge)
- 매매 전 "친구에게 물어보기" 버튼
- 익명 링크 → 친구가 투표 (매수/매도/유지)
- 30일 후 "당신 vs 친구들 평균" 결과 공개
- 바이럴 계수 최강, 한국 카카오톡 문화 맞춤

#### A24. 종목별 유저 집단지성 (Crowd View)
- 특정 종목에 대해 PivoxQuant 유저의 익명 집단 포지션 통계
- "이 종목 보유 유저 평균 수익률 +12%, 평균 보유기간 87일"
- 추천 아님, **사실 통계** (자본시장법 회피)
- "집단이 나보다 낫다/못하다" 관점 제공

#### A25. 투자 트윗 (Invest Tweet)
- 매매 내역을 **수익률 가리고 종목만** 자동 카드 생성 → X/카톡 공유
- 사후 공개 (30일/90일 후 실제 결과 자동 공개)
- "공개 약속" 효과로 신중한 매매 유도 + 바이럴
