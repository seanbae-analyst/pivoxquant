## 인프라 개선

- **Railway PostgreSQL 전환**: SQLite → Postgres, `DATABASE_URL` 환경 변수 참조 방식 전환
- **Agent 생태계 Iron Rules 적용**: agent .md 파일 70개 + SKILL.md 54개에 6개 Iron Rule 일괄 추가
  - No assumption skipping / Partial != Complete / Reasoning != Verification / Evidence required / Brand PivoxQuant / Permission denied = ESCALATE
- **신규 agent 7개 추가**: `verify-ux` / `verify-api` / `verify-data` / `verify-design` / `verify-security` / `investigate-bug` / `bug-hunter`
- **브랜드 통일**: `stockpilot` → `pivoxquant` 53개 파일 일괄 교체 (디렉토리명 `stockpilot/` 유지)
