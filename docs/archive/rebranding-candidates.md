## 0. 네이밍 브리핑 요약 (Executive Summary)

**문제:** `stockpilot.com` 도메인이 선점됨. 완전한 리브랜딩 필요.

**목표:** 3~12글자, 자본시장법 저촉 없음, 한영 모두 자연스러움, 도메인 확보 현실성 있음, "친구한테 자랑하고 싶은" 바이럴 가능한 이름.

**제약 재확인:**
| 항목 | 기준 |
|------|------|
| 자본시장법 Red Flag | investment/advisor/advisory/recommendation/signal/alpha/return/profit/trading 금지 |
| 길이 | 3~12자 (도메인 기준) |
| 발음 | 한국인·영어권 모두 발음 가능 |
| 예산 | 도메인 $100 이하 (.com 선점 시 .io/.ai/.co 대안) |
| 경쟁 충돌 | 국내 핀테크/증권사 상표 회피 |

**카피라이팅 원칙 (Ogilvy):**
> "이름은 제품의 첫 번째 약속이다. 과장하면 신뢰를 잃고, 밋밋하면 기억되지 않는다."
> — 금융 제품은 **"도구/가이드/동반자"** 톤이 맞다. **"돈 벌어주는"** 톤은 규제 리스크.

## B. 상위 20개 후보 심층 분석

> Score 125 만점 또는 전략적 가치가 높은 후보 중 20개 엄선.
> **도메인 가능성은 추정치** — 실제 실행 시 `instantdomainsearch.com`에서 검증 필요.

### 1. Quantmate (퀀트메이트) — Score 125

- **뜻:** Quant(정량분석) + Mate(친구). "퀀트 분석을 쉽게 해주는 친구."
- **발음:** 한 "퀀트메이트" / 영 /kwɒnt meɪt/
- **연상:** 친근한 AI 어시스턴트, 동료감
- **도메인 추정:** quantmate.com 가능성 중 (검증 필요), quantmate.io / .ai 높음
- **장점:** 컨셉이 명확, 법적 안전, 기억에 남음, "~메이트"가 친밀감
- **단점:** "퀀트"가 일반인에게 진입 장벽이 있을 수 있음
- **충돌 체크:** 'Quantopian' (폐업), 'QuantConnect' (개발자 대상) — 충돌 낮음

### 2. Beacon (비콘) — Score 125

- **뜻:** 봉화, 등대. "길을 밝히는 빛."
- **발음:** 한 "비콘" / 영 /ˈbiː.kən/
- **연상:** 확실한 방향, 신뢰, 등대지기
- **도메인 추정:** beacon.com 이미 선점. beacon.finance / beaconinvest.co.kr 등 조합 필요
- **장점:** 강력한 메타포, 브랜드 스토리 쉬움, 로고 아이디어 풍부
- **단점:** 너무 일반적 — 단독 도메인 불가능. 조합명 필요
- **충돌 체크:** Beacon AI, Beacon Pointe (자문사) — 금융권 충돌 높음

### 3. Nova (노바) — Score 125

- **뜻:** 신성(新星). 갑자기 밝아지는 별.
- **발음:** 한 "노바" / 영 /ˈnoʊ.və/
- **연상:** 신선함, 빛, 스타트업 감성
- **도메인 추정:** nova.com 선점. novafin / novastock / getnova 필요
- **장점:** 짧고 강함, 글로벌 발음 가능, 로고 심볼 명확
- **단점:** 너무 많이 쓰임 (Nova Labs, Nova Credit, Nova AI)
- **충돌 체크:** 국내 '노바렉스' 등 다수. 핀테크는 제한적

### 4. Sigma (시그마) — Score 125

- **뜻:** 통계학의 표준편차, 수학·과학의 정수
- **발음:** 한 "시그마" / 영 /ˈsɪɡ.mə/
- **연상:** 정밀함, 퀀트 정체성, 전문성
- **도메인 추정:** sigma.com 선점. sigmafin / sigmastock / sigmaquant
- **장점:** 퀀트 아이덴티티 완벽, 차트·지수 연상
- **단점:** 이미 'Sigma Computing'(BI), 'Six Sigma' 연관 강함
- **충돌 체크:** Sigma Lens (국내), SK Sigma (IT) — 중복

### 5. Gamma (감마) — Score 125

- **뜻:** 그리스 문자 Γ. 옵션 그릭(Greeks)의 감마 (가속도)
- **발음:** 한 "감마" / 영 /ˈɡæm.ə/
- **연상:** 2차 미분, 옵션 트레이더 감성, 정밀함
- **도메인 추정:** gamma.app 선점 (프레젠테이션 툴). gammafin / gammaquant 가능
- **장점:** 퀀트 정체성, 짧음, 밈 친화적 ("감마스퀴즈" 등)
- **단점:** gamma.app 혼동. 기억 장벽
- **충돌 체크:** Gamma (AI 프레젠테이션) — 도메인 높은 경쟁

### 6. Pi (파이) — Score 125

- **뜻:** 원주율 π. 영원한 수학의 상수
- **발음:** 한 "파이" / 영 /paɪ/
- **연상:** 수학, 영속성, 미니멀리즘
- **도메인 추정:** pi.com 선점. pistock / piquant / getpi 가능
- **장점:** 2글자의 극한 미니멀. 로고 한 글자로 완성
- **단점:** Pi Network(사기 의혹 암호화폐)와 연관 위험 높음. **제외 권고.**
- **충돌 체크:** Pi Network, Raspberry Pi — 심각한 충돌

### 7. Prism (프리즘) — Score 125

- **뜻:** 빛을 분산시켜 스펙트럼을 보이는 도구
- **발음:** 한 "프리즘" / 영 /ˈprɪz.əm/
- **연상:** 투명함, 분석, 다면적 시각
- **도메인 추정:** prism.com 선점. prismfin / prismstock / prismlabs
- **장점:** "데이터를 프리즘처럼 분해" 스토리 완벽. 시각적
- **단점:** NSA 'PRISM' 감시 프로그램 연상 (구세대 부정적)
- **충돌 체크:** Prism (수학 학습앱), PrismHR — 다수

### 8. Falcon (팔콘) — Score 125

- **뜻:** 매. 빠르고 정확한 포식자
- **발음:** 한 "팔콘" / 영 /ˈfæl.kən/
- **연상:** 속도, 정밀 타격, 날카로운 시야
- **도메인 추정:** falcon.com 선점. falconfin / falcontrade (피해야) / falconstock
- **장점:** 로고 아이디어 풍부, 남성적 강함, 월가 감성
- **단점:** Falcon X (크립토), Falcon.io (마케팅) — 경쟁
- **충돌 체크:** Jeju Air (구 Eastar) 그룹사 '팔콘' — 국내 항공사 충돌 가능성

### 9. Orca (오카) — Score 125

- **뜻:** 범고래. 바다의 지능형 포식자
- **발음:** 한 "오카/오르카" / 영 /ˈɔːr.kə/

## D. 한국 투자 서비스 네이밍 트렌드 분석

### 관찰 대상
- **토스 (Toss):** 2음절, 동사형("던지다"). 쉬운 금융의 상징.
- **카카오페이:** 모회사 이름 + 기능. 인지도 레버리지.
- **뱅크샐러드:** Bank + Salad (예상 밖 조합). 데이터 시각화 느낌.
- **크래프트 테크놀로지스 (Qraft):** 기술+장인정신. B2B 톤.
- **스냅잇 (Snapit):** Snap+It. 빠른 액션 동사.
- **블루웨일 (Bluewhale):** 자연/동물 + 규모감.
- **타이거자산운용:** 맹수 + 전통 금융사.
- **핀다 (Finda):** 대출 비교. "찾다(Find)" 변형.
- **투게더인베스트:** 사회적 관계 강조.

### 패턴 (먹히는 것)
1. **2~3음절 + 동사/명사 변형:** 토스, 핀다, 스냅잇 — **짧고 행동 유발**
2. **친근한 일상어 조합:** 뱅크샐러드, 카카오페이 — **금융을 일상으로**
3. **자연/동물 메타포:** 타이거, 블루웨일 — **스케일·신뢰 상징**
4. **-피/-다/-잇 접미어:** 토스→토스피, 카카오페이, 스냅잇 — **브랜드 패밀리화**

### 안 먹히는 패턴
- 영어+한국어 혼합 긴 이름 (예: "~테크놀로지스")
- 전문용어 직접 사용 (예: "~시스템즈")
- 1세대 증권사식 (~자산운용, ~투자증권)

### PivoxQuant 리브랜딩 시사점
- **2~3음절 + 동사 느낌** (Quantmate/Tickerly는 3음절)
- **친근한 메타포** (Stockmate = 친구)
- **-ly / -kit / -mate** 접미어가 현재 트렌드

## G. 최종 권고

### 시나리오별 추천

| 목표 | 추천 | 이유 |
|------|------|------|
| **한국 시장 우선 + 빠른 MVP** | **Stockmate** | 발음·뜻 즉각 전달, 바이럴 9.5, 도메인 현실성 |
| **글로벌 확장 목표** | **Tickerly** | 모던 SaaS 톤, 국제 발음 가능, 도메인 최강 |
| **AI/퀀트 정체성 강조** | **Quantmate** | 기술 + 친근 동시 전달, 포지셔닝 완벽 |
| **차별화 극대화 (장기)** | **Pivox** | 추상 브랜드, 검색 우위, 도메인 저렴 |
| **개발자 타겟 B2B 확장** | **Quantloop** | 기술적 정체성, AI 학습 루프 강조 |

### 마케팅부 최종 추천: **Stockmate** (1순위), **Quantmate** (2순위)

**이유:**
1. **배상현 = 1인 학생 창업자.** 브랜드 인지도 구축 비용 최소화가 최우선 → "설명 없이 이해되는" 이름이 유리
2. **한국 MVP 먼저, 글로벌은 Phase 3에서.** Stockmate는 국내 강점 + 글로벌에서도 이해 가능
3. **자본시장법 리스크 제로.** "Mate(친구)"라는 포지셔닝이 "수익 약속" 연관을 완전 차단
4. **도메인 현실성.** stockmate.co.kr / stockmate.io / getstockmate.com 등 복수 옵션 존재

### 즉시 실행 항목 (법무부·디자인부 공동 검토)

1. **도메인 실제 확인:** instantdomainsearch.com에서 Stockmate/Quantmate 계열 전수 조사
2. **상표 검색:** kipris.or.kr (특허청), uspto.gov (미국 USPTO)에서 동일/유사 상표 검색
3. **SNS 핸들 확보:** @stockmate, @stockmate_kr, @quantmate 등 Twitter/Instagram/유튜브 핸들 선점 시도
4. **로고 러프 3종 생성:** 각 TOP 2 후보별로 로고 스케치 (디자인부 의뢰)
