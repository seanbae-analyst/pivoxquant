# 안드로이드 탭 0회 — MacroDroid 레시피 (Phase 2 v3-B)

**작성일**: 2026-09-14 · 전제: [ACCOUNT_SYNC_STRATEGY_V2.md](../launch/ACCOUNT_SYNC_STRATEGY_V2.md) §Phase 2 v3-B, 웹훅은 PR #583.
**원칙**: 우리는 알림을 읽지 않는다. 유저가 자기 기기에서 자기 자동화 앱(MacroDroid)에게 "증권사 알림이 오면 이 주소로 보내라"고 시킨다. 우리는 그 요청을 받을 뿐이다.

## 왜 `.macro` 파일을 배포하지 않고 레시피를 주는가

MacroDroid 내보내기(`.macro`)는 JSON이지만 트리거·액션이 앱 내부 클래스 이름과 버전별 필드로 직렬화된다 (MacroDroid 위키 "Share macros", 포럼 "Anatomy of the .mdr file"). 기기 없이 손으로 만든 파일은 가져오기가 조용히 실패할 수 있다. **정식 배포 파일은 CEO 기기에서 아래 레시피대로 만든 뒤 "공유 → 매크로 공유"로 내보낸 것**을 쓴다(`frontend/public/samples/pivox-fill-forward.macro` 로 두고 설정 화면에서 링크). 그 전까지는 이 레시피가 SoT.

## 준비물 (유저)

1. PivoxQuant → 설정 → **가져오기 토큰** → 이름 "폰 MacroDroid" → 동의 → 발급 → 토큰 복사 (한 번만 보인다).
2. MacroDroid 설치 (무료판은 매크로 5개 제한 — 이건 1개).
3. 증권사 앱 체결 알림이 켜져 있어야 한다. 카카오톡 알림톡(한투)으로 오는 경우도 같은 방식.

## 매크로 (트리거 1 · 제약 1 · 액션 1)

### 트리거 — "알림 수신" (Notification Received)
| 항목 | 값 |
|---|---|
| 애플리케이션 | 토스증권 **또는** 한국투자증권 **또는** 카카오톡 (여러 개면 트리거를 앱별로 추가) |
| 텍스트 내용 | **포함** — `체결` |
| 대소문자/정규식 | 끄기 |
| "지속 알림 무시" | 켜기 |
| 알림 동작 | 없음 (알림을 지우지 않는다) |

> 트리거가 잡히면 MacroDroid가 매직 텍스트 `{notification}`(제목+본문)를 채운다.

### 제약 — 오작동 방지
| 항목 | 값 |
|---|---|
| "알림 텍스트에 포함" | `매수` 또는 `매도` (둘 중 하나, OR 그룹) |

체결 외 알림(입금·배당·공지)이 웹훅으로 가지 않게 한다. 서버 파서도 걸러내지만 요청 자체를 줄인다.

### 액션 — "HTTP 요청" (HTTP Request)
| 항목 | 값 |
|---|---|
| 메서드 | `POST` |
| URL | `https://pivoxquant.com/api/portfolio/imports/webhook` (로컬 테스트는 설정 화면에 표시된 주소 그대로) |
| 헤더 1 | `Authorization` = `Bearer pvx_…` (발급받은 토큰) |
| 헤더 2 | `Content-Type` = `application/json` |
| 본문 종류 | 텍스트 |
| 본문 | `{"text": "{notification}"}` |
| 타임아웃 | 30초 |
| "다음 액션까지 대기" | 켜기 |
| 응답 저장 | 변수 `pivox_resp` (선택 — 디버깅용) |

> `{notification}` 안에 큰따옴표가 있으면 JSON이 깨질 수 있다. MacroDroid 매직 텍스트 옵션에서 **"JSON 이스케이프"**가 있으면 켠다. 없으면 본문 종류를 `text/plain`으로 바꾸고 본문을 `{notification}` 만 두면 된다 — 웹훅은 `text/plain` 본문도 그대로 파싱한다.

### 선택 — 결과 알림
액션 "알림 표시": 제목 `PivoxQuant`, 본문 `대기 목록에 올렸습니다 — 앱에서 이유를 적고 승인하세요`. 응답 코드가 201이 아닐 때만 띄우려면 `{http_response_code}` 조건을 건다.

## 검증 순서 (유저 기기)

1. 매크로 저장 후 "테스트 실행" → 웹훅에 빈 알림이 가므로 `IMPORT_NO_ROWS`(400)가 정상. 401이면 토큰 오타.
2. 모의투자나 1주 체결 → 알림 → 30초 안에 PivoxQuant 기록 페이지 상단 "받은 체결 1건" 카드.
3. 설정 → 가져오기 토큰 목록의 "오늘 N건"이 올라가면 끝.

## 권한과 한계 (안내 문구에 넣을 것)

- MacroDroid의 **알림 접근 권한**은 기기의 모든 알림을 읽을 수 있는 권한이다. 매크로는 위 트리거의 "애플리케이션"과 "텍스트 포함" 조건으로 증권사·체결 알림만 다루도록 좁혀져 있고, PivoxQuant는 그 조건을 통과해 유저가 보낸 텍스트만 받는다.
- 배터리 최적화에서 MacroDroid를 제외하지 않으면 알림 트리거가 늦거나 빠진다.
- 알림에 없는 것(체결 시각의 초 단위, 수수료)은 들어오지 않는다. 그건 파일 가져오기로 보완한다.
- 여기 들어온 체결도 **승인 전에는 기록이 아니다.** 이유를 적어야 거울에 반영된다.
