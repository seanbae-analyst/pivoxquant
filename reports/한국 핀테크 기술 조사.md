# 허가 없이 쓸 수 있는 한국 핀테크 기술 지도

> 조사일 2026-10-28. 다섯 묶음의 조사 노트(`research_notes/한국 핀테크 기술 조사/`)와 리포지토리 실측을 합친 것이다. 가격·조항은 조사 당일 공식 페이지에서 읽은 것만 수치로 적었고, 2차 자료·검색 요약에 의존한 항목과 접근 실패 항목은 "확인 불가"로 남겼다. **이 문서는 법률 자문이 아니다** — 법 해석이 걸린 판단은 모두 변호사 확인 대상으로 표시했다.

한국 개인투자자용 투자 기록·자산관리 앱의 기술은 **"허가·계약이 전제인 기술"과 "누구나 쓰는 기술"로 뚜렷하게 갈리며, PivoxQuant 의 비표준 선택들(시세 미표시·수동 입력과 캡처 판독·AI 기본 꺼짐·PWA·브로커 미연동)은 전자를 통째로 피한 결과라 서로 모순이 없다.** 허가·계약 쪽에는 마이데이터(최소자본금 5억 원 + 트래픽 비례 과금, 2024년 산업 전체 328억 원), 코스콤 시세 정보이용계약(법인 전용, 금액 비공개), 증권사 제휴 API(투자자문·일임업자만), 본인확인기관(건당 과금) 이 있고, 누구나 쓰는 쪽에는 소셜 OAuth, OpenDART·SEC 공시, 수출입은행·ExchangeRate-API 환율, 브라우저 OCR 과 LLM 추출, 매니지드 클라우드가 있다. 그래서 **지금 바로 할 수 있는 것**은 공시·재무·환율의 무료 원천 정리, 텍스트 기반 체결 알림 파싱(정규식 1차 + LLM 2차), 추출 모델의 Haiku 등급 하향(장당 약 $0.0004), 그리고 2026-10-31 전후 적용되는 안전성 확보조치 개정(운영자 접속기록·외부접속 2차 인증·내부관리계획) 대응과 Redis 레이트리밋이다. **조건부**는 미국 시세 표시(Tiingo 표시 재배포 라이선스 스타트업 USD 250/월 — 표 매핑은 추정, 한국 종목 미포함 / FMP Data Display Agreement 는 가격 비공개), 국내 시세(코스콤 — 법인 설립·금액 확인 불가), 유저 본인 증권사 키 연동(토스 약관의 키 대여·제3자 배포 금지와 충돌, 변호사 확인), 국내 PG 유료화(사업자 등록·통신판매업 신고), AI 판독 켜기(국외이전 고지 + AI기본법 §31 사전고지)다. **현실적으로 불가**는 마이데이터 허가, KIS 제휴, 무료 벤더 시세의 유저 표시(약관 위반), iOS 에서 타 앱 알림 자동 읽기다. 고쳐야 할 것은 **환율 경로가 FMP 우선인데 화면은 ExchangeRate-API 출처를 표기하는 불일치**(FMP §2.2.2 와 충돌), 한국 법인으로는 개설이 막힌다는 증언이 다수인 Stripe, 법이 요구하지 않는 "국외이전 필수 동의" 체크박스, 무기한 보관되는 `auth_events`, 인스턴스 로컬 `memory://` 레이트리밋, 처리방침의 Supabase 법인명이고, 그대로 둬도 되는 것은 PWA·시세 미표시·브로커 미연동·AI 추출 전용·본인확인 미도입·ISMS-P·FDS 미도입·`legal_filter` 단일 방어선(단 외부 검증 필요)이다.

## 데이터 연동: 허가와 약관이 자동 수집 경로를 세 갈래로 좁힌다

한국에서 "증권사 → 제3자 앱" 자동 전송을 허가 없이 받을 수 있는 공식 경로는 2026년 현재 사실상 없다. 마이데이터는 2022-01-05 부터 스크래핑이 전면 금지되고 사업자는 API 로만 서비스할 수 있게 됐으며([금융위원회 보도자료](https://fsc.go.kr/no010101/77182?curPage=3)), 허가 요건은 도입 이후 완화된 적이 없다 — **최소자본금 5억 원, 해킹 방지·망분리 보안설비, 사업계획 타당성, 대주주·임원 적격성, 전문성**의 6요건에 예비 2개월 + 본허가 1개월 최소 3개월 심사다([금융감독원 허가설명회 자료](https://www.smallake.kr/wp-content/uploads/2020/07/허가설명회-금융감독원.pdf), [금융위원회](https://www.fsc.go.kr/no010101/74444?curPage=40)). 1인 창업자에게 자본금보다 무거운 것은 운영비 구조다. 정기전송 과금은 건당 단가가 아니라 **트래픽 점유율로 배분**되고(3년 평균 매출 80억 원 이하 중소사업자 50% 감면, 시행 1년 이내 면제), 산업 전체 과금이 2023년 282억 → 2024년 328억 원으로 늘었는데 고유업무 수익은 2024년 46억 원에 그쳤다([MTN](https://news.mtn.co.kr/news-detail/2024011010293768614), [한국데이터경제신문](https://www.dataeconomy.co.kr/news/articleView.html?idxno=42752)). 그 결과 69개 허가사 중 12곳(통신 3사 포함)이 반납해 2026-07 말 57개사가 영업 중이며([한국데이터경제신문](https://www.dataeconomy.co.kr/news/articleView.html?idxno=35905), [머니투데이](https://www.mt.co.kr/finance/2026/05/03/2026042916074119033)), 2026-08-25 「마이데이터 발전방안」은 허가 요건 완화나 금투 정보 확대가 아니라 업무범위 확대·AI 에이전트 대리행사 쪽이다([네이트뉴스](https://m.news.nate.com/view/20260825n25839)). 등록제 전환이나 자본금 인하를 기대할 근거는 이번 조사에서 하나도 나오지 않았다.

증권사 Open API 는 2025–2026년에 개인 대상으로 활짝 열렸지만, 약관은 **"유저가 자기 키를 제3자 앱에 넣는 것"을 허용하는 쪽으로 열리지 않았다.** 한국투자증권 KIS Developers 는 제3자 서비스 제공 법인의 제휴를 "제도권 금융회사(투자일임업·투자자문업)"로 한정하고 핀테크사를 명시적으로 배제하며, 제휴 없이 되는 것은 "법인 소유 계좌를 통한 이용"뿐이다([KIS Developers 제휴 안내](https://apiportal.koreainvestment.com/provider), [제휴 제안 등록](https://apiportal.koreainvestment.com/provider-apply)). 제휴 이용기관용 약관(2025-06-04 개정) 원문은 "이용기관이 개인의 오픈 API 서비스 권한을 얻어 대행"하는 구조와 1년 단위 재신청을 규정한다([한국투자증권 약관 PDF](https://file.koreainvestment.com/updata/namo/09101613%EC%98%A4%ED%94%88API%EC%84%9C%EB%B9%84%EC%8A%A4%EC%9D%B4%EC%9A%A9%EC%95%BD%EA%B4%80_%EC%A0%84%EB%AC%B8.pdf)). 토스증권 Open API(2026-08-13 정식 출시)는 공식 FAQ 원문이 **"API를 통해 제공받는 정보는 투자자 본인의 매매 목적에 한하여 이용… 비상업적인 용도라 하더라도 제3자에게 배포하는 행위는 엄격히 금지"**라고 못 박고([토스증권 FAQ](https://openapi.tossinvest.com/openapi-docs/faq.md)), 약관은 앱키·시크릿키의 대여·양도·제3자 누설 금지와 법인 고객 제외를 담고 있다 — 단 약관 페이지는 JS 렌더링이라 조문 번호·원문은 **확인 불가**이고 검색 요약으로만 확보했다([토스증권 약관 id=752](https://corp.tossinvest.com/en/terms/v2?id=752)). 토스는 고정 IP 등록이 필수라 IP 가 바뀌는 클라우드·모바일 환경은 403 으로 차단되고, 체결 건별 REST 조회가 없어 주문 1건이 1행이며 실시간 체결은 웹소켓 `personal:order` 로만 받는다([토스증권 overview](https://openapi.tossinvest.com/openapi-docs/overview.md)). 반면 KB증권(2026-07-20 오픈베타)은 잔고·체결 내역 조회를 제공하고 제3자 제한 언급이 없다([머니투데이](https://www.mt.co.kr/stock/2026/08/04/2026080414364184356)) — 약관 원문은 미확인이다. 전자금융거래법 §6③ 의 접근매체 대여 금지가 API 키에 적용되는지에 대한 당국 해석·판례는 2026-10 기준 찾지 못했고, 대법원 2020도16468 은 "대가 수수 + 관리·감독 없는 사용"을 대여의 요건으로 봤지만 통장·계좌 사안이다([korea.legal](https://korea.legal/wiki/%ec%a0%91%ea%b7%bc%eb%a7%a4%ec%b2%b4-%ea%b8%88%ec%a7%80%ed%96%89%ec%9c%84/)).

나머지 경로는 목적에 맞지 않거나 가격이 비공개다. 오픈뱅킹의 증권사 참여(2020-12, 13개사 + 4개사)는 "사용자 본인계좌 **입출금내역** 조회"라 보유 종목·체결은 받을 수 없고, 처리대행비용은 2021년 기준 잔액조회 3원·거래내역 10원이었다([금융위원회](https://www.fsc.go.kr/no010101/75016)). 쿠콘·헥토데이터(옛 코드에프) 같은 중개사는 "최초 도입비 + 월 수수료" 구조에 스타트업 요금표가 없고([머니투데이](https://www.mt.co.kr/stock/2021/04/12/2021041108060512807)), CODEF 는 "엔드 유저 계정 정보 등록"으로 Connected ID 를 발급하는 — 즉 유저의 증권사 ID/비밀번호나 인증서를 중개사가 받아 스크래핑하는 — 구조다([easycodefgo](https://pkg.go.dev/github.com/smallfish06/krsec@v0.18.0)). 2025-07 개인정보위 담당 과장은 비사업자 스크래핑에 대해 "내년에는 실태점검에 나설 예정"이라 밝혔고 쿠콘은 "실제 처리자는 고객사"라는 입장이라([이데일리](https://v.daum.net/v/Pd4btQ3Ivc)), 중개사를 써도 규제 리스크는 핀테크 쪽에 남는다. 마이데이터 중계기관 경로는 수신자가 마이데이터 사업자여야 하므로 허가 문제를 우회하지 못한다.

그래서 허가·제휴 없이 남는 경로는 셋이다 — 유저 직접 업로드(CSV·캡처 OCR), 알림 파싱, 유저 본인 키를 본인 환경에서 쓰는 구조. 알림 파싱은 가장 쟁점이 적다. 토스증권 종합계좌약관 원문은 "계좌 내 자산의 변동"을 푸시·알림톡·문자 중 **고객이 설정한 채널**로 통보한다고 규정하므로 알림을 켜고 앱에 옮기는 것은 고객 자신의 행위다([토스증권 종합계좌약관 PDF](https://home-files.tossinvest.com/files/notice/7009c29c-718f-4114-b2bf-d27711e1303a.pdf)). 다만 **증권 체결 알림을 파싱해 매매일지를 자동 기록하는 한국 앱 사례는 찾지 못했다** — 가장 가까운 선례는 뱅크샐러드의 카드 승인 문자 인식(2016)이고([한경매거진](https://magazine.hankyung.com/business/article/201602295405b)), 매매일지 앱(Toffs·Trady·하루매매일지·주식일기)은 전부 수동 입력이다. 기술적으로 Android 는 `NotificationListenerService`(API 18+, 사용자가 설정에서 켜야 함)로 가능하지만([Android Developers](https://developer.android.com/reference/android/service/notification/NotificationListenerService)) iOS 는 서드파티 앱이 타 앱 알림을 읽을 수 없어 단축어·공유 시트 수준이 상한이다. 증권사별 체결 문자 포맷 사전은 공개 자료가 없어 직접 수집해야 한다.

## 시세는 돈이 들고, 공시·재무·환율은 무료다

국내 상장주식 시세를 제3자 앱 이용자에게 보여주는 길은 **코스콤 "정보이용계약" 하나**다. 무료 경로 세 개는 전부 약관이 막는다. 금융위 주식시세정보(공공데이터포털 15094808)는 공공누리 제4유형(상업적 이용금지·변경금지)에 **"상업적 목적 여부와 상관 없이 제3자 무단 제공 및 재배포가 엄격히 금지"**이며 T+1 갱신에 52주 고저 필드도 없다([data.go.kr 15094808](https://www.data.go.kr/data/15094808/openapi.do)). KRX Open API 약관(시행 2025-12-26)은 제6조② "비상업적인 목적으로만", 제11조② "제공받은 정보를 제3자에게 제공할 수 없다"고 못 박는다([KRX Open API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)). 증권사 개인용 API 시세는 KIS 가 "KRX 및 해외거래소와의 정보이용계약을 체결하셨는지 확인"을 요구하고, 코스콤 계약이 없으면 제휴사 앱에도 시세 표출이 불가하다고 안내한다([KIS Developers](https://apiportal.koreainvestment.com/provider)). 코스콤 쪽 제도권 경로는 KRX Data Marketplace 브로셔의 외부제공권한 **[옵션3] "웹사이트 및 모바일용 애플리케이션을 통해 일반대중에게 체결가 정보 제공, 사용자 수에 관계없이 정액제"**가 소규모 앱에 가장 가깝고([KRX 브로셔 PDF](https://data.krx.co.kr/inc/datasale/Market%20Data%20Product%20Brochure.pdf?v=20250732)), 코스콤 오픈API플랫폼은 법인 전용이되 **"중소기업 업력 7년 미만의 기업에게는 기본료 면제(36개월간)"** 정책이 있다([코스콤 FAQ](https://koscom.gitbook.io/open-api/faq/oppf)). 그러나 **원화 요율은 브로셔·FAQ·블로그 어디에도 없어 확인 불가**이며 시장데이터영업팀 견적이 유일한 방법이다.

미국 시세도 개인용(self-serve) 플랜은 전 벤더가 "personal, non-commercial" 이고, 유·무료를 가리지 않는다. FMP 약관 §2.2.2 는 **"Without a specific agreement with FMP, customers are prohibited from showcasing FMP Services or Data on… applications designed for utilization by multiple individuals, irrespective of whether such usage is complimentary or paid"**이고([FMP ToS](https://site.financialmodelingprep.com/terms-of-service)), 가격 페이지는 Basic USD 0 / Starter 29 / Premium 69 / Ultimate 139(월)에 "Displaying or redistributing data sourced from FMP requires a specific Data Display and Licensing Agreement"를 덧붙이며 그 Agreement 가격은 비공개다([FMP Pricing](https://site.financialmodelingprep.com/pricing-plans)). Massive(구 Polygon) Individuals 약관은 "solely for your own personal, non-commercial, and non-business purposes"에 Stocks Advanced USD 199/월 "Individual use only"([Massive ToS](https://massive.com/legal/individuals-terms-of-service), [Massive Pricing](https://massive.com/pricing)), Alpha Vantage 는 "personal, non-commercial use, unless… agreed otherwise in writing"([Alpha Vantage ToS](https://www.alphavantage.co/terms_of_service/)), Finnhub 는 "not redistribute or share access to data or derived results"다([Finnhub ToS](https://finnhub.io/terms-of-service)). 표시 라이선스를 가격까지 공개한 곳은 셋뿐이다 — Tiingo 의 EOD + IEX **"Display Redistribution" USD 250/월(스타트업) / 500/월(엔터프라이즈)**([Tiingo EOD](https://www.tiingo.com/products/end-of-day-stock-price-data); 페이지 표가 깨져 열 매핑은 추정, 한국 종목 포함 여부 미확인), Financial Datasets Professional **USD 2,000/월**("Serve our data to your own users inside your product, with attribution")([Financial Datasets](https://www.financialdatasets.ai/pricing)), Intrinio Startup(표시 허용·원시 재배포 불가, 가격은 2차 자료만)([Intrinio Licensing](https://help.intrinio.com/licensing-data-usage-requirements)). 리포 내부의 2026-09-19 판정 "무료·재배포 가능한 종가 소스는 국내·미국 모두 없다"는 이번 조사에서도 유지된다.

| 벤더 | 개인 플랜 조건(원문) | 표시·재배포 라이선스 | 가격(2026-10-28) |
|---|---|---|---|
| FMP | §2.2.1 personal, non-business | Data Display Agreement 필수 | Agreement 가격 비공개 |
| Tiingo | "Internal Use Only" | Display Redistribution | USD 250/월 스타트업(표 매핑 추정) |
| Financial Datasets | Personal USD 200/월 | Professional 재배포 포함 | USD 2,000/월 |
| Massive | Individual use only | Business 가격 페이지 404 | 확인 불가 |
| Alpha Vantage · Finnhub · EODHD · Twelve Data | personal / internal | 영업 문의 전용 | 확인 불가 |

반대로 **공시·재무·환율은 무료로 유저에게 보여줄 수 있는 원천이 있다.** OpenDART 약관(2020-01-21 시행) 원문에는 "상업·영리·재배포·제3자 제공 금지" 문구가 없고, 제11조① "원칙적으로 무료", 제16조④ "저작권법 및 공공데이터법에 따릅니다"가 전부다([OpenDART 약관](https://opendart.fss.or.kr/intro/terms.do)) — 다만 "금지 조항 부재 = 허용"은 추론이고 일 호출 한도 수치는 개발가이드 503 으로 확인 불가다. SEC EDGAR 는 "All Government-created content on sec.gov and EDGAR public filing content are free to access and reuse"에 10 req/s 상한·User-Agent 선언만 지키면 되고, XBRL companyfacts/frames API 는 키조차 필요 없다([SEC Webmaster FAQ](https://www.sec.gov/os/webmaster-faq), [SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)). 환율은 ExchangeRate-API Open Access 가 "personal or commercial currency conversion purposes" 허용에 **출처 링크 필수·일 1회 갱신·재배포 금지**([ExchangeRate-API docs](https://www.exchangerate-api.com/docs/free)), 한국수출입은행 현재환율 API(공공데이터포털 3068846)는 "이용허락범위 제한 없음"이며 구 도메인이 2026-04-30 종료되고 `oapi.koreaexim.go.kr` 로 옮겼다([data.go.kr 3068846](https://www.data.go.kr/data/3068846/openapi.do)); 한국은행 ECOS 는 페이지 본문 미수신으로 약관·한도 **확인 불가**다.

여기서 리포 실측 하나가 중요하다. `routes/market.py` 의 `/market/fx` 독스트링과 `config.py` 주석, 프론트 `fx-attribution.tsx` 는 환율이 open.er-api.com 에서 온다고 전제하고 "Rates By Exchange Rate API" 출처 링크를 단다. 그런데 `services/fx_service.py::refresh()` 는 **FMP 를 먼저 호출하고 실패하거나 일일 예산의 절반을 넘겼을 때만 exchangerate-api 로 떨어진다**(`_fetch_from_fmp()` → `_fetch_from_exchangerate_api()`). 즉 평시에 유저 화면의 USD/KRW 는 FMP 값이며, 이는 §2.2.2 "irrespective of whether such usage is complimentary or paid"와 정면으로 만나고 출처 표기도 사실과 다르다. 시세 게이트(`MARKET_DATA_DISPLAY_ENABLED`)를 환율에 일부러 안 건 설계 의도는 맞지만, 그 전제("er-api 에서 온다")가 코드에서 깨져 있다.

## 인증·보안·인프라: 의무는 적고, 2026-10-31 이 실제 숙제다

본인확인은 본인확인기관(통신3사 PASS, NICE·KCB 등)만 수행할 수 있고 일반 사업자는 이용기관으로 건당 계약을 맺는다. 공개된 단가는 2020년 보도의 휴대폰 문자 본인확인 30원 초반→약 40원([아이뉴스24](https://www.inews24.com/view/1281414))과 포트원 블로그의 다날 월정액(5만 원/1,200건 ≈ 41.7원)·KG이니시스 통합본인인증 건당 40원([PortOne](https://blog.portone.io/authorization-payment-2), 게시 시점 미표기)뿐이고 PASS·인증서의 공식 B2B 요금표는 **확인 불가**다. 핵심은 비용이 아니라 의무 여부다. 결제·송금·금융상품이 없고 주민번호를 받지 않는 서비스에 실명확인을 요구하는 현행 조항은 이번 조사에서 발견되지 않았고, 오히려 개인정보보호법 §24조의2 가 주민번호 처리를 원칙 금지하며([IT위키 §24조의2](https://itwiki.kr/w/%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4_%EB%B3%B4%ED%98%B8%EB%B2%95_%EC%A0%9C24%EC%A1%B0%EC%9D%982)) ISMS-P 기준 3.1.3 은 "주민번호 없이 가입할 수 있는 방법"을 점검한다([IT위키 ISMS-P 3.1.3](https://itwiki.kr/w/ISMS-P_%EC%9D%B8%EC%A6%9D_%EA%B8%B0%EC%A4%80_3.1.3.%EC%A3%BC%EB%AF%BC%EB%93%B1%EB%A1%9D%EB%B2%88%ED%98%B8_%EC%B2%98%EB%A6%AC_%EC%A0%9C%ED%95%9C)). 이것은 "의무 없음"의 증명이 아니라 발견 실패이므로, 소셜 OAuth 만으로 가입을 받는 PivoxQuant 구조는 "금지 근거를 찾지 못했다" 수준으로 적는 것이 정확하다. 만 14세 미만 역시 법정대리인 동의 + 시행령이 정한 확인 방법(동의 표시 후 문자 통지, 카드정보 등)이 요구되지만([법제처 생활법령](https://m.easylaw.go.kr/MOB/NtcInfoRetrieve.laf?ntcSeq=1012)) "가입자 전원의 연령을 어떤 방법으로 확인하라"는 명문은 찾지 못했다. PivoxQuant 는 `services/age_verification.py` 에서 생년월일 없이 자가선언 체크박스만 받고 14세 미만을 거부하는데, 이는 법정대리인 플로우를 피하는 합법적 설계다. 다만 프론트 `consent-stack.tsx` 가 인용하는 "PIPA §22 ⑥"은 2023-09-15 시행 개정으로 §22조의2 로 옮겨갔다는 2차 자료가 여럿이라([thecheck](https://thecheck.co.kr/child-personal-data-parental-consent/)) 조문 번호를 law.go.kr 원문으로 확인해야 한다 — 원문은 이번 조사에서 미열람이다.

전자금융거래법·감독규정은 "금융회사 또는 전자금융업자"가 수범자이고 PivoxQuant 처럼 결제 게이트가 꺼져 있고 브로커 연동이 운영자 본인 read-only 뿐인 서비스가 여기 해당한다는 근거는 없다([위키문헌 전자금융거래법](https://ko.wikisource.org/wiki/%EC%A0%84%EC%9E%90%EA%B8%88%EC%9C%B5%EA%B1%B0%EB%9E%98%EB%B2%95)) — 금융위 유권해석은 찾지 못했다. ISMS 의무대상은 정보통신서비스 매출 100억 원↑ 또는 직전 3개월 일평균 이용자 100만 명↑([IT위키 ISMS-P 인증 대상](https://www.itwiki.kr/w/ISMS-P_%EC%9D%B8%EC%A6%9D_%EB%8C%80%EC%83%81))이고, 2026-04-09 발표된 ISMS-P 실효성 강화방안은 2027년부터 "대규모 개인정보처리자"에 의무화를 예고했는데 BSA 의견서가 인용한 개정안 기준은 일일 평균 정보주체 3천만 명이다([헤럴드경제](https://www.heraldk.com/article/2026040915075146606), [BSA](https://www.bsa.org/files/policy-filings/kr07142026bsakrpipa.pdf)). 비용은 언론 보도치로 인증수수료 600만~1,800만 원 + 컨설팅 약 5,000만 원, 6~10개월이다([inews24](https://www.inews24.com/view/1028408), [fntoday](https://www.fntoday.co.kr/news/articleView.html?idxno=395214)). 클로즈드 베타와 수 자릿수 차이이므로 ISMS-P 는 의무도 현실적 선택도 아니다. 토스의 FDS(전담팀·ML·경찰청/더치트 연동, 6개월 사기 송금 15만 건 차단)는 송금이 있는 서비스의 요구이지 기록 앱의 참고 대상이 아니다([토스피드](https://toss.im/tossfeed/article/toss-fds-team)).

실제 숙제는 개인정보 안전성 확보조치 기준이다. 암호화 대상은 고유식별정보·비밀번호(일방향)·바이오정보이고, 접속기록은 1년 이상·**5만 명↑ 정보주체 또는 고유식별/민감정보 처리 시 2년**이며 정보주체 본인의 접속은 제외된다([IT위키 안전성 확보조치 기준](https://itwiki.kr/w/%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4%EC%9D%98_%EC%95%88%EC%A0%84%EC%84%B1_%ED%99%95%EB%B3%B4%EC%A1%B0%EC%B9%98_%EA%B8%B0%EC%A4%80)). 2025-10-31 시행 개정은 접속기록 보관 대상을 "처리시스템에 접속한 모든 자(정보주체 제외)"로, 외부 접속 시 안전한 인증수단 적용 대상도 같은 범위로 넓혔고 내부관리계획의 점검 주기를 자율로 돌렸는데, **이 조항들은 1년 유예라 2026-10-31 전후에 적용된다**([바이라인네트워크](https://byline.network/2025/10/31-281/)). PivoxQuant 가 보유하는 정보(이메일·이름·포트폴리오·기록 텍스트)에는 고유식별·민감정보가 없으므로 저장 암호화 의무 필드는 사실상 없고 브로커 토큰 AES-GCM(`services/crypto_service.py`)은 의무 이상이다. 그런데 거꾸로 두 가지가 비어 있다. 고시가 말하는 "접속기록"은 **운영자의 처리시스템 접속**인데 리포에 그 장치가 없고(`접속기록`·`audit_log` grep 0건 — 측정 범위 models/ services/ scripts/ app.py), 유저 로그인 로그 `auth_events` 는 고시 대상이 아닌 보통의 개인정보라 보유기간 상한을 정해 파기해야 하는데 파기 잡 없이 무기한 보관된다(`docs/legal/policy-audit-2026-09-17.md` A-7·Q-P3 미결). 1인 운영자라도 Supabase·Render·Vercel·GitHub 콘솔 2FA 와 내부관리계획 한 장은 2026-10-31 이후 기준의 최소치다 — 소규모 처리자 완화 조항이 있는지는 고시 원문 미열람으로 **확인 불가**.

국외이전은 PivoxQuant 가 "과하게" 하고 있을 가능성이 있는 유일한 지점이다. 해외 사업자 클라우드 보관은 통상 '처리위탁'으로 보고, §28조의8 ① 3호(정보주체와의 계약 이행을 위한 처리위탁·보관 + 처리방침 공개 또는 고지)로 **별도 동의 없이** 적법화할 수 있다는 해석이 일관되게 확인된다([nepla 일문일답](https://www.nepla.ai/wiki/it-정보-방송통신/개인정보-위치정보-신용정보/-일문일답-해외-클라우드-aws-등-에서-개인정보를-보관-처리할-때-정보주체의-동의를-받아야-하는가-54gnvzpe81pr), [IT위키 국외이전](https://itwiki.kr/w/%EA%B0%9C%EC%9D%B8%EC%A0%95%EB%B3%B4_%EA%B5%AD%EC%99%B8_%EC%9D%B4%EC%A0%84)). 가입 시 "[필수] 개인정보 국외 이전 동의" 체크박스(`consent-stack.tsx`)를 받는 현재 방식은 1호(동의) 경로인데, 동의 경로를 택하면 수탁자가 바뀔 때마다 재동의 의무를 스스로 만든다 — 3호로의 전환은 변호사 확인 대상이다. 서울 리전 저장이 국외이전을 면하게 하는지에 대한 개인정보위 공식 판단은 **찾지 못했고**, Supabase FAQ 는 DB·Auth·Storage·백업은 고객이 고른 리전에 두되 로그는 EU, 계정·지원·텔레메트리·CDN 은 리전 밖이며 **주 처리자는 Supabase Pte. Ltd.(싱가포르)**, 미국 법인은 지원·운영 시에만 접근한다고 밝힌다([Supabase Data Residency FAQ](https://supabase.com/legal/privacy-resources/data-residency-and-transfers-faq)). 처리방침 `privacy-ko.md` §6 의 "Supabase, Inc.(미국)" 표기는 이 FAQ 와 어긋날 수 있어 계약 당사자(Order Form/DPA)로 맞춰야 하고, `render.yaml` 의 `region: singapore` 는 리포에서 확인되므로 Render 행의 "처리 리전 싱가포르"는 맞다. AI 판독처럼 "합리적으로 예상 가능한 범위"를 벗어날 수 있는 이전만 건별 동의로 두는 현재 설계(`ai-read-offer.tsx`)는 자료와 부합한다.

결제는 기술보다 법인 구조가 먼저다. "한국에 법인을 두면 Stripe 계정 자체가 안 열린다… 대부분의 한국 SaaS 창업자들은 해외 법인을 만들어 Stripe 를 쓴다"는 증언이 다수이고([브런치](https://brunch.co.kr/@chunja07/196)) 반대 주장은 근거가 불명하며 Stripe 공식 문서는 한국 로컬 결제수단(PAYCO·Samsung Pay)만 다룬다 — **공식 지원 여부 문서는 확인 불가**다. 국내 경로는 토스페이먼츠 공식 요금 기준 가입비 220,000원 + 연관리비 110,000원 + 카드 3.4%(VAT 별도)이고 빌링 전용 요율은 페이지에 없으며([토스페이먼츠 요금](https://www.tosspayments.com/about/fee)), 2026-08-14 적용 영세·중소 우대수수료는 연매출 3억 이하 신용 0.4%~ 로 떨어지되 신규 사업자는 "일반"으로 시작해 반기 후 환급된다([금융위원회](https://fsc.go.kr/no010101/86274?curPage=4)). 통신판매업 신고는 직전년도 50회 미만 또는 간이과세자면 면제지만 PG 가 신고번호를 요구할 수 있다([뉴시스](https://www.newsis.com/view/NISX20200729_0001111296), [thecheck](https://thecheck.co.kr/mail-order-business-report-exemption/)). PWA 는 Apple 가이드라인 3.1.1(구독은 IAP 의무)·한국 제3자 결제 26% 의 적용 대상 자체가 아니다 — 가이드라인에 PWA 라는 단어가 없는 것은 예외 조항이 있어서가 아니라 스토어 밖이기 때문이며, 네이티브 래퍼를 올리는 순간 3.1.1 이 즉시 붙는다([Apple 가이드라인](https://developer.apple.com/app-store/review/guidelines/), [CNBC](https://www.cnbc.com/2022/06/30/apple-opens-up-third-party-app-payments-in-korea-will-take-26percent-cut-.html)).

## OCR·AI·LLM: 비용은 변수가 아니고, 동의와 정확도가 변수다

공식 단가로 계산하면 스크린샷 1장의 추출 비용은 어느 경로든 의사결정 변수가 되지 못한다. 클라우드 OCR 은 Upstage Document Parse Standard **$0.01/페이지**(Enhanced $0.03)([Upstage](https://upstage.ai/pricing)), Google Document AI **$1.50/1,000페이지**([Google Cloud](https://cloud.google.com/document-ai/pricing)), AWS Textract Detect $0.0015/페이지(서울 리전 단가·한국어 지원은 페이지에 없음)([AWS](https://aws.amazon.com/textract/pricing/))이고, Naver CLOVA OCR 은 공개 페이지 3곳 모두 요금 셀이 비어 있어 원화 단가 **확인 불가**다([CLOVA OCR FAQ](https://guide.ncloud-docs.com/docs/en/clovaocr-faq)). LLM 비전은 Claude Haiku 5.5 입력 $0.10/출력 $0.50 per MTok, Opus 5.5 $4/$20, 이미지 토큰은 ⌈w/28⌉×⌈h/28⌉ 라 1920×1080 이 표준 티어 1,560 토큰이다([Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing), [Claude Vision](https://platform.claude.com/docs/en/build-with-claude/vision)). 조사자 추정(1080×2400 캡처 ≈ 1,600 토큰, 출력 400, 시스템 800 가정)으로 **Haiku 5.5 ≈ $0.00044/장, Opus 5.5 고해상 ≈ $0.025/장**, 현재 구조(브라우저 Tesseract.js → 마스킹 텍스트만 전송 → Opus 5.5)는 ≈ $0.017/장이며, 1,000명 베타가 월 30장씩 올려도 월 $13(Haiku)~$750(Opus) 범위다. Gemini 2.5 Flash-Lite 는 $0.10/$0.40 으로 비슷하지만 **무료 티어는 콘텐츠를 제품 개선에 사용(Yes)** 이라 제외해야 한다([Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing)). 온디바이스 선택지 중 한국어가 공식 지원되는 것은 Android ML Kit v2 와 Tesseract(kor) 이고([ML Kit](https://developers.google.com/ml-kit/vision/text-recognition/v2)), Apple Vision 은 초기 리비전에 한국어가 없었으며 iOS 18.1 에서 지원된다는 개발자 보고가 있다([Apple Developer Forums](https://developer.apple.com/forums/thread/765905)) — 공식 문서의 버전은 미확인. 한국어 헤드투헤드 벤치마크는 공개 자료가 없어 증권사 캡처 샘플로 자체 측정해야 하고, 깨끗한 디지털 스크린샷은 문자 인식률보다 **표 구조(행 묶기)와 숫자 열 정렬**이 병목이라는 점이 `parse-holdings.ts`/`ai_read.py` 의 관계식 검증(수량×단가=금액) 설계와 맞물린다.

국내에서 "자동 기록"이 확인된 것은 증권사 자체 서비스(키움 2013 '자동투자일지', 현재 존속 여부 미확인)뿐이고([아주경제](https://www.ajunews.com/view/20130514000364)), 독립 매매일지 앱(살래말래·Trady·고독한 투자자·거래 노트·투자일기)은 전부 수동 입력이다([살래말래](https://apps.apple.com/kr/app/%EC%82%B4%EB%9E%98%EB%A7%90%EB%9E%98-%EC%A3%BC%EC%8B%9D-%EB%A7%A4%EB%A7%A4%EC%9D%BC%EC%A7%80-%EC%BB%A4%EB%AE%A4%EB%8B%88%ED%8B%B0/id6755510192?l=en-GB)). 해외 저널은 브로커 CSV 업로드 + API 자동 동기화가 표준이고([Tradervue Help](https://help.tradervue.com/article/4626-broker-sync-vs-standar-import)), TradesViz 의 AI 활용은 미지원 포맷을 ChatGPT/Gemini 로 변환하라는 "Convert it with AI" 에 그치며([TradesViz FAQ](https://www.tradesviz.com/product-faq/)), 스크린샷 OCR 은 소형 iOS 앱(Trading Journal Pro·TraderCater)의 차별화 포인트다. "추출·요약만, 판단 없음"을 제품 원칙으로 명문화한 국내 사례는 찾지 못했고 시장은 'AI 투자비서' 방향이라([더팩트](https://news.tf.co.kr/read/economy/2217584.htm)), PivoxQuant 의 추출 전용 AI 는 차별점이라기보다 규제·신뢰 리스크를 줄이는 방어선으로 설명하는 것이 정확하다. 체결 문자 파싱은 공개 포맷 사전이 없으므로 정규식 1차(변형 케이스 테스트 스위트) + LLM 2차(정규식 실패분만)가 비용·검증 양쪽에서 유리하고, iOS 에서는 공유 시트 → PWA 텍스트 입력 → 로컬 정규식 → 확인 UI 가 현실적 상한이다.

규제 쪽은 세 층이다. 첫째, 금융위 「금융분야 인공지능 가이드라인」 개정안은 2026-06-22 시행, 7대 원칙(거버넌스·합법성·**보조수단성**·신뢰성·금융안정성·신의성실·보안성)의 "모든 금융회사" 대상 **자율규제**라([연합/다음](https://v.daum.net/v/20260618150301114), [뉴데일리](https://biz.newdaily.co.kr/site/data/html/2026/06/18/2026061800173.html)) 비금융 핀테크에 직접 구속력은 없어 보이지만 원문은 미확인이다. 둘째, AI기본법은 2026-01-22 시행이고 §31 은 생성형 AI 기반 서비스임을 **이용 전 사전 고지**(약관·화면 안내 가능)하되, "서비스 UI 안에서만 제공되는 결과물"은 결과물별 표시가 면제되고 다운로드·공유로 외부 유통되면 표시 대상이 될 수 있으며, 계도기간 1년 이상·사전고지 위반 과태료 3천만 원 이하다([뉴시스](https://mobile.newsis.com/view/NISX20260121_0003485509), [세종 뉴스레터](https://www.shinkim.com/kor/media/newsletter/3114)). 한 뉴스레터는 "2026-07-21 개정 시행"을 언급해 상충하므로([DKL](https://maily.so/dklnews/posts/g0zml7v7rql)) 법제처 원문 확인이 필요하다. PivoxQuant 의 추출 결과가 앱 내 검토 표로만 쓰이면 사전고지로 족하지만, '데이터 내보내기'에 AI 추출 행이 섞여 나가면 외부 유통에 해당할 수 있다. 셋째, 국외이전이다. Anthropic 은 2026-06 보도에서 국내 규제환경에 맞춘 데이터 레지던시 옵션을 "검토 중"이고([sbsstar](https://sbsstar.net/article/N1008615690/anthropic-lands-in-south-korea-amid-fallout-from-mythos-export-controls)) 가격 페이지의 `inference_geo` 는 미국 전용(1.1배)만 있다([Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing)). 텍스트만 보내고 계좌·식별 줄을 기기와 서버에서 두 번 제거하는 현재 설계는 이전 대상 데이터를 보유 종목·수량·금액으로 좁히지만, 특정 개인의 보유내역은 개인정보로 볼 여지가 커서 "국외이전 고지 + 처리방침 개정 없이는 켤 수 없다"는 코드 주석의 판단은 자료와 부합한다. Upstage·CLOVA 의 보관 위치·학습 미사용 약정은 공식 페이지에서 **확인 불가**이므로 "국내 벤더면 국외이전을 피한다"고 단정할 수 없다.

## 규제 경계와 경쟁 스택: 무료 + 조언 없음은 §101 밖이고, 경쟁 제품은 전부 시세를 보여준다

2024-08-14 시행 개정 자본시장법에서 유사투자자문업 신고(§101)의 요건은 **"고객으로부터 일정한 대가를 받고" + "개별성 없는 조언"**이다. 금융위 보도자료는 단방향 채널(수신자가 채팅을 입력할 수 없는 채팅방·푸시·알림톡)로만 가능하고 SNS·오픈채팅 양방향 유료 회원제는 투자자문업(미등록 시 3년 이하 징역 또는 1억 원 이하 벌금)으로 규율한다고 밝혔고([금융위원회](https://fsc.go.kr/edu/news/83077?curPage=1)), §101①이 "불특정 다수인 대상 간행물"에서 "고객으로부터 일정한 대가를 받고"로 바뀌고 §101의3 이 표시·광고에 ①개별 상담·자금운용 불가 ②원금손실 가능성 ③정식 금융투자업자 아님 고지를 요구한다([법무법인 대륜](https://www.daeryunlaw.com/newsletter/news/53)). 변호사 해설은 "누구나 같은 투자조언을 무료로 받을 수 있는 경우에는 직접적인 대가를 받았다고 보기 어려워 신고가 필요하지 않다"고 보되 게시일 미표시라 2024 개정 반영 여부가 불명하다([로톡](https://www.lawtalk.co.kr/posts/34923)). 구조상 무료 + 조언 없음인 기록·회고 앱은 두 요건 모두 밖이고, 유료화하면 "대가" 요건이 살아나 **남는 방어선은 "조언이 아니다"는 것뿐**이다. 그 방어선을 코드로 보증하는 것이 PivoxQuant 의 `services/legal_filter.py`(정규식 42패턴 surgical 치환 + `@legal_scrub_response` 데코레이터 + 테스트 7종)인데, **금지어 필터·응답 스크럽을 공개적으로 설명한 국내 핀테크 기술 블로그·논문은 하나도 찾지 못했다.** 비교 대상이 없으므로 이 방어선은 독자 설계이고, 변호사 검토 없이는 "충분"을 주장할 근거가 없다. §101의3 고지 3종은 신고 대상이 아니더라도 면책 문구로 선제 채택하는 것이 비용 없는 방어이며, 커뮤니티가 없는 PivoxQuant 는 양방향 채널 규율을 맞지 않는다. 금소법 §22 광고 규제와 협회 사전심의는 "금융상품 또는 판매업자의 업무" 광고에 걸리고 핀테크의 상품 비교·추천은 2021년 금융당국이 "중개"로 판단했으므로([금융위원회 가이드라인](https://www.fsc.go.kr/no010101/76045), [아주경제](https://www.ajunews.com/view/20210915030933437)), 증권사 계좌 개설 링크·ETF 비교 같은 제휴 수익 모델이 레드라인이다. 무료 정보 제공 앱에 대한 금융위·금감원 유권해석은 찾지 못했으니 CLAUDE.md 의 "무료 운영은 §101 밖인가"는 변호사 질문 목록에 그대로 남는다. 쓸 수 있는 공공 자원은 K-Startup 스타트업 법률지원(2026-03-30~12-31 상시, 850건 내외, 창업기업 자격)([중기부 공고 PDF](https://grant-documents.thevc.kr/299360_2026%EB%85%84_%EC%8A%A4%ED%83%80%ED%8A%B8%EC%97%85_%EB%B2%95%EB%A5%A0%EC%A7%80%EC%9B%90%EC%82%AC%EC%97%85_%EC%B0%B8%EC%97%AC%EA%B8%B0%EC%97%85_%EB%AA%A8%EC%A7%91_%EA%B3%B5%EA%B3%A0(%EC%88%98%EC%A0%95).pdf))과 핀테크지원센터 전문지원단(73명) 무료 컨설팅이고([KDI 경제정보센터](https://eiec.kdi.re.kr/policy/materialView.do?num=286746)), 혁신금융서비스(심사 최대 120일, 지정 2년 + 2년)는 면제받을 규제가 있을 때만 의미가 있다.

경쟁·유사 제품의 스택은 규모에 따라 두 계열이다. 국내 대형은 **JVM(Kotlin/Java) + Spring + Kubernetes + MySQL** 이 공통 분모다 — 토스증권 채용 공고(Kotlin, Spring MVC/WebFlux, JPA, MySQL·MongoDB·Redis, Kubernetes·Istio; Market Platform 은 Go·Kafka·NATS)([토스 채용](https://toss.im/career/job-detail?gh_jid=4168349003)), 카카오페이증권(JVM·Spring·AWS·Kubernetes)([리멤버](https://career.rememberapp.co.kr/job/posting/282605)), 뱅크샐러드(gRPC 위 Go/Kotlin/Python, AWS Kubernetes, MySQL·DynamoDB, Datadog·Sentry)([리멤버](https://career.rememberapp.co.kr/job/posting/297517)). 이 스택은 팀 규모와 금융보안원 감사·망분리가 전제라 1인 창업자가 따라갈 이유가 없다. 국내 직접 경쟁은 둘 다 iOS 네이티브 + 광고/인앱이다. 살래말래(2025-11-20 출시, 무료·인앱 없음·19+·광고·커뮤니티)는 스택 비공개([App Store](https://apps.apple.com/kr/app/id6755510192?l=ko)), 도미노(패스트포워드)는 "연동 한 번으로 투자 내역"·실시간 시세·₩9,900 플러스 멤버십에 Pre-A 80억 원을 받고 "투자관리 서비스 최초 마이데이터 사업자 신청"을 했다고 보도됐으나 허가 취득 여부와 연동 방식은 **확인 불가**다([App Store](https://apps.apple.com/kr/app/id1540576519), [벤처스퀘어](https://www.venturesquare.net/894635)). 해외 소규모 사례가 PivoxQuant 에 더 가깝다 — Tradervue 는 2021 인수 시점에 **"lone employee"로 10만+ 활성 트레이더**를 운영했고([tech.mn](https://tech.mn/news/2021/03/30/sureswift-capital-acquires-tradervue)), Sharesight 는 Ember.js 웹앱을 Cordova 로 래핑, 전체 인프라 AWS, MySQL → Aurora 이전, **웰링턴 개발팀 8명**으로 60만+ 투자자를 운영하며 초기 외주 견적은 $50k~$500k 였다([Sharesight 블로그](https://www.sharesight.com/blog/qa-with-sharesight-co-founder-and-cto-scott-ryburn-on-10-years-of-sharesight)). 고쳐야 할 것과 그대로 둘 것은 기준이 하나다 — **법이 요구하거나 약관이 금지하는데 코드가 반대로 되어 있으면 고치고, 비표준이지만 규제·비용 회피라는 같은 방향을 향하면 둔다.** 고칠 것은 여섯이다. (1) 환율 소스 우선순위 — 출처 표기와 실제 값이 다르고 FMP §2.2.2 에 걸린다. (2) Stripe — 한국 법인 개설 불가가 중론이라 유료화 전에 국내 PG 로 교체할지 해외 법인을 둘지를 코드보다 먼저 결정해야 한다(공식 문서는 확인 불가). (3) 2026-10-31 고시 대응 세 가지(2FA·운영자 접속기록·내부관리계획). (4) `auth_events` 파기 잡과 `memory://` 레이트리밋. (5) 처리방침의 Supabase 법인명·로그 위치와 `consent-stack.tsx` 의 "§22 ⑥" 조문 번호. (6) 국외이전 필수 동의 체크박스 — 법이 요구하지 않을 가능성이 높아 "과한 것"이지만 전환은 변호사 확인 뒤에 한다. 둘 것은 PWA(스토어 밖이라 IAP·26% 가 안 붙음; 획득 채널 열위는 베타 목적상 감수), 시세 미표시(합법 무료 경로가 없음), 브로커 미연동(허가·약관 모두 막힘), AI 추출 전용·기본 꺼짐(§101 "조언" 리스크와 국외이전 표면 최소화 — 시장 방향과 반대지만 방어선으로 정확), Google/Kakao OAuth 만의 가입과 14세 자가선언(금지 근거 미발견, 법정대리인 플로우를 만들지 않는 것이 더 단순), 브로커 토큰 AES-GCM(의무 이상이지만 비용 0), Flask 모놀리스(1인 유지의 전제), 그리고 `legal_filter` 단일 방어선(공개 비교 대상이 없으므로 교체가 아니라 변호사 검증 대상). ISMS-P·FDS·본인확인은 "도입하지 않은 것"이 맞는 상태다.

## 결론

이번 조사가 바꾼 이해는 한 가지다. PivoxQuant 가 업계 표준에서 벗어난 지점들은 기술 취향이 아니라 **한국 금융 데이터 규제의 세 관문(마이데이터 허가·코스콤 라이선스·증권사 약관)이 1인 무료 베타에 닫혀 있다는 사실의 거울상**이고, 그 대가는 전부 "제품 비교 열위" 한 곳으로 모인다 — 경쟁 제품은 국내외 가릴 것 없이 시세를 보여주고 계좌를 연동한다. 관문이 열리는 조건은 셋 다 돈과 법인(코스콤 견적, Tiingo USD 250/월, 마이데이터 5억)이지 코드가 아니므로, 다음 세션의 기술 작업은 관문을 두드리는 게 아니라 **관문 밖에서 실제로 틀린 것**(FMP 우선 환율, Stripe 전제, 2026-10-31 고시, 파기 잡)을 바로잡고 무료 원천(공시·환율·텍스트 알림 파싱)을 끝까지 쓰는 데 써야 한다.

남는 질문은 기술이 아니다. 유저 본인 키 연동이 약관상 허용되는지, 무료 운영이 §101 밖인지, 국외이전을 고지로 갈음할 수 있는지, 14세 자가선언이 충분한지 — 네 가지 모두 공개 자료로는 끝나지 않았고 변호사 확인 없이는 "할 수 있다"로 바꿀 수 없다. 반대로 "한국 개인투자자가 기록을 하긴 하는가"라는 제품 전제의 답은, 이번에 확인된 대로 국내 매매일지 앱 전부가 수동 입력이고 체결 알림 파싱을 내세운 앱이 하나도 없다는 공백 자체가 단서다 — 그 공백이 수요 부재인지 포맷 유지 비용 때문인지는 베타 데이터만이 답할 수 있다.
