## §E 로펌 Q&A 추가 항목 (V2 추가분)

### E.1 [최우선] EFTA §22 "거래기록 5년 보관" 적용 주체 해석

**질문**: PivoxQuant 는 KIS Open API 를 통해 이용자의 주문 체결 이력을 **조회** 할 뿐 **체결** 하지 않습니다. EFTA §22 "거래기록 5년 보관" 의무는 체결 주체인 KIS 에게만 부과되고, PivoxQuant 는 해당 의무 주체가 아니라는 해석이 맞는가?

**왜 중요한가**:
- PIPA 삭제권(§36) vs EFTA §22 보관의무 충돌 가능성.
- 이용자가 "연동 해제" 요청 시 즉시 삭제 가능한지 vs 5년 보관해야 하는지 **이용약관 §11 / 개인정보처리방침 §10.3** 의 근본 전제.

**회사 포지션**: 비적용. 체결 주체는 KIS.

**판정 요청**: 금감원 / 로펌 교차검증 필요.

---

### E.2 KIS Open API 시세정보 재배포 금지 — 이용자 위반 시 PivoxQuant 책임 범위

**질문**: 이용자가 PivoxQuant 화면의 실시간 시세를 스크린샷으로 SNS 에 유포한 경우, KIS 가 PivoxQuant 에게 **이용약관 위반으로 계약 해지·손해배상** 을 청구할 수 있는가? V2 §12 조항만으로 PivoxQuant 의 과실 면책이 충분한가?

**왜 중요한가**:
- PivoxQuant 의 **사업 연속성**에 직결. KIS 와의 계약 해지 시 서비스 전면 중단.

**회사 포지션**: §12 와 모니터링 도구(예: 워터마크)로 과실 면책 주장.

**판정 요청**: 로펌 — (a) 워터마크 등 추가 기술적 조치 필요성, (b) KIS 와의 개별 계약 (Commercial License) 전환 필요성.

### E.3 "Option C" 결정의 기능 회귀 리스크

**질문**: Alpaca 연동 제거 후 **autotrader 기능을 Partner 티어에서 삭제**하면, 기존 베타 유저 중 Partner 에 관심을 보인 자에게 **약관변경 고지 + 환불** 의무가 발생하는가?

**회사 포지션**: 베타 = 무료. 기존 유저 재동의 불필요.

**판정 요청**: 로펌 — 약관규제법 §17 (약관 변경 고지) 적용 여부.

### E.4 KIS 계좌번호 **마스킹 표시** 충분성

**질문**: V2 §10.1 은 계좌번호를 "앞 6자리 노출 + 뒷자리 마스킹" 으로 표시. 이것이 PIPA §29 안전성 확보조치 및 **개인정보 안전성 확보조치 고시 §7 (개인정보 표시 제한)** 충족?

**회사 포지션**: 충분. KIS 앱도 동일 방식.

**판정 요청**: 로펌 — 금융 도메인 특례 여부.
