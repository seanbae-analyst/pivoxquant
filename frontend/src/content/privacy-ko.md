# PivoxQuant 개인정보처리방침 (초안)

> 시행일: **변호사 검토 후 확정** · 현재 버전: 2.0-draft

**배상현**(이하 "운영자")은 「개인정보 보호법」 및 관련 법령을 준수하며, 이용자의 개인정보 보호를 최우선 가치로 삼습니다. 본 개인정보처리방침은 운영자가 제공하는 **PivoxQuant**(이하 "서비스") 이용 시 개인정보가 어떻게 수집·이용·보관·파기되는지 안내합니다. **현재 서비스는 무료로 제공되며, 무료 단계에서도 개인정보 보호법이 동일하게 적용됩니다.**

---

## 제1조 (수집하는 개인정보 항목)

운영자는 서비스 제공을 위해 다음의 최소한의 개인정보를 수집합니다.

### 1. 회원가입 시 (필수 — OAuth 소셜 로그인)

이용자는 Google 또는 Kakao OAuth로만 가입하며, 이메일+비밀번호 가입은 제공되지 않습니다.

| 항목 | 비고 |
|------|------|
| 이메일 주소 | 회원 식별, 로그인, 고지사항 발송 |
| 이름 | OAuth 제공자가 제공하는 범위 |
| 프로필 이미지 URL | OAuth 제공자가 제공하는 경우 (선택) |
| OAuth 고유 식별자 (Google sub / Kakao user_id) | 회원 식별 |

### 2. 서비스 이용 중 (기능별 — 이용자 입력 또는 연동)

| 항목 | 수집 시점 |
|------|-----------|
| 투자 성향 응답 (온보딩 설문) | 이용자가 온보딩을 진행하는 경우 |
| 포트폴리오 데이터 (종목, 수량, 평균 매입가, 매수 환율, 보유 메모) | 이용자가 직접 입력하는 경우 |
| 거래 내역 (종목, 매매 구분, 수량, 단가, 손익) | 이용자가 직접 입력하거나, "가져오기"로 올라온 체결 정보를 이용자가 승인하는 경우 |
| 이용자가 직접 올린 거래 파일·텍스트에서 추출한 체결 정보 (종목명·종목코드, 매매 구분, 수량, 단가, 금액, 통화, 수수료, 체결 일시) | 이용자가 "가져오기" 화면에서 증권사 앱이 내보낸 거래내역 파일(CSV · XLSX · XLS · PDF) 또는 체결 알림 텍스트를 직접 업로드하는 경우. 처리 방식은 제2조의 "가져오기 처리 원칙" 참조 |
| 가져오기 이력 (파일명, 처리 건수, 동의 일시) 및 가져오기 토큰 정보 (토큰 해시, 앞 12자리 표시값, 발급·폐기 일시) | 이용자가 "가져오기" 기능 또는 가져오기 토큰을 사용하는 경우 |
| 사전 거래 기록 (Pre-Trade) 입력 (의도 종목·근거 메모) | 이용자가 사전 거래 기능을 사용하는 경우 |
| 관찰 노트 (거래 없이 적은 메모, 관련 종목·태그) | 이용자가 관찰 노트를 쓰는 경우 |
| 리서치 노트 (종목, 사업 요약·이유·틀렸다고 볼 신호·위험·직접 확인한 숫자, 알게 된 경로, 다시 볼 날, 채점과 채점 한 줄) | 이용자가 리서치 양식을 쓰거나 채점하는 경우. 채점은 같은 종목의 본인 체결 기록(실현 손익의 부호)과 나란히 본인에게만 보여 줍니다 |
| 문 앞 기록 (증권 앱을 연 시각, 고른 답(그냥 보기·살 게 있음·팔 게 있음), 적은 한 줄과 그 줄에서 읽은 종목, 앱 이름) | 이용자가 "문 앞의 한 줄"을 설정해, 본인 휴대폰의 자동화 도구가 가져오기 토큰으로 보내거나 웹 화면에서 직접 답하는 경우. 증권 앱의 화면·계정·주문 정보는 받지 않으며, 같은 이용자의 체결 기록과 나란히 본인에게만 보여 줍니다 |
| 거울(Mirror) 분석 결과 및 페르소나 스냅샷 | 위 거래 데이터로부터 통계적으로 산출 |
| 알림·마케팅 수신 설정, 동의 일시 | 이용자가 설정하는 경우 |
| 웹 푸시 구독 정보 (브라우저가 발급한 푸시 수신 주소, 알림 암호화에 쓰는 키) | 이용자가 기기에서 푸시 알림을 켜는 경우. 기기에서 푸시 알림을 끄면 삭제되며, 푸시 서비스가 구독 만료를 알려 오면 다음 발송 시도 때 삭제됩니다. 전달 경로는 제6조 제5항 참조 |
| 고객 문의 내용 및 문의 시점 이메일 | 문의 접수 시 |

### 3. 증권사 계좌 연동 (현재 제공하지 않음)

**운영자는 현재 증권사 계좌 연동 기능을 제공하지 않으며, 브로커 API 인증정보(App Key · App Secret · 계좌번호 · 접근 토큰)를 일절 수집·저장하지 않습니다.** 이용자가 증권사 계정이나 그 인증정보를 서비스에 입력하는 화면 자체가 존재하지 않습니다.

거래 데이터는 이용자가 직접 입력하거나 제2조의 "가져오기"로 등록하는 방법으로만 서비스에 들어옵니다. 향후 연동 기능을 도입하는 경우 수집 항목·암호화 방식·별도 동의 절차를 본 방침에 먼저 반영한 뒤 시행합니다.

### 4. 자동 수집 정보

- IP 주소, 접속 로그, 기기 정보(OS·브라우저), 쿠키·세션 식별자
- 서비스 내 활동 로그(조회 종목, 기능 이용 기록 등)
- 서비스 오류 발생 시 기술적 로그(요청 URL, User-Agent 등)

### 5. 수집하지 않는 정보

- 주민등록번호 (수집하지 않음)
- 신용카드 번호·은행 계좌번호 등 결제수단 정보 (현재 무료 — 수집하지 않음)
- 실명 인증 정보 (투자자문업이 아니므로 불필요)

> 검토 비고: 현재 서비스는 무료이므로 결제 관련 개인정보(카드정보·청구지 등)를 수집하지 않습니다. 유료 전환 시 결제대행사(Stripe)를 통한 결제정보 처리 조항을 신설하고 본 방침을 개정합니다.

## 제2조 (수집 방법)

1. OAuth 소셜 로그인을 통한 자동 전송 (Google / Kakao)
2. 온보딩·포트폴리오·사전 거래 화면에서의 직접 입력
2-1. 이용자가 "가져오기" 화면에 직접 업로드한 증권사 거래내역 파일(CSV · XLSX · XLS · PDF) 또는 체결 알림 텍스트의 파싱 (업로드 시 별도 동의, 서비스는 증권사 계정·인증정보에 접근하지 않음)
2-2. 이용자가 설정에서 발급한 가져오기 토큰으로, 이용자 본인이 운영하는 자동화 도구(예: 휴대폰 자동화 앱)가 전송한 체결 알림 텍스트의 파싱, 그리고 같은 토큰으로 전송한 문 앞 기록(증권 앱을 열 때 고른 답과 한 줄)의 저장 (토큰 발급 시 별도 동의, 토큰은 발급 시 1회만 표시되고 서버에는 복원 불가능한 해시로만 보관, 이용자가 언제든 폐기 가능)
3. 쿠키 및 로그를 통한 자동 수집
4. 고객 문의 처리 과정에서의 수집

> 증권사 API 연동을 통한 계좌 정보 조회는 현재 제공하지 않습니다(제1조 제3항).

### 가져오기(Import) 처리 원칙

- **원본 파일은 저장하지 않습니다.** 업로드된 파일은 메모리에서 읽어 표로 해석한 뒤 곧바로 폐기되며, 디스크·데이터베이스·외부 저장소 어디에도 기록되지 않습니다. 이력에 남는 것은 파일명(최대 255자)과 처리 건수·동의 일시뿐입니다.
- **PDF 암호는 파일을 여는 데에만 사용하고 저장하거나 로그에 남기지 않습니다.** 증권사가 생년월일 등으로 잠근 PDF를 열기 위해 이용자가 입력한 암호는 해당 요청이 끝나면 사라지며, 오류 보고 경로에도 포함되지 않도록 차단되어 있습니다.
- **계좌번호는 추출하지 않습니다.** 파일·텍스트에서 뽑는 값은 체결 정보뿐이며, 확인용으로 남기는 원문 조각은 한 건당 최대 300자이고 계좌번호 형태의 문자열은 저장 전에 가려집니다.
- **승인 전까지는 "대기 목록"에 머뭅니다.** 해석된 체결 정보는 대기 목록에 저장되며, 이용자가 승인해야 거래 내역으로 확정됩니다. 이용자는 승인하지 않고 삭제할 수 있습니다.
- **용량 제한:** 파일 2MB · PDF 40쪽 · 붙여넣기 텍스트 20,000자 · 1회 전송 500건.

## 제3조 (수집 및 이용 목적)

| 이용 목적 | 처리 항목 |
|-----------|-----------|
| 회원 식별 및 인증 | 이메일, OAuth ID |
| 정보 제공 도구(시그널·거울·포트폴리오 집계) 제공 | 거래·포트폴리오 데이터, 이용 로그 |

| 이용자가 직접 쓴 기록(관찰·리서치 노트, 문 앞 기록)의 저장·열람 | 관찰 노트, 리서치 노트, 문 앞 기록 |
| 알림 및 마케팅 정보 발송 (동의자에 한함) | 이메일, 수신 동의 기록, 웹 푸시 구독 정보 |
| 고객 문의 및 민원 처리 | 이메일, 문의 내용 |
| 서비스 개선 및 통계 분석 | 이용 로그(비식별화) |
| 부정 이용 방지 및 보안 | IP 주소, 접속 로그 |
| 법령상 의무 이행 | 접속 로그 등 |

## 제4조 (보유 및 이용 기간)

운영자는 수집·이용 목적이 달성되면 지체 없이 해당 정보를 파기합니다. 다만 관련 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.

### 1. 회원 정보

- **탈퇴(삭제) 요청 시:** 요청 즉시 계정이 잠기고 로그인이 차단되며, **30일의 유예 기간**이 지나면 매일 1회 자동 실행되는 파기 작업이 회원 정보와 관련 데이터를 데이터베이스에서 **완전히 삭제**합니다. 유예 기간 중에는 이용자가 탈퇴를 철회할 수 있고, 철회하지 않으면 별도 조치 없이 삭제됩니다. 유예 없이 **즉시 삭제**를 요청하는 경로도 함께 제공합니다.
- **삭제 범위:** 계정 정보, 포트폴리오·거래 내역, 가져오기 이력·대기 목록·가져오기 토큰, 사전 거래 기록, 관찰 노트, 리서치 노트, 문 앞 기록, 페르소나 스냅샷, 알림·수신 설정, 웹 푸시 구독 정보, 문의 내역 등 이용자 계정과 연결된 데이터 전부.
- **삭제 후에도 남는 것:** 로그인 시도 기록은 보안 및 부정 이용 대응을 위해 기록 자체는 남기되, 이메일 주소를 **복원이 불가능한 해시값**으로 대체하여 더 이상 개인을 식별할 수 없는 상태로 만듭니다. 개인과 연결되지 않은 익명 이용 통계(가입 단계별 집계 등)도 식별 정보 없이 남습니다.
- **가져오기 대기 데이터:** 이용자가 승인하지 않고 대기 목록에 남겨 둔 체결 정보는 이용자가 직접 삭제하거나 탈퇴로 파기될 때까지 보관됩니다.
- **문 앞 기록:** 이용자가 직접 삭제하거나 탈퇴로 파기될 때까지 보관됩니다. 이용자는 웹 화면(문 앞)에서 하나씩 지울 수 있습니다.

### 2. 법령에 따른 보존

| 항목 | 보존 기간 | 법적 근거 |
|------|-----------|-----------|
| 소비자의 불만 또는 분쟁처리에 관한 기록 | **3년** | 전자상거래법 §6 |
| 로그인 시도 기록 (성공·실패) | 계정 유지 기간 (탈퇴 시 이메일을 해시값으로 대체) | 개인정보 보호법 §29 및 안전성 확보조치 기준 |

### 5. 웹 푸시 알림의 전달 경로

이용자가 푸시 알림을 켜면, 알림은 **이용자의 브라우저 제조사가 운영하는 푸시 서비스**를 거쳐 기기로 전달됩니다(예: Chrome은 Google, Safari는 Apple, Firefox는 Mozilla, Edge는 Microsoft). 어느 푸시 서비스를 쓸지는 이용자의 브라우저가 정하며, 운영자가 고르거나 따로 계약한 사업자가 아닙니다.

- **푸시 서비스에 전달되는 것:** 푸시 서비스가 발급한 푸시 수신 주소, 암호화된 알림 메시지, 발송 시각 등 전달에 필요한 정보.
- **알림 내용은 암호화해 보냅니다.** 알림 내용은 웹 푸시 표준(RFC 8291)에 따라 운영자 서버가 이용자 브라우저의 키로 암호화해 보냅니다. 푸시 서비스는 전달에 필요한 정보(수신 주소, 발송 시각, 메시지 크기 등)를 처리합니다.
- **잠금 화면 표시:** 알림 문구에는 종목명 등 이용자 본인의 기록과 관련된 내용이 들어갈 수 있고, 기기 설정에 따라 잠금 화면에 보일 수 있습니다. 표시 여부는 기기·브라우저의 알림 설정에서, 알림 끄기는 서비스의 [설정 → 알림]에서도 바꿀 수 있습니다.

> 검토 비고 6(2026-10-14): 웹 푸시는 제1항 표(회원가입 시 별도 동의를 받는 국외 이전 대상)에 넣지 않고 이 항에서 따로 알립니다. 푸시 서비스는 이용자 브라우저가 정하는 사업자로, 운영자가 선정·계약한 사업자가 아니어서 위탁으로 보지 않으나, 푸시 수신 주소와 전달 정보가 국외 사업자를 거치는 이상 처리위탁·국외 이전(§28-8)에 해당하는지는 변호사 확인이 필요합니다(자문 큐 Q6에 병합). 해당한다고 판단되면 제1항 표와 회원가입 동의 문구를 함께 고칩니다.

## 제8조 (쿠키)

1. 운영자가 사용하는 쿠키는 아래가 전부이며, 모두 로그인 유지·보안·표시 설정에 필요한 쿠키입니다.
2. **광고나 행태정보 수집을 위한 쿠키, 제3자 추적 스크립트는 사용하지 않습니다.** Google Analytics(GA4)를 포함한 어떠한 웹 분석 도구도 현재 사용하지 않습니다(실측).
3. 이용자는 브라우저 설정에서 쿠키 저장을 거부할 수 있으나, 거부 시 로그인 등 일부 기능 이용이 제한될 수 있습니다.
4. 쿠키 안내 배너에서 이용자가 선택한 값은 쿠키가 아니라 이용자 브라우저의 로컬 저장소에 저장되며, 서버로 전송되지 않습니다.
5. **기기 안 저장(로컬 저장소).** 쿠키 외에도 서비스는 이용자 브라우저의 로컬 저장소에 아래 값을 둡니다. 이 보관분은 이용자 기기에만 있으며 운영자 서버로 전송하지 않습니다(이용자가 화면에서 제출한 내용만 서버에 저장됩니다).
   - **최근 화면 데이터:** 거울·기록·포트폴리오 화면의 마지막 조회 결과(이용자 본인의 기록). 서버가 준비되는 동안 화면을 바로 보여 주기 위한 것으로, 로그아웃·탈퇴 요청·다른 계정 로그인 시 지우고 7일이 지난 값은 쓰지 않습니다. 로그인 정보·인증 토큰·문의 내역·가져오기 원문은 여기에 두지 않습니다.
   - **월급날 배분:** 이용자가 적은 들어온 돈, 생활비·저축·투자·기타 금액, 돌아보기 답. **서버로 보내지 않으며** 다른 기기에서는 보이지 않습니다. 화면의 "지우기", 회원 탈퇴 요청, 브라우저 데이터 삭제로 지워집니다. 로그아웃해도 이 기기에 남으므로 공용 기기에서는 "지우기"를 사용하세요.
   - **진행 중인 입력과 화면 설정:** 가입 동의 선택·온보딩 답 등 진행 중인 입력, 필터·스크롤 위치·안내 닫기 같은 표시 설정.

| 쿠키 | 용도 | 보관 기간 |
|------|------|-----------|
| 세션 쿠키 · 로그인 유지 쿠키 | 로그인 상태 유지 | 브라우저 종료 또는 로그아웃 시까지 |
| CSRF 토큰 쿠키 | 요청 위조 차단(보안) | 세션과 동일 |
| 언어 설정 쿠키 | 한국어·영어 표시 설정 저장 | 1년 |

> 비고: 향후 웹 분석 도구를 도입하는 경우 본 방침을 개정하고 별도 고지합니다.

## 제9조 (안전성 확보 조치)

### 1. 기술적 조치

- 비밀값은 평문으로 저장하지 않습니다 — 가져오기 토큰은 복원이 불가능한 해시(SHA-256)로만 보관하며, 암호화가 필요한 민감 정보에는 HKDF + AES-GCM 방식을 사용합니다
- 전송 구간 암호화 (HTTPS / TLS)
- 데이터베이스 접근 통제, 보안 패치 적용

### 2. 관리적 조치

- 개인정보 취급자 최소화 (운영자 1인), 접근 권한 관리, 주기적 점검

### 3. 물리적 조치

- 애플리케이션 서버(Render · 싱가포르 리전)와 데이터베이스(Supabase · 서울 ap-northeast-2 리전)는 모두 물리적 보안이 확보된 클라우드 데이터센터에서 운영됩니다.

## 제11조 (만 14세 미만 아동의 개인정보)

운영자는 **만 14세 미만** 아동의 회원가입을 허용하지 않습니다. 회원가입 시 이용자가 만 14세 이상임을 직접 확인(자가선언)하며(개인정보보호법 §22 ⑥), 확인 시각을 기록합니다. 생년월일 등 추가 개인정보는 수집하지 않습니다. 2026-09-19 이전 가입 시 수집된 생년월일은 더 이상 이용하지 않으며 회원 탈퇴 시 함께 삭제됩니다.
