# 한국 핀테크 데이터 연동 기술 — 개인투자자의 보유·체결 데이터를 앱이 받아오는 경로 (2026-10-28 조사)

> 조사 방법: WebSearch + 1차 자료 WebFetch/curl (금융위 보도자료, 토스증권 Open API 공식 문서·FAQ markdown, 한국투자증권 오픈 API 이용약관 PDF 원문, 키움·KB·LS 관련 기사, 마이데이터 과금·반납 관련 2024–2026 기사). 약관 원문을 직접 읽은 것은 **한국투자증권 "오픈 API 서비스 이용 약관(제휴 이용기관_사용자)" PDF 1건**뿐이다. 토스증권 Open API 약관은 페이지가 JS 렌더링이라 원문 추출에 실패했고 검색 요약(조항 내용)만 확보했다 — 아래에 그렇게 표시했다. 날짜가 오래된 자료(2019–2022)는 각 항목에 연도를 적었다.

## 핵심 질문 1. 마이데이터 사업자 허가 없이 금투업권 거래내역을 받는 합법 경로가 있는가 (중개업자 이용·제휴·유저 직접 업로드)?

### Takeaway
"증권사 → 제3자 앱" 자동 전송을 **허가 없이** 합법적으로 받을 수 있는 공식 경로는 2026년 현재 사실상 두 가지뿐이다: (a) 증권사가 **제도권 금융회사(투자자문·일임업자)** 에 한해 열어주는 Open API 제휴 — 핀테크·비제도권 법인은 명시적으로 배제, (b) 유저 본인이 발급한 **개인용 Open API 키**를 유저 본인이 쓰는 구조(토스증권·KIS·키움·KB·LS가 2025–2026년에 개인 대상 REST API를 열었다). 2022-01-05 이후 마이데이터 사업자의 스크래핑은 전면 금지됐고, 2025년에는 비사업자의 스크래핑에 대해서도 당국이 실태점검을 예고했다. 유저가 직접 내려받은 파일·캡처를 업로드하는 경로는 법적 쟁점이 가장 적지만 수작업이다.

### Inferences
- 오픈뱅킹은 증권 **계좌의 현금 입출금**만 보이는 구조라 주식 **체결·보유종목**은 받을 수 없다(API 정의가 "입출금내역"). 평가액·거래내역 목적에는 부적합.
- 마이데이터 사업자(예: 뱅크샐러드·쿠콘)를 통한 "제3자 제공" 경로는 제도상 존재하지만, 제공 측 사업자와의 B2B 계약 + 별도 동의 + 마케팅 금지 조건이 붙고, 공개된 스타트업 대상 상품 사례는 찾지 못했다.
- KIS 약관 구조(§2 ③ "이용기관이 개인의 오픈 API 서비스 권한을 얻어 대행", §5 ②~④)는 "제3자 앱이 유저 명의 데이터를 읽는" 정식 경로가 **제휴 이용기관 계약**뿐임을 보여준다 — 그리고 제휴 자격은 투자자문·일임업자다.
- 따라서 1인 핀테크가 쓸 수 있는 **허가·제휴 불필요 경로**는 ① 유저가 본인 키로 돌리는 로컬/본인 환경 연동(제3자 서버가 키를 보관하면 각사 약관의 키 대여·누설 금지와 충돌 — 질문 3 참조), ② 유저 직접 업로드(CSV/캡처/OCR), ③ 알림 파싱(질문 5) 세 가지로 좁혀진다.

### Gaps
- 신용정보법 §33조의2 "본인에게 전송" 경로를 증권사가 실제로 어떤 형식(파일 다운로드? 표준 API?)으로 구현했는지 확인 불가.
- 개인정보보호법 본인전송요구권 2026-08 시행이 증권사(금융투자업자)에도 적용되는지, 금융 분야는 신용정보법 특례로 제외되는지 확인 불가.
- 마이데이터 사업자(뱅크샐러드 등)가 외부 스타트업에 "제3자 제공 API"를 상품으로 파는지, 조건·가격은 공개 자료에서 찾지 못함.

## 핵심 질문 2. 마이데이터 허가의 실제 요건(자본금 5억·물적 요건·ISMS 등)과 1인 창업자의 현실적 취득 가능성; 2025–2026 완화 논의 현황

### Takeaway
요건은 2020년 도입 이후 **완화된 바 없다**(최소자본금 5억, 보안설비·망분리, 사업계획 타당성, 대주주·임원 적격성, 전문성 6요건; 예비 2개월+본허가 1개월 최소 3개월). 2024–2026년 당국 논의는 "진입 완화"가 아니라 **과금 원가 재산정(인하)·업무범위 확대(AI 에이전트·개인사업자·가상자산)** 쪽이고, 그 사이 69개 허가사 중 12곳(통신 3사 포함)이 반납해 2026-07 말 57개사가 영업 중이다. 과금(2024년 328억 원, 트래픽 비례 배분)은 사용자가 늘수록 커지는 구조라 1인 창업자에게는 자본금보다 **운영비 구조**가 더 큰 장벽이다.

## 핵심 질문 3. 증권사 Open API 중 제3자 서비스가 유저 명의 키로 조회하는 것을 명시적으로 허용/금지하는 곳 (약관 원문)

### Takeaway
확인된 범위에서 **"유저가 자기 키를 제3자 앱에 넣는 것"을 명시적으로 허용하는 증권사는 없다.** 한국투자증권은 제3자 서비스를 **제휴 이용기관(투자자문·일임업자 한정)** 계약 경로로만 열어 두고, 토스증권 Open API 약관은 **개인 고객 전용·법인 제외**, 앱키·시크릿키의 **대여·양도·제3자 누설 금지**, API로 받은 정보는 **본인 매매 목적 한정·제3자 배포 금지**(비상업적이어도)를 명시한다. 키움은 "제3자 작성 프로그램" 사용 자체는 막지 않되 결과 책임을 고객에게 둔다(2025-09-29 공지, 2차 자료). 전자금융거래법 §6③ 접근매체 양도·대여 금지 조항이 API 키에 적용되는지에 대한 당국 해석·판례는 찾지 못했다.

## 핵심 질문 4. 쿠콘·헥토(코드에프) 등 중개 API의 가격대·계약 조건 (스타트업 가능 여부)

### Takeaway
