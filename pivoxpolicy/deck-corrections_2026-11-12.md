덱이 무엇을 말했는지는 `registry/codings/deck_2026-11-01.yaml`(슬라이드 11·14와 노트를 옮긴 1차 코딩)과

우선순위: **A = 사실이 틀림(꼭 고침)** · B = 기준일·범위를 밝혀야 함 · C = 측정 방법이 바뀌어 표를 바꾸는 게 좋음.

## A — 사실이 틀림

### A1. 슬라이드 14 노트 — FSB 최종본의 에이전트 고유 식별자
- **덱:** "FSB 최종본(10-15)에서 개별 식별자 문구가 빠졌다"
- **고친 문장:** "FSB 최종본(2026-10-15)도 에이전트마다 고유 식별자를 두라고 적는다(§2.3 Attribution). 협의안에서 빠진 것은 '합성 직원(synthetic employee)' 표현뿐이다."
- **근거:** https://www.fsb.org/uploads/P151026-1.pdf PDF p.30 — "Visibility assigns individual unique identifiers to each AI agent … Unique identifiers for agents allow them to be easily differentiated from human users". 같은 PDF: 위험 기반 승인 트리거 p.56, kill-switch 구현·테스트 p.57.

### A2. 슬라이드 15 — 패치 기한 선례
- **덱:** "CISA BOD 22-01 — KEV 등재 취약점 2주 내 패치"
- **고친 문장:** "CISA BOD 26-04(2026-06-10)는 노출 여부 · KEV 등재 · 공격 자동화 가능성 · 기술적 영향 4가지로 기한을 3일 / 14일 / 60일로 나눈다. KEV 등재 + 자동화 가능 + 완전 장악이면 노출과 무관하게 3일. (전신 BOD 22-01은 폐지됐다.)"
- **덧붙일 1차 근거(덱 논지에 맞음):** BOD 26-04 배경 문단 — "their use of AI may further narrow the time defenders have to react between patch release and possible exploitation".
- **한계는 그대로:** 연방 민간기관 대상이라 민간 금융사에는 적용되지 않는다.

### A3. 슬라이드 14 — 한국 '사람 승인' 칸
- **덱:** 한국 사람 승인 = 자율(1) — 금융위 AI 가이드라인의 '보조적 역할 · 최종 판단은 직원' 원칙
- **고친 문장:** 한국은 AI에 대한 사람 승인·관리감독이 **구속력 있는 법률에 있다**(AI 기본법 제34조 제1항 제4호 "고영향 인공지능에 대한 사람의 관리ㆍ감독"). 단 에이전트를 이름 붙이지는 않는다 → AI·에이전트 층 **2**.
- **근거:** `out/matrix-consensus_2026-11-12.md` KR × 사람 승인 = 2 / 2† (일반 / AI). 이 칸은 법률 한 건이 받친다(`out/sensitivity-consensus_2026-11-12.md`).
- 이 칸 때문에 "한국 간극"은 7칸이 아니라 **6칸**이다.

### A4. 슬라이드 14 — 미국 '사람 승인 0 · 즉시 중단 0'
- **덱:** 미국 사람 승인 0, 즉시 중단 0
- **고친 문장:** 미국은 두 통제를 **일반 통제로는 구속력 있게 요구한다**(NYDFS Part 500 — 사람 승인: 500.12(b) 보완통제의 CISO 서면 승인 · 즉시 중단: 500.7(a)(4) 불필요한 계정·접근의 제거·비활성화. 단 사람 승인 2는 거래 결재가 아니라 예외 승인 한 줄에 기댄다). 그러나 **AI·에이전트에 적용한 요구는 자율 문서뿐**이다(NIST IR 8596 · NCCoE → 1).
- '0'은 "에이전트 대상 구속력 요구가 없다"는 뜻으로만 맞다. 표에 '0'을 그대로 두면 "미국은 결재·계정 정지도 없다"로 읽힌다.

## B — 기준일·범위를 밝혀야 함

### B1. 슬라이드 5 — 한국 금융권 연쇄 침해 규모
- **덱:** "16개사 · 약 10만 건"
- **고친 문장:** "16개사 · 약 10만 건(금융위 10-14 집계). 11-05 금융위 발표 기준 37개사 40건 · 약 47.3만 건."
- **근거:** 금융위 보도자료 88086(2026-11-05). AI 관여는 당국이 '추정·배제 못 함'이라고 했고 확정이 아니다 → 사건 레지스트리에서 `suspected`.

### B2. 슬라이드 14 — EU 칸
- **덱:** EU 즉시 중단 = 구속력(유일한 구속력 근거). 다른 칸은 비어 있음
- **고친 문장:** "EU는 AI Act 제14조만 코딩했다 — 사람 승인 · 즉시 중단 = 구속력(AI 일반 대상, 고위험 AI 한정). 나머지 5개 통제는 제14조 범위 밖이라 0이다. DORA 등은 아직 보지 않았다."
- 즉시 중단에 대해 "구속력 있는 유일한 근거"라는 말은 **맞다** — 한국·미국의 AI 층 즉시 중단은 모두 자율(1)이다. 하지만 사람 승인은 한국(AI 기본법)에도 있다(A3).

### B3. 슬라이드 11·14 — '에이전트를 명시한 구속력 문서'
- 덱의 결론 "에이전트를 이름 붙인 구속력 요구는 없다"는 **두 층 코딩과 독립 두 팀에서도 그대로다**(점수 3인 칸 0개). 이 문장은 고치지 않는다.
- 덧붙일 것: "에이전트를 명시한 요구는 자율 문서 — 금보원 AI 에이전트 보안 평가기준 · NIST NCCoE 개념서 · FSB 최종 보고서 — 에만 있다."

## C — 표를 두 층으로 바꾸기 (교수 피드백 "비교 기준이 추상적" 대응)

슬라이드 14의 한 칸짜리 표는 '직원 통제가 있으면 다룬 것인가'가 칸마다 달랐다(1차 vs 원문 코더 불일치 12칸이 전부 이 물음). 아래 두 층 표로 바꾸면 그 물음이 사라지고 **간극이 칸 단위로 세어진다**.

칸 = **일반 통제(사람·계정·시스템) / AI·에이전트 적용**. 0 미다룸 · 1 자율 · 2 구속력 · 3 구속력 + 에이전트 명시. `*` 근거 조항이 에이전트를 명시 · `†` 에이전트를 명시한 자율 문서가 따로 있음.

| # | 통제 | 한국 | 미국 | EU | 국제 |
|---|---|---|---|---|---|
| 1 | 인벤토리 | 2 / 1 | 2 / 1* | 0 / 0 | 0 / 1 |
| 2 | 공급자 관리 | 2 / 1* | 2 / 1 | 0 / 0 | 0 / 1* |
| 3 | 고유 식별자 | 2 / 0 | 1 / 1* | 0 / 0 | 0 / 1* |
| 4 | 최소 권한 | 2 / 1* | 2 / 1* | 0 / 0 | 0 / 1* |
| 5 | 사람 승인 | 2 / 2† | 2 / 1* | 0 / 2 | 0 / 1* |
| 6 | 감사 기록 | 2 / 1* | 2 / 1* | 0 / 0 | 1 / 1* |
| 7 | 즉시 중단 | 2 / 1* | 2 / 1* | 0 / 2 | 0 / 1* |

(`out/matrix-consensus_2026-11-12.md` 그대로. 21개 문서 · 독립 AI 코더 두 팀 · 일반 층 κ 0.91 · AI 층 κ 1.00 · 갈린 7칸 조정.)

슬라이드에 쓸 한 줄 결론:
- **간극 12칸** — 일반 통제는 구속력이 있는데 AI·에이전트 적용은 자율뿐이거나 없다. 한국 6 · 미국 6.
- **구속력 + 에이전트 명시 = 0칸** — 어느 관할도 없다.
- **한국 일반 통제의 '구속력'은 대부분 전자금융감독규정 제13조 한 조에 기댄다**(7개 중 5개 통제). 그 조가 AI를 이름 붙이지 않으니, 그 한 조에 AI 적용을 넣는 개정이 간극 5칸을 닫는 가장 짧은 길이다 — 정책 제안 슬라이드에 쓸 수 있다.
