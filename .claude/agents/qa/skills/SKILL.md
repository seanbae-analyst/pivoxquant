# QA Skills

## test-write
- 테스트 작성: 유닛/통합/E2E 테스트
- `Jest, Testing Library, Playwright`

## bug-hunt
- 버그 탐지: 코드 분석으로 잠재 버그 탐색
- `엣지 케이스, 레이스 컨디션, null 처리`

## regression-check
- 회귀 테스트: 변경사항이 기존 기능 깨뜨리지 않는지 확인
- `변경 파일 기반 영향 범위 분석`

## trading-logic-verify
- 매매 로직 검증: 트레이딩 계산 정확성 검사
- `수익률 계산, 파라미터 적용, 주문 실행 로직`

## performance-test
- 성능 테스트: 로딩 속도, 렌더링 성능
- `Lighthouse, Bundle size, API 응답 시간`
