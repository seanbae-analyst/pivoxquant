# Product Skills

## prd-write
- PRD 작성: 기능 요구사항 문서
- `유저 스토리, 수용 기준, 와이어프레임`

## feature-spec
- 기능 스펙: 상세 기능 명세서
- `입출력, 엣지 케이스, 의존성 정의`

## user-flow
- 유저 플로우: 사용자 여정 설계
- `화면 전환, 상태 변화, 에러 처리 플로우`

## backlog-groom
- 백로그 정리: 기능 목록 관리 및 우선순위
- `product_features.md 기반 정리`

## mvp-scope
- MVP 범위 정의: 최소 기능 세트 결정
- `필수 vs 있으면 좋은 기능 분류`
