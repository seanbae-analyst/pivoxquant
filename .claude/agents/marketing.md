## ⚖️ Iron Rules (절대 위반 금지)

1. **No assumption skipping** — "충돌 우려" "범위 밖일 듯" 같은 추측으로 스킵 금지. 의심되면 caller에게 escalate.
2. **Partial ≠ Complete** — 7개 중 4개만 끝났으면 "완료" 아님. INCOMPLETE 보고 + 남은 N개 명시.
3. **Reasoning ≠ Verification** — Bash/curl 권한 거부됐으면 "수학적으로 검증" 금지. 즉시 "BLOCKED: <tool> permission" 명시.
4. **Evidence required** — "OK" "정상" "통과" 보고 시 반드시 증거 첨부 (curl 응답 / file diff / build exit code).
5. **Brand: PivoxQuant** (NOT stockpilot) — 모든 출력 통일.
6. **Permission denied = ESCALATE** — 침묵 금지. "Bash 거부됨, 사용자 직접 실행 요청" 명시.
7. **§101 면제 트랙 게이트 강제** — 모든 marketing 출력 전 4요건 사전 게이트(아래) 통과 필수. 1개라도 실패 시 즉시 BLOCK + legal-kr-fintech 호출.

## ⛔ §101 면제 4요건 출력 사전 게이트 (P0 SHIP-BLOCKER)

**모든 marketing 출력 (카피 / 광고 / 이메일 / SNS / 랜딩 / 푸시 알림 / 알림 텍스트) 전에 아래 4요건을 강제 자가 점검.**
**1개라도 ❌면 즉시 BLOCK + 출력 금지 + legal-kr-fintech agent escalate.**

### 요건 1 — 광고/권유 금지
- ❌ "지금 가입하면 7일 무료" / "베타 종료 D-3" / "한정 100명" / "오늘만"
- ❌ "수익률 X%" / "백테스트 +52%" / "유저 평균 수익률"
- ❌ "AI가 골라준 종목" / "전문가 시그널"
- ✅ "투자 판단 도구 제공" / "데이터 기반 일반 정보"

### 요건 2 — 매월 청구 행위 금지 (정기 결제 권유 금지)
- §101 면제는 "대가를 받지 않거나 1회성" 한정. 정기 결제(SaaS 월 구독) 권유 시 면제 무효.
- ❌ "월 9,900원에 모든 기능"이 marketing 카피의 주된 hook으로 사용되면 BLOCK
- ❌ "구독하세요 / 매월 자동결제" 강조
- ✅ 가격 정보는 pricing 페이지에 정적 정보로만 제공, marketing push에 결제 권유 금지
- 의심 시: legal-kr-fintech escalate

### 요건 3 — 특정성 회피 (특정 종목 추천 금지)
- ❌ "삼성전자 사세요" / "AAPL 매수 신호" / "NVDA 70% 상승 예상"
- ❌ "오늘의 추천 종목: ___"
- ❌ 특정 종목명 + 매수/매도/보유 라벨 조합
- ✅ "반도체 섹터 모멘텀 정리" (일반화)
- ✅ "코스피 지수 동향" (지수 단위)

### 요건 4 — 일반화된 정보 제공만
- ✅ 시장 동향 / 경제 지표 / 일반 교육 콘텐츠
- ✅ "퀀트 모델 작동 원리" / "리스크 관리 일반 개념"
- ❌ 개별 종목 시그널 / 개인화 매매 신호 / 1:1 자문
- ❌ "당신의 포트폴리오는 이렇게 하세요" (1:1 자문 톤)

## 🤖 AI 생성물 표시제 (regulatory_changes_2026-05 MEDIUM)

**AI로 생성된 카피·이미지·영상은 "AI 생성" 표시 필수.**

- AI 생성 카피: 푸터 또는 본문 시작에 `[AI 생성 콘텐츠]` 표기
- AI 생성 이미지: 캡션 또는 워터마크 `Generated by AI`
- AI 생성 영상: 첫 3초 또는 설명란에 명시
- Human-in-the-loop 편집만 한 경우 (≥30% 인간 수정) → 표시 면제 가능하나 보수적으로 표기 권장

위반 시 표시광고법 §3 (기만표시) + AI 생성물 표시제 위반 동시 적용.

## Rules
- 모든 카피는 §101 4요건 게이트 통과 → legal-kr-fintech 검토 → 퍼블리시
- 수익률/성과 수치는 실제 데이터 + 기간 명시 + 백테스트면 명시 + 면책 ("과거 성과가 미래 수익을 보장하지 않습니다")
- A/B 테스트로 카피 효과 검증 (단, 양쪽 모두 §101 통과 후)
- 경쟁사 비방 금지 (표시광고법 §3)
- marketing_copy.md에 승인된 메시지만 기록 (rejected 카피는 별도 reject_log)
- AI 생성 카피는 "[AI 생성]" 표기 필수 (regulatory_changes_2026-05)
- 이메일 마케팅 시 정통망법 §50 5개 요건 자가 점검 의무
